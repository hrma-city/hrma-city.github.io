一、统一字段规范（机读契约）

15 张表共用同一套字段，JSON 兼容，判定表引擎可直接消费。代码型表（A、G 等）用 tables[].matrix 还原二维矩阵；行表用 tables[].list；步骤/时间线用 tables[].steps。

字段类型必填说明
idstring是稳定唯一标识，法典用 JT-A…JT-O（对应表 A–O）
codestring是法典内的表编号，如「表 A」
titlestring是判定表中文名
domainenum是域：价格 / 库存 / 竞争 / 渠道 / 客户 / 节奏 / 应急
categorystring否源 data-cat（英文），与 domain 对应
tagsarray否检索标签
triggerstring是何时查这张表（触发条件）
preconditionsstring否查表前必须已知的数据
inputsarray是输入变量 [{name,desc,type,unit,range,example}]
derivedarray否派生量 [{name,formula,desc,example}]
decision_logicstring是整体判定思路（一句话）
basisstring否公式与算法依据、演示算例
pitfallsstring否执行约束 / 易错点 / 红线
data_needsarray否需喂给引擎的数据字段名清单
confidencestring否置信度与适用范围说明
relatedarray否关联表 JT-X
versionstring否阈值版本，如 v1.0
tablesarray是机读载体：忠实还原法典的判定表面（matrix 二维矩阵 / list 行表 / steps 有序步骤）

表 A

每日价格调整判定表

价格

这是整本法典用得最多的一张表。每天都要用。 两个输入：① 目标日当前预测 OCC（在手房晚 + 预测增量 ÷ 可售房量）； ② Pickup 偏差 =（当前在手房晚 − 去年同期同一提前窗口在手房晚）÷ 去年同期在手房晚 × 100%。

触发：每日 09:10 执行调价前，依据目标日预测 OCC 与 Pickup 偏差确定 BAR 动作　|　决策逻辑：以预测 OCC 为行、Pickup 偏差为列查矩阵得价格动作；与表 B 库存动作配套；受表 O 优先级约束（价格优先级 3）。

库存与限制条件配置表

库存

价格定完之后，立刻配库存。库存动作优先级高于价格动作（见表 O）—— 房量安全永远比多卖 20 块钱重要。输入：目标日预测 OCC。

触发：价格定完后立即配置当日库存限制条件　|　决策逻辑：按预测 OCC 配置 MinLOS / CTA / 低价渠道 Stop Sell / 超额预订；库存动作优先级高于价格（表 O 优先级 2）。

预测 OCCMinLOS 最少住期CTA 不可入住低价渠道 Stop Sell超额预订
≥ 95%2 晚（D1 峰值日 3 晚）启用关闭尾房特惠 / 团購 / 批发商不超售
90 – 95%2 晚仅 D1 日启用关闭尾房特惠≤ 2 间
85 – 90%1–2 晚（周末 2 晚）否保留按表 E
70 – 85%1 晚否全开按表 E
< 70%不设限否全开 + 上促销不超售

表 C

价格指数（ARI）判定表

竞争

ARI = 本店 ADR ÷ 竞争组合加权 ADR × 100。回答一个问题：我卖得比隔壁贵还是便宜？ 云璟酒店竞争组合加权均价 ¥680，本店平峰 BAR 也是 ¥680，所以基准 ARI ≈ 100。

触发：评估本店价格相对竞争组合高低时　|　决策逻辑：按 ARI 七档判定，偏高/偏低则调价；不得与表 A 叠加（同日只执行优先级更高者，表 A 优先级 3 > 表 C 优先级 4）。

ARI判定动作
> 120严重偏高MPI < 95 → ↓8%；MPI ≥ 95 → 维持并每日盯 Pickup
110 – 120偏高RGI < 100 → ↓5%；RGI ≥ 100 → 维持
103 – 110略高维持，观察 Pickup
97 – 103健康维持
90 – 97略低预测 OCC ≥ 80% → ↑3%；否则维持
80 – 90偏低↑5%
< 80严重偏低↑8%，并核查房型配置与含早策略

关联：JT-D、JT-O　·　置信度：高　·　版本：v1.0

表 D

市场渗透指数（MPI）判定表

竞争

MPI = 本店 OCC ÷ 竞争组合 OCC × 100。回答一个问题：这条街的客人，我抢到了我该抢的份额吗？ MPI > 100 说明份额领先。

触发：评估本店市场份额是否达标时　|　决策逻辑：按 MPI 五档判定份额；偏诊断少出动作（表 O 优先级最低 6）；与 ARI 配合做三角诊断（MPI×ARI=RGI）。

MPI判定动作
> 110份额领先优先提价（走表 C 的提价分支）
100 – 110健康维持
95 – 100略弱检查 OTA 曝光 / 挂牌 / 点评分；补挂牌
85 – 95落后↓5% 或增加 OTA 广告投放
< 85严重落后启动《应急方案 L2-E1》：↓10% + 全员直销动员 + 48 小时复盘
情形含义处方
MPI 高 + ARI 高卖得又多又贵还能再提，试探性 ↑3–5%
MPI 高 + ARI 低靠低价换量提价，份额已稳，该收割了
MPI 低 + ARI 高太贵卖不动降价或加价值（含早/升级）
MPI 低 + ARI 低又贵不起又卖不动产品/口碑出问题，先查点评和渠道曝光
三角诊断法：MPI × ARI = RGI
单独看 MPI 或 ARI 都会误判，两个一起看才能下诊断： 情形含义处方 MPI 高 + ARI 高卖得又多又贵还能再提，试探性 ↑3–5% MPI 高 + ARI 低靠低价换量提价，份额已稳，该收割了 MPI 低 + ARI 高太贵卖不动降价或加价值（含早/升级） MPI 低 + ARI 低又贵不起又卖不动产品/口碑出问题，先查点评和渠道曝光

关联：JT-C、JT-O　·　置信度：高　·　版本：v1.0
