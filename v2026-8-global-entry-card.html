1 · 可复制的进入单元

全球化的单位不是「国家」，而是： 一位愿意试点的教师 ＋ 一套可本地化生成的案例 ＋ 一个可对接的认证框架。
要素最小可交付验收
一位教师3–5 位有改革意愿的 RM 教师；教师个人课堂就是最小试点单元，不等院系审批一学期内至少 4 讲用进真实课堂
一套案例免费课堂组件 1 套 + 本地参数生成 1 例；核心口径不变过 8 项门禁 + 本地教师确认 1 次
一个框架认证就绪对齐声明模板 1 份（默认不启用）禁用词回归 0 命中
不以覆盖国家数为目标
第一年只做 1–2 个语言与文化上相对熟悉的区域（东南亚或中东的英语授课酒店管理学院）。过早讲「服务全球院校」，会稀释产品迭代精力。

2 · 第一年：5–10 位教师深度试点的四阶段

阶段动作产出时限 / 门槛
0 · 样品先做 1 讲 AI 副驾驶样品：教学框架 + 案例讨论卡 + 小测 + 追问提示；跑通 8 项门禁与人工抽检1 讲样品 + 门禁报告 + 抽检记录样品未过门禁，不进入招募
1 · 招募通过学术社群与教学问题内容触达，找到 3–5 位愿意试点的教师；签《贡献者协议》与数据同意书试点名单（匿名 ID）+ 同意书不等主体注册、不等机构合同
2 · 一学期试点免费/极低价提供教学助手；每讲记录使用次数、门禁失败原因、教师反馈使用日志 + 三指标前后值 + 可公开引用证据若 3 位以上教师 4 周内未用进真实课堂 → 先改组件形态，不扩区域
3 · 证据与转化整理试点报告，取得公开引用同意；用试点教师推荐推动院系订阅试点效果报告 + 院系订阅报价单（B 轨）先选「有改革意愿的单一课程」，不全面铺开
顺序不可颠倒
样品 → 招募 → 试点 → 证据 → 订阅。材料给的是 12–18 个月的 B2B 周期，一人公司没有销售团队，所以必须让产品本身成为销售；这同时也是「先 1 个样品再谈批量」纪律在全球轨的落地。

5 · 试点数据表与同意书要点

字段组字段用途
标识pilot_id / teacher_id_hash / institution_type / region / track分组与脱敏，不收姓名邮箱明文入分析表
使用sessions_used / components_used / gate_fail_reason判断组件是否被真用、门禁哪里常失败
三指标pre_accuracy / post_accuracy / participation / prep_minutes_before / prep_minutes_after效果证据
同意consent_public_quote / consent_retention_days / delete_request公开引用与留存/删除
反馈notes / would_recommend / what_to_change迭代输入

同意书必须写明的五件事

  1. 采集的是聚合与匿名数据，不采集可识别学生信息；
  2. 用途限定于产品迭代与效果报告，不用于广告画像；
  3. 留存期限与到期删除路径（写明天数，不写「长期保存」）；
  4. 公开引用前须再次确认，且一律脱敏；
  5. 教师可随时要求删除自己的输入数据与本地参数。
跨境合规
PIPL（中国出境）／GDPR（欧盟）／FERPA（涉美院校学生记录）分别检查；用 Merchant of Record 承接跨境收款与发票，避免逐国注册主体。这五项已登记为待办 F-05，本轮只给清单不执行。

7 · 三年节奏与 stop rules（操作级）

阶段做量化门槛停止 / 转向条件
第 1 年1–2 个熟悉区域，5–10 位教师深度试点；同期以教学工具演示身份接触学术社群≥4 讲/人用进真实课堂；三指标有前后值若 3 位以上教师 4 周内未用进课堂 → 改组件形态，不扩区域
第 2 年复制到 2–3 个新区域；认证教师网络开始非主动扩张；案例库与轻量评估跟进院系级订阅客户 10–20 个（材料口径，作为内部目标）若续费率低于试点转化率一半 → 价值锚错了，回到备课负担本身
第 3 年+认证对齐产品化；评估是否需要外部合规/本地化协作按实际产能决定，不预设若现有模拟器厂商已补齐教师侧功能且免费 → 收窄到「口径校验 + 认证对齐」
防御不靠功能多
材料第三约束：hotellab 与 Cesim 完全可能向下兼容加教师侧功能。RMC 的防御是组织形态的不可模仿性——创始人直接维护、AI 驱动、按教师个体需求快速迭代；保持产品「小到不值得被复制」，同时用认证教师网络形成切换成本。一旦开始堆功能、建平台、招团队，这个优势就没了。
