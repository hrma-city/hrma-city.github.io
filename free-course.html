单元 1 · 收益管理是什么 · 酒店为什么离不开它（6 学时（讲 3 + 实训 3））

▾ 展开本单元：开场问题 / 讲什么 / 例子 / 实训

开场问题（照着念）：一间房挂牌卖 620 元，这 620 元是不是全赚进腰包了？

这一单元讲什么（轻量版）：

  1. 收益管理不是"降价促销"，而是把有限的房间在正确的时间、用正确的价格、卖给正确的人
  2. 三个核心指标：出租率＝已售房 / 可售房；平均房价 ADR＝房费收入 / 已售房；每间可售房收入 RevPAR＝出租率 × ADR
  3. 变动成本：每多卖一间房，真正多花的成本只有约 95 元（水电、易耗、布草），所以单间边际贡献＝卖价 − 95
  4. 四个适用条件：产能固定（房间数变不了）、需求会波动、客人能细分、房间能提前预售

一个简单例子：云璟酒店 300 间，出租率 68%、平均房价 620 元 → RevPAR≈421.6 元；每间边际贡献≈525 元。先记住这个数，后面全用它。

课堂 / 课后实训：用云璟 90 天数据，算出三个指标，并算一次单间边际贡献。

轻量版到这就够了：轻量版到这就够了：指标口径、结构分解、口径变更这些"深坑"先不碰——知道三个数怎么算、边际贡献怎么来，就能开课了。　｜　想深入 → 训练营 + 社群答疑

单元 2 · 怎么看未来有没有客 · 需求预测入门（6 学时（讲 3 + 实训 3））

▾ 展开本单元：开场问题 / 讲什么 / 例子 / 实训

开场问题（照着念）：距目标日还有 7 天，在手订单 180 间、目标 240 间，你是该紧张还是该淡定？

这一单元讲什么（轻量版）：

  1. 进度 Pickup＝在手订单 − 去年同期在手，看"比往年多还是少"
  2. 进度偏差＝在手订单 − 目标，看"离目标还差多少"
  3. 判定表（表 A）：横行是预测的出租率，纵列是进度偏差，交叉格就是当天的动作（涨 / 降 / 不动）
  4. 台账记三件事：改了什么、依据哪张表、谁批的——留痕比聪明更重要

一个简单例子：对着一张表 A，读出"预测出租率 85%、进度落后 10%"那一格，动作是什么？先读出来，再想为什么。

课堂 / 课后实训：画一条未来 7 天进度线，标出哪一天开始明显偏离，再连续查 3 天表 A 练手。

轻量版到这就够了：轻量版到这就够了：取消率、No-show、预订曲线、预测偏差归因先放一放——会读表 A、会画进度线，学生已经比大多数从业者懂行了。　｜　想深入 → 训练营 + 社群答疑

单元 3 · 房价怎么定才不亏 · 价格体系（6 学时（讲 3 + 实训 3））

▾ 展开本单元：开场问题 / 讲什么 / 例子 / 实训

开场问题（照着念）：高级房卖 620 元，行政房该卖多少？凭感觉定，还是有一套锚？

这一单元讲什么（轻量版）：

  1. BAR（最优可售房价）是所有价格的"锚"，其他房型价格都围着它转
  2. 房型价差是一套体系（阶梯），不是随手拍脑袋
  3. 打平量＝降价损失的收入 ÷ 单间边际贡献；注意分母是边际贡献 525，不是卖价 620
  4. 价格一致性红线：同一房型同一日期，各渠道价格必须一致

一个简单例子：淡日想直降 40 元冲量：先算打平量＝"少收的 40 元 × 要多卖几间"÷ 525，算出来不划算就改打包，不破价格锚点。

课堂 / 课后实训：做一次房型价差体检：列出你校合作酒店的各房型价格，看价差合不合理。

轻量版到这就够了：轻量版到这就够了：团队底线（机会成本）、时长控制、含早打包这些进阶玩法，留到训练营再讲——先把"降价前先算打平"这根弦绷上。　｜　想深入 → 训练营 + 社群答疑

单元 4 · 满了怎么办 · 空着怎么填 · 库存与限制条件（6 学时（讲 3 + 实训 3））

▾ 展开本单元：开场问题 / 讲什么 / 例子 / 实训

开场问题（照着念）：高级房卖完了，前台却来问"还有没有便宜房可以给这位客人"——给，还是不给？

这一单元讲什么（轻量版）：

  1. 房型保护：给高价房型留量，不是有房就卖，低级房满了对高级房是保护
  2. 最低住店天数：满房日用来挡掉"住一晚就走"的低价短单
  3. 超售三步：基准取消率 → 乘修正系数 → 换算成可超售间数，且必须有过硬上限
  4. 免费升级四级排序：会员等级 → 连住天数 → 房态余量 → 到店顺序

一个简单例子：一个满房日场景：高级房剩 5 间、行政房剩 2 间，散客还想订高级房——先保护哪间、放不放低价单？

课堂 / 课后实训：给一个满房日，决定各房型保护量与最低住店天数，再排一次免费升级顺序。

轻量版到这就够了：轻量版到这就够了：walk（到店无房）处置话术、团队置换的机会成本先不展开——守住"保护高价房、超售有上限"两条，就不会出大错。　｜　想深入 → 训练营 + 社群答疑

单元 5 · 渠道怎么选 · 对手怎么看 · 渠道与竞争（6 学时（讲 3 + 实训 3））

▾ 展开本单元：开场问题 / 讲什么 / 例子 / 实训

开场问题（照着念）：同样 620 元，走 OTA 要被扣 15% 佣金，走官网不扣但量少——哪个更赚？

这一单元讲什么（轻量版）：

  1. 净收入＝卖价 ×（1 − 渠道成本率）；比渠道要比"净的"，不是比挂牌价
  2. 价格一致性红线：同房型同日期各渠道同价，每天核查
  3. 竞组三个"同"：同档次、同商圈、同客源，才叫可比对手
  4. 三个指数：MPI 看量、ARI 看价、RGI 看综合竞争力

一个简单例子：620 元走 OTA（扣 15%）净收 527 元；走官网净收 620 元。差 93 元——这就是为什么要做直销。

课堂 / 课后实训：建立本店竞组名单（5 家），写清每家为什么可比或不可比；算一次 MPI / ARI / RGI。

轻量版到这就够了：轻量版到这就够了：直销提升三招、竞对跟价三步先不细讲——会算净收入、会建竞组名单，渠道与竞争就不懵了。　｜　想深入 → 训练营 + 社群答疑

单元 6 · 一学期下来怎么证明你教对了 · 综合实训与汇报（6 学时（讲 3 + 实训 3））

▾ 展开本单元：开场问题 / 讲什么 / 例子 / 实训

开场问题（照着念）：月度经营会：RevPAR 涨了 3%，可经营毛利却跌了 1%。总经理问"为什么"——你答得上来吗？

这一单元讲什么（轻量版）：

  1. 量价拆解：先分清是人少了还是价低了，再谈渠道结构
  2. 一页纸六板块：结论 → 结果 → 原因 → 风险 → 动作 → 需要的决定
  3. 四维量规：依据正确性 / 留痕完整性 / 经营解释 / 可执行性——只看依据，不看文采
  4. 汇报的终点是"要一个决定"，不是把过程讲完

一个简单例子：用上面那句话做 5 分钟演练：先给结论（价涨量跌），再给原因和要批的动作。

课堂 / 课后实训：交一份《收益诊断报告》+ 一页纸汇报版，按四维量规自评。

轻量版到这就够了：轻量版到这就够了：整学期的数据建模、滚动预测先不碰——能让学生用一页纸讲清"为什么"，这门课就算教对了。　｜　想深入 → 训练营 + 社群答疑
