一、项目名称与摘要

项目名称：基于"岗课赛证"融通的酒店收益管理课程建设与校赛平台共建项目

申报单位：×× 学院 / 系　负责人：×××　　建设周期：× 学年

本项目面向酒店管理与数字化运营等相关专业，解决收益管理课程"缺师资、缺实操、缺评价、缺成果"的开课难题。以一套成体系的课程资源（41 章教材、84 课时）为基础，引入可自动化判分的校赛平台，将课堂教学、校内竞赛、达标评价与岗位能力标准贯通：教师照章授课、学生以赛代练、成绩按统一阈值生成 L1–L3 能力等级与校本达标证明，作为课程学分认定与拟对接 1+X 的过程性佐证（认定以本校教务为准），企业以真实岗位任务反推培养标准。项目建成后形成"课—赛—证—岗"闭环，产出可核查的课程档案、竞赛成绩、达标证明台账与专业建设佐证材料，为人才培养方案修订、教改项目结项与专业评估提供支撑。

关键词：岗课赛证融通；收益管理；产教融合；校赛平台；1+X；课程学分认定

二、建设背景与依据

2.1 政策口径

对接国家关于深化现代职业教育体系建设改革、推进"岗课赛证"融通与 1+X 证书制度试点、深化产教融合与校企合作的要求，鼓励院校引入行业标准和真实岗位任务，推动课程内容与职业标准、教学过程与生产过程、学历证书与职业技能等级证书相衔接。报送前补本地对应文件与文号。

2.2 行业背景

收益管理是酒店经营的核心职能，其决策高度依赖数据（入住率、平均房价、可售房量、渠道结构、细分客群），行业已形成以指标判读、预测、动态定价、库存保护、超售控制、渠道管控为主的标准化作业方式。与传统服务技能相比，收益管理决策的结果可由数字直接验证，因而具备客观判分条件，适合以竞赛形式检验教学成效。

2.3 院校现实

需说明的是，酒店数智经营类竞赛平台已有第三方厂商提供，本项目不重复建设平台，定位为课程内容、判分标准与课证融通方案的共建，与既有平台互补。

酒店管理专业普遍开设前厅、客房、餐饮等实操课程，但收益管理多作为章节附带内容，缺少独立课时、可用教具与可核查的评价手段；教师缺乏企业决策场景，学生难以获得"做一次定价并看到结果"的训练；专业建设成果亦缺少可量化的竞赛与证书支撑。

三、现存问题（三个断点）

断点具体表现本项目对应解法
开课难无独立课纲、无配套教材与教案，教师需自行开发；概念抽象（置换分析、保护位）难讲清直接引入成体系教材与教案（41 章 / 84 课时 / 配套判定项），教师零额外备课；难点用可视化与动画补齐
办赛难旅游类专业竞赛多为人工评分（导游、摆台），组织成本高、难规模化；收益类竞赛无固定规程引入赛项库（16 赛项，覆盖理解—决策—论证—抗压），决策类由模拟器自动判分；初赛线上机评、决赛现场联网
评价难课程成绩与职业证书、学分认定不互通；学生参赛成果无法折算，教务缺认定依据按统一阈值出具 L1–L3 达标证明，配套编号规则与台账，作为课程模块学分认定与拟对接 1+X 初级考核的过程性佐证

四、建设目标

总目标：建成一门能稳定开出、可客观评价、有竞赛与证书产出的收益管理课程，并形成可复制的专业建设成果包。

五、建设内容与实施路径

5.1 四个环节（课—赛—证—岗）

  • 课：以 41 章教材与教案为主体排课，按「指标 / 预测 / 定价 / 库存 / 渠道 / 运营」六大模块组织教学；难懂概念配动画，缺实操的部分用模拟对抗带练。
  • 赛：按赛项库选题组赛，A 类（理解）机评做海选、B 类（决策）模拟器自动判分做主赛、C/D 类（论证、抗压）用于决赛与展示；组织者按执行清单 T-30 推进。
  • 证：成绩达阈值出具 L1–L3 校本达标证明，编号连续、台账归档；作为「收益管理实务」课程模块学分认定与拟对接 1+X 的过程性佐证，认定以本校教务与考核站点为准。
  • 岗：与共建酒店把真实岗位任务反推为能力标准，形成岗位能力图谱，服务人才培养方案修订与实习就业衔接。

六、创新点

  1. 判分客观化。收益管理决策结果可用数字验证，决策类赛项由模拟器自动判分，避免人工评分主观性与高组织成本，使校赛可规模化、可常态化。
  2. 课程与竞赛同源。教材章节与赛项、能力等级逐条映射，教师按同一张表授课、出题、评价，不增加备课负担；比赛不是课外活动，而是课程的评价环节。
  3. 成果可核查。成绩、证书编号、验真码、签发台账全程留痕，直接成为教改结项与专业评估的佐证材料，解决"建设成果说不清"的常见痛点。
  4. 标准共建而非单次采购。院校作为标准共建单位参与反馈与署名，数据与成绩归院校、不锁定，合作可随时退出，降低长期依赖风险。

十一、结论（可直接引用）

本项目以成体系的课程资源与可自动判分的校赛平台为切口，把收益管理从"难开、难评、难出成果"的章节内容，建设为覆盖课程、竞赛、证书与岗位标准的教学闭环。建设周期内可稳定开出课程、常态化举办校赛、按统一标准出具达标证明并支撑学分认定，全过程留痕、成果可核查，可直接支撑人才培养方案修订、教改项目结项与专业评估。项目投入集中在资源与平台服务，不新增实训场地与大型设备，组织成本可控，具备在同类院校推广复制的条件。
