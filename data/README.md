## 生成逻辑

1. **OCC** = 月度基准 × 需求倍率 × 星期权重 × 随机噪声(0.94–1.06)
2. **ADR** = 月度基准 × 需求倍率(弱化 0.55) × 星期权重(弱化 0.5) × 噪声(0.95–1.05)
3. **需求等级** D1/D2/D3/D4 由事件表 + 节假日 + 月份 + 星期几共同决定
4. 餐饮收入 = 客房收入 × (0.50–0.62)，D1 日再 ×1.18
5. 03 号文件刻意混合「领先 / 落后 / 持平」三种进度，覆盖《法典》表 A 的各个格子
6. 04 号文件按 ARI 分四段循环（偏高 / 偏低 / 略低 / 健康），覆盖表 C 的七档判定

## 交叉验算（学员自查用）

拿到任何一份报表，先用这三条验一遍，对不上就是脏数据：

- `已售房晚 = 可售房量 × OCC`
- `客房收入 = 已售房晚 × ADR`
- `RevPAR = OCC × ADR = 客房收入 ÷ 可售房量`
