两条路径，各走各的：学生按教材走——开篇 + 五篇三十二章，每章「读 → 练 → 用」， 收尾是教材自带的综合实训与自测题库；酒店人按认证模块走——M01–M14，按 L1 执行专员 → L2 主管 → L3 经理 三级递进，每模块「学 → 用 → 练 → 考」，直接对接考级。 内容同出一源，但编排顺序完全不同：一条照教材的篇章结构，一条照职业能力的级别结构。走一条就够。

教材和模块是什么关系（最容易被弄混的一点）：两者讲的是同一套知识，但服务不同的人。教材（三十二章）是学生的读物，按学科逻辑从原理讲到执行；模块（M01–M14）是酒店人的职业认证路径，按 L1 执行专员 → L2 主管 → L3 经理三级递进，每个模块标了课时与认证权重，学完直接报考对应级别。两条路径的站号大体对应（第 N 站 ↔ 教材某章），教师备课两边都能参照，但读者各走各的，不必互相看。

怎么用这一页：学生路径每一章三步——读教材这一章；练章末练习（答案在附录 B）； 用配套工具（概念章没有工具，就不显示）。每篇开头有一句说明这一篇在解决什么。 做完点「标记完成」，进度存在您这台设备上。教学顺序＝教材顺序，不必另找大纲。
