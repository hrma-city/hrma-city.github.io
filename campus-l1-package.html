L1 校赛达标包：开课 + 办赛 + 达标评价 一站式方案

按 课赛证映射大表，把 L1 初级对应的赛项打包成一套院校可直接落地的达标包：A 类全（A1–A4）+ B1/B2/B4。教师照章上课、照表办赛、照线出具达标证明，零额外备课。配套 B1 正式赛项页 可直接开赛。

口径声明（2026-11-04 统一修订）：本页出现的 L1/L2/L3 是 RMCity 自建能力等级；「证书 / 发证 / 证书线」均指校本达标证明及其能力刻度，不是 1+X 酒店收益管理职业技能等级证书（北京三快在线科技 / 美团颁证，标准代码 540002），也不等同其初 / 中 / 高级。学分认定、1+X 与学分银行换算一律为拟对接，以本校教务部门与 1+X 考核站点正式认定为准。详见 统一口径说明 与 1+X 逐条映射大表。

一、达标包范围（L1 初级含哪些赛项）

L1 = 理解（能算、能辨）+ 基础决策（能下基础定价/保护位/渠道决策）。共 7 个赛项，全部机评、可规模化。

二、校赛流程（初赛线上 · 决赛现场联网）

① 报名门内链接 / 校本 LMS 发布，统一身份进入
② 海选（线上·机评）A1–A4 客观题 + B1 模拟初赛，平台自动判分晋级
③ 决赛（现场联网）机房统一账号实时联网，B1 正式赛项 + B2/B4 选做
④ 达标证明按阈值出具 L1 达标证明，成绩作为拟对接 1+X 的过程性佐证
现场联网而非纯现场：初赛线上广覆盖、降成本；决赛现场联网保证公平监督，平台判分 + 裁判复核可疑告警——与赛事引擎总览定的路径一致。

三、L1 达标规则与拟对接路径

准入线A 类（A1–A4）每项正确率 ≥ 70%，且至少 1 项决策类（B1/B2/B4）综合得分 ≥ 60（同 B1 正式赛项 L1 线）。
能力等级仅 L1 初级（自建刻度）；决策类综合分 ≥ 80 可一并记录 L2 潜力，待升 L2 赛项补证。
学分认定（拟）L1 达标可作为"收益管理实务"课程模块的过程性评价佐证；是否免重复考核、抵多少学分，由本校教务认定。
拟对接 1+XL1 模块与 1+X 酒店收益管理初级考核的能力范围已逐条对标（见 映射大表）；是否换算、如何换算由考核站点认定，不自动成立。

四、组织者一键清单

1在 B1 正式赛项页 编排台建赛事实例：名称 / 级别（校赛）/ 评分权重（默认 60/40）/ 能力等级线（L1=60, L2=80, L3=92；自建刻度，非 1+X 分数线）。
2发布报名入口（门内链接或校本 LMS），统一身份认证进入。
3海选：开启 A1–A4 客观题 + B1 模拟初赛，平台自动判分，按比例晋级。
4决赛：安排机房、统一账号、现场联网；B1 正式赛项开赛，B2/B4 选做。
5完赛后"导出全部成绩 CSV"交教务；按阈值核验 L1 名单。
6出具 L1 达标证明（拟对接教务 / 1+X，以本校认定为准）；赛项数据反哺下一轮教学。

五、这套包为什么院校容易采用

教材（41 章）已经在了，赛项规程、判分引擎、证书标准都齐了——院校要做的只是"把课表和赛程排进去"。教师零额外备课、教务有过程性评价佐证、学生有达标证明可拿、企业有标准可认。你（RMCity）持续收订阅 + 办赛/内容增值。
