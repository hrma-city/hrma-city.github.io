校赛达标证明电子模板：粘贴成绩，批量生成

配套 B1 正式赛项页 与 首场校赛执行清单。赛后把导出的成绩 CSV 粘进来，系统按分数线自动判级、生成证书编号与验真码，一键打印或导出签发台账。本页生成的是校本达标证明版式，非国家职业技能等级证书；经院校盖章、教务备案后方可作为校内过程性评价材料。

口径声明（2026-11-04 统一修订）：本页出现的 L1/L2/L3 是 RMC 自建能力等级；「证书 / 发证 / 证书线」均指校本达标证明及其能力刻度，不是 1+X 酒店收益管理职业技能等级证书（北京三快在线科技 / 美团颁证，标准代码 540002），也不等同其初 / 中 / 高级。学分认定、1+X 与学分银行换算一律为拟对接，以本校教务部门与 1+X 考核站点正式认定为准。详见 统一口径说明 与 1+X 逐条映射大表。

一、字段规范（与成绩导出对齐）

B1 正式赛项页「导出全部成绩 CSV」的字段可直接粘贴，无需改格式。

列字段说明
1姓名持证人姓名，与报名身份一致
2院校参赛院校全称
3学号用于教务存档与学分认定核对（认定以本校教务为准）
4赛项如 B1 动态定价决策（校赛）；达标包可写 L1 校赛达标包
5综合得分0–100，判级依据
6净 RevPAR可选，印在证书上作成绩佐证；缺失留空即可
首行为表头时会自动跳过；允许只填前 5 列。低于 L1 线的选手不生成达标证明，单列进「未达标名单」，避免误发。

二、签发规则

判级综合得分 ≥ L3 线 → L3 高级；≥ L2 线 → L2 中级；≥ L1 线 → L1 初级；低于 L1 线不出具证明。默认 60 / 80 / 92 为自建能力刻度，非 1+X 分数线，与 编排台能力等级线 一致，可现场调整后重新生成。
达标包口径若使用 L1 校赛达标包，除综合得分外还需 A 类（A1–A4）每项正确率 ≥ 70%、且至少 1 项决策类（B1/B2/B4）≥ 60；组织者在签发前按 L1 准入线复核。
编号RMC-年份-级别-四位序号，如 RMC-2026-L1-0001。编号连续、不重号，作废须留痕不复用。
验真每证附 6 位验真码，由「姓名＋编号＋得分」生成，供院校自查与用人单位核验。正式部署时改由赛事引擎后端签发、落库、提供在线验真页。
学分（拟）L1 达标可作为「收益管理实务」课程模块的过程性评价佐证；是否抵学分、如何换算 1+X 与学分银行，由本校教务与 1+X 考核站点认定。能力等级与 课赛证映射大表 的 L1/L2/L3 一致。

三、批量签发台

打印时用浏览器「打印 → 另存为 PDF」，每张证书自动独占一页；建议横向、勾掉页眉页脚。

四、编号与台账

生成后台账须归档，作为过程性评价、拟对接 1+X 与专业建设的佐证材料；学分认定以本校教务为准。

项目规则
编号结构RMC-2026-L1-0001：RMC 固定前缀 / 签发年份 / 级别码 / 四位流水号
台账字段证书编号、姓名、院校、学号、赛项、综合得分、证书级、净 RevPAR、签发日期、验真码
存档院校教务处存 CSV + 证书 PDF 一份；RMC 存签发记录用于标准共建统计（成绩数据归院校，不锁数据）
作废填错不删号，标记「作废」并注明原因，流水号不复用
复核签发前由组织者核对身份与 L1 准入线，签发后公示 3 个工作日再报教务

五、边界与正式落地

本页是模板与生成样式演示。所生成的证明在无院校盖章、未备案前不构成正式资格证明，且不是 1+X 职业技能等级证书。正式落地需：① 院校审定证书样式与署名；② 教务/继续教育部门备案并纳入学分认定目录；③ 对接 1+X 考核站点完成模块映射；④ 由赛事引擎后端签发、生成在线验真页与可核验二维码。
这也是给试点院校的交付物之一：证书样式、编号规则、台账格式三件事一次给全，院校不用从零设计。配套见 试点 MOU 模板（达标证明与学分拟对接条款）与 执行清单（T+3 签发、T+7 导出）。
