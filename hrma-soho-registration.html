个体工商户注册实操清单

用途：作为「收益管理教学平台 / 教材工具包 / 师资陪跑」的经营与开票主体 ｜ 零成本、线上办、1–3 天 ｜ 本清单仅作操作参考，具体以本省政务服务网口径为准

★ 结论：个体户注册现在就可以办。登记费全免、全程网办、立等可取（2026-05-01 起全国统一新规）。它只是给你一个能开票的主体，不绑定任何后续消费；唯一后续义务是季度零申报（免费、几分钟）。

一、为什么现在办（而不是等用户）

  • 零成本：登记费全免，执照免费邮寄，多数地区经营场所免提交证明（住所承诺制核验通过即免）。
  • 零风险：不开办、不买平台、不接任何付费，只是先拿一个主体资格。
  • 去掉成交摩擦：第一所学校问价时，你当天就能开「咨询服务费 / 技术服务费」发票签约，不用临时跑流程。
  • 能量友好：这是一次性「产品型」动作，不是持续运营，不触发「看到待办就累」的放弃机制。
  • 注：真正要「等验证再花」的是小鹅通专业版 ¥12,800/年，不是这个免费主体。

二、注册渠道（线上最快）

  • 本省的 政务服务网 / 政务服务 APP（如粤省事、浙里办、天府通办、豫事办、皖事通、随申办等）。
  • 搜索「个体工商户设立登记」→ 选择「全程电子化」→ 填写表单 → 电子签名 → 等待执照邮寄。
  • 无需跑窗口，一般 1–3 个工作日（部分地区立等可取）。

三、经营场所（你没有实体店怎么填）

  • ① 自有 / 租赁住宅：根据《湖北省经营主体住所登记管理规定》第八条，住宅作经营场所原则上需「住改商」——经利害关系业主一致同意（物业/业委会同意书）。武汉2026年对纯线上轻业态（电商、技术咨询、管理咨询）放宽，核准率>90%，但各区尺度不一：光谷等签《经营场所自主申报承诺书》即可，江汉/武昌部分老小区仍需业委会说明。黄陂区等具体口径请以「湖北政务服务网/鄂汇办」提交时的材料清单或窗口答复为准。租房还需准备租赁合同+房东产权证复印件。
  • ② 地址托管 / 集群注册：部分园区、孵化器免费提供注册地址（需签托管合同，不走住所承诺制），适合纯线上业务，且长期稳定、免搬家变更麻烦。
  • 不建议走「电商平台网络经营场所」那条（小鹅通不算典型电商，易混淆），用住宅或托管最稳。
  • 📝 住所申报承诺制怎么走：在「鄂汇办 / 湖北政务服务网」填个体户设立、录入地址后，系统若支持会弹出「是否采用住所申报承诺制」勾选项，勾选并签《经营场所自主申报承诺书》即免交房产 / 租赁证明。⚠️ 但住宅通常不适用承诺制（武汉仅光谷等少数区对科技轻创业放宽），盘龙大道44号是住宅，系统大概率不给勾选，需走住改商 + 租赁 / 产权证明；以提交时系统提示为准。承诺书须如实填写，虚假申报会被列异常名录。

三-B. 住改商 vs 托管：到底怎么选（决策表）

租住宅走「住改商」看似省事，实则把注册押在别人（房东+邻居）肯不肯配合上；托管地址本就是商用登记址，零人际摩擦。按摩擦从低到高：

方案要房东同意？要住改商/邻居？材料摩擦
① 托管地址❌ 不用❌ 不用托管合同最低
② 鄂汇办看黄陂区是否开放住所承诺制仅需租赁合同若弹勾选，签个字即过申报承诺书低（看系统）
③ 租房住改商✅ 要（给产权证复印件）✅ 要（业委会/邻里同意）租赁+产权+住改商证明最高
📌 实操建议：先在「鄂汇办」提交个体户设立、选黄陂区（盘龙城所），看系统弹不弹「住所承诺制」勾选——弹了，租房签个字就过（最简）；没弹，别去求房东搞住改商，直接走商务秘书托管（¥1,000–3,000/年，包工商注册+信件代收），花钱买断摩擦，最省心。武汉可选：E智谷孵化器（免费注册地址，东西湖）、江岸区 OPC 空间（低成本，高校师生）、光谷园区集中登记地。

四、经营范围（关键坑 · 决定要不要办学许可）

⚠ 核心原则：你的交付是「收益管理教学平台登录权 + 教材/工具包 + 师资陪跑咨询」，本质是教育咨询 + 信息技术服务 + 知识产品。客户是高校教师/院校，不是给中小学生开培训班，也不发国家认可的职业证书。因此不需要办学许可证——只要经营范围守在「咨询/技术服务」内、不开展系统性面授发证。

✅ 建议写入（直接复制，无需任何教育资质）

  • 教育咨询服务（不含涉许可审批的教育培训活动）
  • 信息技术咨询服务
  • 软件开发
  • 信息咨询服务（不含许可类信息咨询服务）
  • 技术服务、技术开发、技术咨询、技术交流、技术转让、技术推广
  • 市场营销策划

❌ 千万别写（会触发《办学许可证》）

  • 培训 / 教育培训 / 职业技能培训（发证） / 营利性民办培训机构
小鹅通入驻时，若类目审核问到「是否开展教育培训」，回答口径：提供的是「教材、工具包与教学咨询指导」（知识产品+咨询），非办学，不开展许可类教育培训活动。

五、注册后必做：税务报到 + 数电票（给学校开票用）

  • 30 日内税务报到，核定为小规模纳税人（季度销售额 ≤30 万免增值税）。
  • 申领数电票（税务 UKey 免费），即可给学校开「咨询服务费 / 技术服务费」发票走账——这正是你卖给院校的硬需求。
  • 银行对公户：个体户不强制开；但学校走账建议有（或用经营者个人账户 + 规范申报），看学校财务要求。

八、操作清单（照着勾）

  • 1确定经营场所：住宅（备房产证/租赁合同）或园区托管地址。
  • 2想好字号（如「XX 市 XX 教育咨询工作室」），准备 1–3 个备选名。
  • 3登录本省政务服务网/APP → 搜「个体工商户设立登记」→ 全程电子化。
  • 4复制第四节「✅ 建议写入」的经营范围文本粘贴（删掉 ❌ 项）。
  • 5电子签名 → 提交 → 等执照邮寄（1–3 天）。
  • 6领照后 30 日内税务报到，核定小规模，申领数电票。
  • 7记日历：每季度零申报 + 每年工商年报。
