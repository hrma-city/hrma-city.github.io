情境导入

你一定踩过的坑

周六是旺季，只剩 6 间房。一个客人只订周六一晚，付 800 订走了。

周日晚上这 6 间全空着——因为周六一晚的客人把"周六+周日"的连带需求挡在了门外。

如果当时要求"最少住两晚"，周六和周日都能卖掉，两晚合计收入更高。

更妙的是：这个动作完全没有提价。客人看到的还是一个价格，只是多了一个条件。这就是可得性控制的威力。

三要点怎么用（各配一例）

  • MinLOS（最少住几晚）：要求客人至少连住 N 晚，把"住一晚就走"的需求挡掉，把房留给连住客。
  • CTA / CTD（关闭到达 / 关闭离店）：CTA 不让某天入住（保护从前一日开始的连住）；CTD 不让某天离店（保护向后延伸的连住）。
  • 这是可得性控制，不是涨价：客人感知不到"被宰"，只是多了个条件——比直接提价温和得多，也不伤口碑。
  • MinLOS——例：周六满房、周日空 → 设"最少住 2 晚"，把周六的客顺延到周日，两晚都卖出。
  • CTA——例：周日不允许"入住"（但允许从周六连住过来）→ 保护从前一日开始的连住客。
  • CTD——例：周五不允许"离店"（要求住到周六）→ 把周五的客延伸到旺季的周六，提升整体收益。

核心判据

设置限制的条件： 当「单晚客的边际收益 < 保住连住客的期望收益」时启用 MinLOS → 挡掉只住一晚的客 CTA → 不让某日入住（保护从前面开始的连住） CTD → 不让某日离店（保护向后延伸的连住）
算例 1（该设）：周六剩 6 间。客人 A 只住周六，付 800。客人 B 想住周六+周日，愿付 750/晚 × 2 = 1,500。
接受 A：收入 800，周日大概率空房。
设 MinLOS=2：A 被挡（或改订两晚），B 成交 1,500。
1,500 > 800 → 设 MinLOS 划算。

算例 2（不该设）：若周日也是满房日（同样紧俏），则不必设——因为不愁卖，连住客的价值优势消失。
结论：MinLOS 的价值来自"前后日需求不对称"。前后都旺，就没必要设。

算例 3 · 三种限制的选择

场景：周五空、周六满（演唱会）、周日空 ① MinLOS=2（周五起）→ 周五+周六连住，填满周五 ② CTA 周日 → 周日不能单订，只能从周六连住过来 ③ CTD 周五 → 周五入住的客必须住到周六
正确组合是 ① + ②：周五设 MinLOS=2（连带周六），周日设 CTA（只接周六连住过来的客）。
这样三个晚上串成一条"两晚"的产品，把原本会空置的周五和周日都带动起来。
CTD 在这里反而不必要——它会限制周五入住的客人，减少订单。

案例三 · 限制条件的"剂量"
某店第一次用 MinLOS，直接设了 3 晚。结果 pickup 暴跌 55%，被迫撤回。
第二次改为 MinLOS=2，pickup 仅降 8%，而周日出租率从 35% 升到 68%。
结论：限制条件也有剂量。从最轻的开始（2 晚），观察反应，再决定是否加码。一步到位往往把客人吓走，而且你无法判断"是条件太重，还是方向错了"。

活动后：撤除 MinLOS 与 CTA（关键：别忘了撤）；复盘实际系数。
结果：周五出租率从平日的 45% 升到 88%，周日从 35% 升到 70%；周末三天 RevPAR 比去年同期高 42%。
结论：限制条件的价值不在"设"，而在"提前设 + 各渠道一致 + 事后撤除 + 复盘"。四个环节缺一，效果就打折。

反面案例 · 案例二 · 设错了的一次
某店在平季周三设 MinLOS=2，结果 pickup 立刻下滑 40%。
原因：周三并非紧俏日，连住客的期望收益并不高于单晚客——条件无的放矢，只是把客人赶走。 撤掉后恢复正常。 结论：限制条件是稀缺性工具，只在紧俏时用。滥用会直接损失订单。

一页带走

  • MinLOS（最少住几晚）：要求客人至少连住 N 晚，把"住一晚就走"的需求挡掉，把房留给连住客。
  • 这是可得性控制，不是涨价：客人感知不到"被宰"，只是多了个条件——比直接提价温和得多，也不伤口碑。
  • MinLOS——例：周六满房、周日空 → 设"最少住 2 晚"，把周六的客顺延到周日，两晚都卖出。
  • CTA——例：周日不允许"入住"（但允许从周六连住过来）→ 保护从前一日开始的连住客。
  • 核心判据
    设置限制的条件： 当「单晚客的边际收益 < 保住连住客的期望收益」时启用 MinLOS → 挡掉只住一晚的客 CTA → 不让某日入住（保护从前面开始的连住） CTD → 不让某日离店（保护向后延伸的连住）
  • 是否紧俏日是（预计满房）→ 可设；淡季 → 不设（会吓跑客人）
  • 单晚客 vs 连住客连住客期望收益更高 → 设 MinLOS 保护
  • 剩余房量剩余 ≤15% → 设；剩余充足 → 不设
  • 前后日是否也紧俏前一日也紧俏 → 用 CTA；后一日也紧俏 → 用 CTD；只有本日紧俏 → 用 MinLOS
