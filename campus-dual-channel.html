双通道商业模式总图：把"资料挂网上"做成第三条路

你后怕的根源是「要帮老师教到能抄作业，中间得补一堆」。纯货架会把这堆甩回给老师、纯定制又扛不住边际成本。结论是：不二选一——用货架做获客与分流，用平台和服务做续费锚点。

一、你后怕的根源，拆开看

不是你不行，是这个生意的"交付深度"和"生产成本"天然冲突。

为什么纯货架会重蹈祖长生
  • 你后怕的那堆——出卷、评卷、申报、磨课、人培、评估——纯货架全甩回给老师，老师更教不动 → 差评、无复购。
  • 货架比卖包更不续费：卖包好歹有个年费钩子，纯货架买完即走，连钩子都没有。
  • 你刚建的 L3 六类服务若每单手写，规模化必死；纯货架是彻底放弃这部分收入。
但你的直觉也对：重定制生产确实扛不住
  • 41 章 × 861 条判定项 × 6 类服务，如果为每位老师单独生产，第 10 所就会崩。
  • 所以正确结构不是"货架 vs 服务"二选一，是让货架替你分流。

二、第三条路：货架 + 升级

生产一次、无限卖的轻件挂上去（货架）；每页留升级钩子；大多数老师自助（你零边际成本），少数真卡住的升级到年费/L3，你才介入，且是标准化服务不是纯定制。

① B 端通道 · 院校整包年费

¥2.8 万起 / 年（基础档）
  • 客群：学校采购（教研室 / 教务处）
  • 产品：L1 教学包 + L2 平台 + 可选 L3 服务 / L4 共建
  • 续费点：学期末"一键复制班级" + 学情报告
  • 你介入：重（首年建课、培训、服务）
  • 预算科目：软件服务费 / 师资培训费 / 教改专项

② C 端通道 · 教师自助货架

¥99 起 / 章包（持续访问权）
  • 客群：个体老师、青年教师、跨专业兼课
  • 产品：单章包 / 模块包 / 篇包 / 全套（=教学包）
  • 续费点：季度教材更新 + 数据模板同步 + 社群答疑
  • 你介入：轻（系统化、不一对一）
  • 支付：微信 / 支付宝自主下单，零销售成本
两通道互相导流：C 端老师用爽了 → 推荐学校买年费；B 端学校采购后 → 学生/兼任老师个人也想补某章⇅同一个人可能先 C 后 B，或同时是两头的用户

四、货架怎么拆（按你已有的 41 章）

拆得越细，老师越能"按需选"，你也越不用为谁单独生产——因为已经生产好了。

货架单元包含建议价对应需求
单章包1 份教案 + 该章判定表 + 1 个课堂案例¥99"这章我讲不熟，单买"
模块包4 章一组（如定价决策 CH05–08）¥299"这块我全要补"
篇包一篇 4–12 章（如认知篇 CH01–04）¥499"整篇体系化地学"
全套 41 章= L1 教学包（含模板+数据+判定表合集）¥2,980"我要整个包"
数据模板包三套模拟数据 + 计算器 Excel¥199"我只想要能跑的数据"
关键设定：货架卖的是持续访问权，不是文件所有权。在线可读 + 每季度随教材版本更新 + 社群答疑 + 数据模板同步更新——这些才是能年年收钱的理由。纯 PDF 下载是死货架，别走那条。

五、续费分别发生在哪

B 端续费：锁在学期节奏里。建课发码 → 派练习 → 课堂对抗 → 期中组卷 → 期末成绩 → 学情报告 → 一键复制上学期班级。第 7 步就是续费按钮。绝大多数教育产品死在第 6 和第 7 之间：期末拿不出报告，下学期又要重来，老师开始想"换个平台"。
C 端续费：锁在"更新+社群"。教材每年改版、OTA 政策每半年变、数据模板随真实经营迭代。老师买的是"我的教案永远不过时"，不是"一份静态文件"。季度更新邮件 + 社群答疑，就是 C 端的续费提醒。
