这一级具体怎么跑

收益管理不是「每月大调一次价」，而是每天 15 分钟的小心看护。今天的 15 分钟，决定了一周、一月、一年的结果。这一页把「每天到底干什么」拆成 4 张牌，照着走就行。

操作步骤 · 4 个

一张牌一个动作

每个动作沿用同一套结构：先讲你会踩的坑，再讲怎么做、给公式、给今天就能做的动作、给工具。

动作 1
早盘三看（9:00 · 5 分钟）　在手可售 / Pace / 竞品
⚠ 别踩这个坑：只盯 OTA 后台的「今天剩几间」，不看 Pace、不看竞品，结果永远慢半拍。

怎么做

开盘先看三样：①在手可售 = 总房量 - 已确定性预订 - 已锁房；②Pace = 本期至今预订量 ÷ 去年同期；③竞品今日牌价（同类型 3 家）。三样并排，一眼知强弱。

在手可售 = 总房量 - 已确定性预订 - 已锁房

今天就能做的动作

固定 9:00 开盘；三数写进每日巡检表；竞品只盯 3 家同档

🛠 工具：预订进度Pace表 / 每日巡检表　·　📄 在线预览　·　⬇ 下载Excel
动作 2
触发判断树（5 分钟）　三维 → 提价 / 不动 / 促销
⚠ 别踩这个坑：凭感觉「今天应该涨一点」，没有判断树，涨错方向比不涨更糟。

怎么做

按三维走：在手<基线 且 Pace<0.9 → 该促销；在手>基线 且 Pace>1.1 且 竞品未降 → 该提价；其余 → 不动。三条件满足≥2 才动，否则保持。

提价触发 = (在手>基线) ∧ (Pace>1.1) ∧ (竞品≥我) ；促销触发 = (在手<基线) ∧ (Pace<0.9)

今天就能做的动作

用触发条件检查表逐项打勾；只动满足条件者；一天最多改一次价

🛠 工具：触发条件检查表 / 判断树卡片　·　📄 在线预览　·　⬇ 下载Excel
动作 3
今天动还是不动（3 分钟）　满足条件才动，否则也留记录
⚠ 别踩这个坑：「不动」就什么都不记，月底复盘发现同一类日子反复错过窗口。

怎么做

若满足触发条件，执行改价/放渠道；若不满足，明确记「今日不动（原因：___）」。不动也是一种决策，必须留痕，否则无法复盘。

决策 = 触发满足 → 执行；触发不满足 → 记录「不动」

今天就能做的动作

每个开盘都产出一条记录（动/不动+原因）；周一时汇总看规律

🛠 工具：每日巡检表（动/不动 留痕列）　·　📄 在线预览　·　⬇ 下载Excel
动作 4
改动留痕（2 分钟）　改了什么 / 为什么 / 预期
⚠ 别踩这个坑：改完价就关页面，下周问「那天为什么涨」答不上来，也无法归因。

怎么做

每次改动在巡检表记三列：改了什么（如 BAR +30）、为什么（Pace 1.15）、预期结果（出租率+3pt）。到期回填实际，和预期对比。

留痕三列 = 动作 + 原因 + 预期；回填 = 实际 vs 预期

今天就能做的动作

改动必填三列；周一例会回看上周留痕；偏差大的写复盘笔记

🛠 工具：每日巡检表（动作+原因+预期 三列）　·　📄 在线预览　·　⬇ 下载Excel
本页行动清单
  1. 每日 9:00 开盘看三数（在手/Pace/竞品）
  2. 触发判断树逐项打勾，满足≥2才动
  3. 每个开盘都留「动/不动+原因」记录
  4. 改动必填三列，周一回看偏差
