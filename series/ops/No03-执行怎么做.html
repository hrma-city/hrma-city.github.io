这一步具体怎么做

执行是把决策落到系统里的动作：改价、锁房、配渠道。执行最忌「频繁小调」——既制造噪声，又让客人觉得乱。一次调准，比一天调十次强。

操作步骤 · 3 个

一个动作一张牌

每个动作沿用同一套结构：先讲你会踩的坑，再讲怎么做、给公式、给今天就能做的动作、给工具。

动作 1
改价上架　调差价 → PMS
⚠ 别踩这个坑：在 OTA 和官网各改一遍、还改错，价差引发客诉。

怎么做

以 BAR（最优可售房价）为基准统一调；所有衍生价（含早/不含早/会员）按固定差幅联动；改完在 PMS/渠道后台核对一次。避免低于最低可接受价。

衍生价 = BAR ± 固定差幅（如含早 +¥40）

今天就能做的动作

改 BAR → 联动衍生价 → PMS 核对 → 渠道回查

🛠 工具：PMS 价格模板 / 渠道后台　·　📄 在线预览　·　⬇ 下载Excel
动作 2
锁房控库存　D-7 收紧 / D-3 回收
⚠ 别踩这个坑：高需求日还敞开门卖低价，等到满房才发现该赚的没赚。

怎么做

设 MinLOS（最短住期）拦截碎片化需求；D-7 收紧低价渠道，D-3 回收团队未签房；高需日关掉折扣价。

MinLOS 按需求强度动态设（强需 ≥2 晚）

今天就能做的动作

D-14 设 MinLOS；D-7 收 OTA；D-3 回收团队房

🛠 工具：库存日历 / MinLOS 规则　·　📄 在线预览　·　⬇ 下载Excel
动作 3
配渠道投放　直销优先
⚠ 别踩这个坑：OTA 一降价就全量跟，直销会员被挤没了。

怎么做

按配额放量/收量：直销会员优先保；OTA 只在配额内放；用「阶梯投放」（需求强时先收 OTA 保直销）。

直销占比目标 >= 渠道总 booking 的 30%

今天就能做的动作

按配额放渠道；强需求先收 OTA；盯直销占比

🛠 工具：渠道投放看板　·　📄 在线预览　·　⬇ 下载Excel
这一步的节奏（每天 / 每周 / 每月 / 每年）
  • 每天　盘中改价/锁房，改动必留记录。
  • 每周　按例会决策更新下周价与配额。
  • 每月　看渠道成本，调配额结构。
  • 每年　谈渠道合同，优化佣金结构。
本页行动清单
  1. 以 BAR 为基准联动改价，改完核对
  2. 设 MinLOS 与锁房节奏
  3. 按配额放/收 OTA，保直销
  4. 每次改动留记录可追溯
