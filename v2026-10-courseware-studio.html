1 · 两种模式，两种用法

模式给谁怎么找输出
A · 标答模式（按教材目录）还不知道怎么开课、想直接照着讲的教师下拉点选章节（7 篇分组、46 章全可选，不再手输）该章一讲标准课包：目标／导入／公式／算例／三题与答案／追问卡／配套资产
B · 自助模式（按关键词/教学模块）已有自己的课程体系、只想补充素材的教师点选教学模块 + 输入关键词 + 筛资料类型相关资料卡片（章节、判定表、案例、算例、组件、数据）→ 加入「我的课包」→ 导出
我为什么把 B 做成「标签 + 检索 + 收集篮」，而不是另一个关键词输入框
单纯「输入关键词→吐一段内容」容易变成又一个黑盒生成器。教师真正要的是：按自己熟悉的模块找到散布在全站的资料，挑几样带走，拼进自己的课。所以 B 给的是可核对的章节/判定表/组件链接，外加一个可导出的收集篮；A 才给完整的标准答案。两者共用同一套 46 章索引，不会出现两套口径。
边界
本地索引驱动样品，非真实模型调用、非全文检索；零额度、可离线。章节与资产链接都指向站内真实页面，命中理由（模块/关键词）会显示出来，方便教师自己判断相关性。

章节列表来自 46 章成品教材；选任意一章都会给出对应模块的实质内容，不会再出现「输不全就显示不出来」。

3 · 索引口径与验收

项规则
目录来源v2026-10-textbook-full.html（46 章连续编号、7 篇）＋ outputs/v2026-10-chapter-index.json
旧章号每题结果都标「原第 N 章」或「新增 · Nx 讲」，可用成品教材卷首对照表换算
模块映射12 个教学模块，一章可属多模块；模块只是检索维度，不改变教材篇章归属
关键词标题 + 专业词（RGI / CLV / wash / ρ / fence / WAPE / Bias / HHI / 生成式 AI 等）+ 模块名联合匹配
相关度模块命中 +3、关键词每条 +2；同分按章号升序；无筛选时全册浏览
母本边界结果只给站内可点链接与资料清单，不输出 41 章正文全文、不出售题库真题与参考答案
不做什么不调用付费模型、不做账号体系、不采集学生数据、不自己发认证
自检口径
jsdom 点击级测试须覆盖：46 个章节选项齐全、切换章节输出随之变化、Tab 切换、模块点选与关键词检索命中、收集篮加入与条目数变化、清空筛选。
