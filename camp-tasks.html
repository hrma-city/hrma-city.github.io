T1 · 七日日报 阶段一

任务目标
用云璟 90 天数据，独立完成连续 7 天的收益日报
给到您的数据
云璟 90 天数据集（8 表）
要做的动作
取数 → 填日报 → 标异常 → 写原因
交付物
7 天日报 + 3 个异常的书面说明
判定标准
数值全部准确、口径一致；异常标注有依据、能落到具体动作
常见扣分点
只填数不标异常；异常写成"市场不好"这类无法执行的结论

T2 · 指标体检 阶段一

任务目标
算清 OCC/ADR/RevPAR 与 MPI/ARI/RGI，写一份 300 字诊断
给到您的数据
云璟数据 + 竞品群 A880/B680/C560/D720/E520
要做的动作
算三组指标 → 判断落后是价的问题还是量的问题
交付物
指标表 + 300 字诊断
判定标准
能说清 MPI&gt;1 而 ARI&lt;1 意味着什么（靠低价换量）
常见扣分点
只看 RevPAR 不看 RGI；把 MPI 和 ARI 分开讲、看不出联动

T3 · 台账规范 阶段一

任务目标
建立调价台账与取消/No-show 记录
给到您的数据
近 30 天调价记录
要做的动作
补录历史调价 → 建立台账字段 → 写填报规范
交付物
一份可长期用的台账模板 + 填报规范
判定标准
每次调价有：日期、房型、原价、新价、依据、审批人
常见扣分点
台账缺"依据"字段——没有依据就等于不可追溯

T4 · 分日预测 阶段二

任务目标
做未来 30 天的分日 OCC/ADR 预测
给到您的数据
过去 2–3 年同月同周数据 + 事件日历
要做的动作
取基准 → 标事件 → 分高/中/低需求日 → 出分日预测
交付物
30 天分日预测表 + 依据说明
判定标准
用同期数据而非全年平均；事件日单独标注并注明确定程度
常见扣分点
用全年平均值；未剔除特殊事件年份；未分房型

T5 · 调价演练 阶段二

任务目标
给定 5 个情境，逐个做调价决策并说明依据
给到您的数据
5 个情境（进度超前/竞品普涨/竞品降价/需求疲软/事件日）
要做的动作
按三看法则判断 → 定涨幅或降幅 → 算弹性量损
交付物
5 份决策说明（含计算过程）
判定标准
三看齐全（进度/竞品/弹性），且算出量损与 RevPAR 变化
常见扣分点
拍脑袋定涨幅；涨了不算量损；"竞品涨我就涨"无独立判断

T6 · 价格体系 阶段二

任务目标
设计一套房型价差与 BAR 体系
给到您的数据
云璟房型结构：高级150/豪华90/行政45/套房15
要做的动作
定 BAR → 定房型价差 → 折算协议/会员/团队价 → 检验可追溯
交付物
价格体系表 + 价差依据说明
判定标准
所有价格都能追溯到 BAR；价差与可感知差异、额外成本对应
常见扣分点
价差拍脑袋；套餐价折算不回 BAR；协议价与 BAR 脱钩

T7 · 库存方案 阶段三

任务目标
出一份周度库存方案：房型开关 + MinLOS + 保护位
给到您的数据
某周分日需求预测 + 在手预订
要做的动作
排开关顺序 → 定 MinLOS → 设保护位与释放条件
交付物
周度库存方案（含触发条件与撤销条件）
判定标准
开关顺序正确（先关低价）；MinLOS 算了留住 vs 被挡；保护位有释放规则
常见扣分点
先关高价房型；MinLOS 设了不设撤销条件；保护位定死不释放

T8 · 渠道配额 阶段三

任务目标
做渠道净价排序与配额方案
给到您的数据
各渠道挂牌价、佣金率、附加成本
要做的动作
算净价 → 排序 → 定配额 → 写 OTA 谈判要点
交付物
渠道净价表 + 配额方案 + 谈判要点
判定标准
净价算全（含促销分摊、开票结算成本）；配额依据净价差
常见扣分点
只算佣金不算其他成本；"全给 OTA"或"只做直销"两个极端

T9 · 超售与应急 阶段三

任务目标
定超售档位并写 walk 预案
给到您的数据
320 间 / 已订 308 / No-show 11% / walk 成本 1200
要做的动作
算预期 No-show → 设安全边界 → 写 walk 预案与授权边界
交付物
超售方案 + walk 预案（安置、交通、差价、次日回本店）
判定标准
有缓冲不顶满；预案可执行；超过授权上限报店总审批
常见扣分点
顶满预期 No-show；没有 walk 预案；超授权不上报

T10 · 团队置换 阶段四

任务目标
算临界报价并写谈判话术
给到您的数据
团队 120 间夜 @480；散客 680；变动成本 95；附加收益 8000
要做的动作
算置换损失 → 求临界报价 → 写谈判话术与底线
交付物
置换测算 + 临界报价 + 谈判话术（含底线）
判定标准
临界报价算对（约 526）；话术围绕附加收益谈，不是直接让价
常见扣分点
只跟成本比（不低于成本就接）；忘记计入附加收益；底线没写死

T11 · 月度计划 阶段四

任务目标
做一个月度收益计划并把预算分解到周、到日
给到您的数据
全年目标 + 淡旺季 + 事件日历
要做的动作
定月目标 → 分到周 → 分到日 → 与去年对比找缺口 → 缺口变动作
交付物
月度计划 + 周/日分解表 + 缺口动作清单
判定标准
三个目标互相校验；不平均分配；每个缺口对应一个具体动作
常见扣分点
平均分配；只有目标没有动作；目标之间不自洽（OCC×ADR≠RevPAR）

T12 · 综合答辩 阶段四

任务目标
给定异常情境现场决策 + 15 分钟答辩
给到您的数据
随机抽取的异常日情境（台风/竞对恶意降价/系统故障等）
要做的动作
现场判断 → 说明依据 → 回答追问
交付物
现场决策 + 答辩记录
判定标准
判断有依据、能说清 trade-off、被追问不慌、承认不知道的部分
常见扣分点
只给结论不给依据；被追问就改口；不懂装懂
