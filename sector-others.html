板块 04 · 其他行业

其他行业（餐饮 · 娱乐 · 医疗 · 租车 · 新兴行业）

把收益管理内核搬到非住宿、非旅游的场景：餐饮看翻台与时段、娱乐看场次与座位、医疗看号源、租车看车队。它们的共同点是——产能固定、库存易逝、需求可细分，所以同一套方法依然成立。

核心指标
RevPASH（餐饮）/ RevPAA（医疗）/ RevPAT（租车）
产能单位
餐位·小时 / 号源 / 车·天
关键差异
翻台率、爽约率、车型嵌套取代房型与 No-show
核心方法
时段/场次控制 + 分级定价 + 超配管理
酒店 住宿业 旅游业 其他行业

概念

餐饮业总览
RevPASH、翻台率、用餐时长、时段定价、团购渠道
娱乐休闲总览
场次排布、座位分级、套餐组合、会员体系
医疗号源
RevPAA、号源利用率、爽约率、号别结构
租车
RevPAT、车队利用率、车型嵌套、租期折扣

流程

餐饮六模块
F1 指标 / F2 预测 / F3 定价 / F4 库存 / F5 渠道 / F6 落地
娱乐六模块
E1 指标 / E2 预测 / E3 定价 / E4 库存 / E5 渠道 / E6 落地
医疗号源六模块
排诊日历、号别嵌套、超约、退号回收
租车六模块
车队可用日历、车型嵌套、超售与调度

案例

租车超售零拒载（算例）
超售 5% < No-show 12% → 零拒载、多赚 ¥44,880
医疗超约零拒载（算例）
超约 8% < 爽约 10% → 零拒载、多赚 ¥114,048
