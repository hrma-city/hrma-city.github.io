HRMA · 教师开课训练营

全部内容设计

4 周后，你手上有一门能开起来的课——不是"听懂了"，是拿到了自己的大纲、教案、实训和评价方案。

一、训练营基本盘

项设定
对象酒管 / 旅管专业教师（高职 + 应用型本科为主）
周期4 周 / 期，一年 4 期（3 月、5 月、9 月、11 月，避开寒暑假与开学月）
规模每期 200–300 人；首期内测 30–50 人
形式12 节录播微课 + 4 次集中答疑 + 4 个产出作业 + 判定表批改
价格内测 ¥980 / 标准版 ¥1,980 / 专业版 ¥4,980（可报销）
精力首期约 120h（一次沉没）；之后每期约 30h；全年约 240h
交付铁律：内容做重（一次性），服务做轻（每期）。
把重的一次性做完（录课、模板、判定表），把轻的重复做（答疑、批改、群维护）。不做 1v1、不代写、不随时响应、不改到满意为止。

二、四周完整内容

每周 3 节微课 + 1 个产出作业 + 1 张判定表
第 1 周 · 这门课到底教什么（内容重构）
主题：把"知识清单"改成"决策能力清单"
M1　收益管理课的 4 种失败：讲概念不讲决策 / 讲理论不讲数据 / 讲系统不讲手动 / 讲知识不讲评价
M2　32 个公式的教学排序：哪些先讲、哪些后讲、哪些根本不讲
M3　16 周教学日历怎么排（含实验周、复习周、考核周的分配）
本周作业：产出《16 周课程大纲》（用模板改，不是从零写）　→　判定表 A 评分
第 2 周 · 一节课怎么设计（教学设计）
主题：90 分钟里，学生真正记住的是什么
M4　一节课的标准结构：导入（5′）→ 活动（30′）→ 决策（35′）→ 复盘（20′）
M5　3 个必做的课堂活动：超售决策 / 知识抢答 / 值班叙事（含投屏玩法与断网预案）
M6　学生最容易听不懂的 5 个点及讲法：机会成本 / 影子价格 / pickup / BAR 层级 / 置换分析
本周作业：产出《1 个完整教案（90 分钟）》（含活动、板书、提问设计）　→　判定表 B 评分
第 3 周 · 实训与数据（没有系统怎么做）
主题：不买 RMS，也能让学生练真决策
M7　没有系统怎么做收益决策训练：手动取数流程 + Excel 判定表
M8　12 个游戏的分层用法：课堂现场（投屏分组）/ 课后练习 / 综合考核，各自怎么用
M9　251 题题库与考核设计：怎么出题、怎么判分、怎么防作弊
本周作业：产出《1 个实训设计》（含任务书、数据、评分标准）　→　判定表 C 评分
第 4 周 · 评价与申报（产出与证明）
主题：让这门课能被看见、能被申报、能被承认
M10　「1+3」评价体系：1 个综合考核 + 3 个过程评价（含量规模板）
M11　课程思政的 3 个自然结合点（不生硬、不喊口号）
M12　申报材料清单：一流课程 / 教改项目 / 技能大赛，各需要什么、怎么提前留痕
本周作业：产出《评价方案 + 申报材料清单》　→　判定表 D 评分
结 业
四周累计产出＝课程大纲 + 1 个完整教案 + 1 个实训设计 + 评价方案 + 申报清单　＝　一门能开起来的课。

三、每周运行节奏（固定，不随人变）

时间动作你的精力
周一发放当周 3 节微课 + 作业说明 + 模板0（已录好，自动发放）
周三群内收集问题（异步，不实时答）0.5h
周五集中答疑 90 分钟（直播，可回放）3h（含准备）
周日 24:00作业截止0
下周二判定表反馈（A/B/C 档 + 3 条改进意见）3h（助教初筛后你复核）
边界写死：群内不承诺实时回复；答疑只在周五集中进行；批改只出「判定表 + 3 条意见」，不做长文个性化反馈（那是精力黑洞）。这些边界要在开营第一天就讲清楚。

四、判定表评分标准（批改不靠感觉）

4 张判定表，三档结论，反馈不超过一页
档位含义反馈方式
A 档 · 可直接用达到全部必达项，明天就能拿去上课判定表全勾 + 一句肯定
B 档 · 需小改核心齐全，缺 1–2 个要素，改 1 小时可用判定表 + 3 条改进意见
C 档 · 需重做结构性问题（如大纲没有决策链、教案没有学生活动）判定表 + 具体返工指引（指向对应微课）
为什么用判定表批改：① 批改速度提升 5–10 倍（勾选而非写文章）；② 标准统一，学员无法质疑；③ 判定表本身就是产品，可复用、可出版、可作为 AI 分身的评分引擎；④ 反馈指向"判定表第几项扣分"，而不是主观评价——这正是你"收益管理教学教练"的人设。

六、精力账与首期打法

阶段内容工时
首期一次性投入录 12 节微课 + 做模板包 + 做判定表 + 备课约 120h
之后每期4 次集中答疑(12h) + 批改统筹(12h) + 群维护(6h)约 30h
全年 4 期120 + 30×4约 240h
首期 120h 是唯一的坎。这是全部门槛所在，也是唯一的"体力活"。
应对：先录 4 节课就开首期（第 1 周内容 + 简化版后 3 周），不要等 12 节全录完。首期本来就是内测价 ¥980，学员能接受"共创"定位，且他们的反馈会让后 8 节录得更准。
首 期 三 步
① 先做《开课自检表》收邮箱 → ② 录 4 节 + 开内测首期（30–50 人，¥980）→ ③ 跑完必拿三样：一句评价 + 学员作业样例 + 可公开校名。有了这三样，才谈得上渠道与涨价。
一句话：训练营卖的不是课时，是学员手上那份能直接用的课程包。内容做重一次，服务做轻每期——这样才能在你 240 小时/年的精力预算里，做出 300 人的规模。
