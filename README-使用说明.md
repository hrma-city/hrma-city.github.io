## 二、核心方法论（三不原则）

| 原则 | 含义 |
|---|---|
| **不猜** | 所有判断必须有数据来源。禁止「我觉得」。要抓哪些数、从哪抓、几点前抓完，写死在《取数清单》里 |
| **不算** | 公式已固化进 Excel 模板。学员只需填数、读结果，不需要记公式 |
| **不纠结** | 所有决策由《操作法典》判定表给出：输入条件 → 输出动作 |

**学员每日四步闭环**：

```
看数 → 查表 → 执行 → 记录
```

第四步「记录」是命门——每一步都写清「当时看到什么数、查的哪张表、得出什么动作」，
30 天后就能回头算**调价命中率**。这让收益管理从玄学变成可复盘、可考核、可传承的工程。

## 三、《收益管理操作法典》—— 整套体系的地基

15 张判定表，编号 A–O。学员唯一需要随身带的东西。

| 表 | 名称 | 表 | 名称 |
|---|---|---|---|
| **A** | 每日价格调整判定表（6×5 矩阵） | **I** | 预订窗口分档监控表 |
| **B** | 库存与限制条件配置表 | **J** | 免费升级规则表 |
| **C** | 价格指数 ARI 判定表 | **K** | 会议／宴会综合收益联动表 |
| **D** | 市场渗透指数 MPI 判定表 | **L** | 异常事件应急判定表 |
| **E** | 超额预订标准表 | **M** | 每日操作流水线（时间表） |
| **F** | 房型价差阶梯表 | **N** | 周度／月度节奏表 |
| **G** | 团队／协议询价接受判定表 | **O** | 决策优先级与冲突仲裁表 |
| **H** | 渠道开关判定表 | | |

**表 O 是「不纠结」的终极保障**。多张表打架时严格按优先级执行：

```
表L 应急 > 表B 库存 > 表A 价格 > 表C 定位 > 表H 渠道 > 表D 诊断
```

三条铁律：① 同日只执行最高优先级那条；② 最高优先级为「维持」则顺延；
③ 冲突与取舍必须写进《调价台账》备注栏。

## 四、三条使用路径

### 路径 A · 完整授课（推荐给培训机构）

M01 → M14 全走一遍，每周 2 课时，**20 周**完成三级。
每课时 90 分钟固定结构：

| 时段 | 环节 |
|---|---|
| 0–15 min | 知识点输入（不超过 5 个新概念） |
| 15–35 min | 讲师示范（用真实数据完整走一遍四步闭环） |
| 35–70 min | 学员跟练（讲师巡场，**不主动帮忙**） |
| 70–85 min | 判定表默写 |
| 85–90 min | 随堂测 5 题（**全对才能进下一课**） |

### 路径 B · 单店速成（推荐给急需用人的酒店）

只上 **M01、M03、M05、M06、M07** + 《操作法典》专项训练，**4 周**让员工能顶岗。
这是投入产出比最高的方案。

### 路径 C · 自查手册（推荐给在岗收益经理）

不授课。直接把《操作法典》+ Excel 模板发下去当随身 SOP，配 251 题题库自测，**1 天上手**。

## 五、认证体系

| 等级 | 学时 | 课时 | 能力终点 | 通过条件 |
|---|---|---|---|---|
| **L1** 收益执行专员 | 4 周 | 16 | 独立完成每日取数、查表、执行、记录 | 笔试 ≥80 + 实操 ≥85 + 出勤 ≥90% |
| **L2** 收益管理主管 | 8 周 | 32 | 独立完成预测、定价决策、周度策略、渠道管理 | 同上 |
| **L3** 收益管理经理 | 8 周 | 32 | 能做预算、定战略、带部门、向业主汇报 | 同上 **+ 答辩 ≥75** |

证书有效期 2 年，续期需 40 学时继续教育。未通过可免费重修一次。

**判定表默写采用累计制**：L1 背 3 张 → L2 累计 9 张 → L3 累计 15 张。
矩阵类表（A、G）错 6 格以上直接不及格。

## 七、配套资源怎么用

### Excel 模板（8 个）

| 文件 | 用途 |
|---|---|
| 01 每日收益日报 | 日报，自动算 MPI / ARI / RGI / NRevPAR |
| 02 Pickup 追踪表 | 未来 30 天在手与 Pickup 偏差 |
| 03 竞争比价监测表 | 5 家竞对价格 + ARI 自动诊断 |
| 04 调价台账 | **含命中率复盘**，30 天后回填即可算调价命中率 |
| 05 房型价差与价格体系 | 含全年 365 天价格日历 + 价差校验 |
| 06 年度预算与月度分解 | 从月度基准推到全年 GOP + 量差价差归因 |
| 07 周报月报模板 | 周报 / 月报 / 业主一页纸 / 周末作战表 |
| 08 超额预订计算器 | 表 E 超售 + 表 G 团队询价 + 表 K 会议综合贡献 |

### 讲师版 PPT（3 套 · 103 页）

每页备注栏都写了：讲几分钟、怎么开场、举什么例子、问学员什么问题、哪里容易被问倒。
配套《讲师手册》含 20 组常见问题 Q&A。

### 模拟数据集（4 个）

基于杭州滨江云璟酒店的仿真数据，内部自洽、可互相验算。
校准结果：OCC 72.06%（基线 72%）、ADR ¥618（¥618）、RevPAR ¥445（¥445），客源结构误差 <0.1%。
**埋了 10 处已知异常点**供讲师出题，详见 `data/README.md`。

用这三条交叉验算可快速发现脏数据：
- `已售房晚 = 可售房量 × OCC`
- `客房收入 = 已售房晚 × ADR`
- `RevPAR = OCC × ADR = 客房收入 ÷ 可售房量`

### 游戏化教具

- **决策模拟器**：12 个场景，提交后自动对照法典判分并指出错在哪一格
- **战术卡牌 36 张**：含完整对战规则，强制学员「说出触发条件」
- **角色扮演 4 套**：拒绝团队 / 不跟降价 / 超售危机 / 业主汇报，配逐句话术

## 八、给讲师的三条提醒

1. **随堂测 5 题全对才能进下一课。** 这条不执行，后面会全线崩塌——课程是强依赖的，
   表 A 没背下来，后面所有模块都听不懂。

2. **学员跟练的 35 分钟，讲师不许主动帮忙。** 卡住是学习的一部分。
   等 3 分钟以上或学员明确求助三次才给提示，而且只说「去查哪张表」，不给答案。

3. **阈值是通用起点，不是圣经。** 学员上岗 3 个月后，必须用自己酒店的真实数据回填校准——
   尤其表 E（超售率）、表 C（ARI 绝对值）、表 F（价差）。
   法典的价值在于给了个 80 分的起点和可校准的框架，让新人第一天就能干活。

## 九、教学原型

全学院共用一家虚构酒店，数据完全自洽：

**杭州滨江云璟酒店** · 中高端全服务 · 320 间客房（10 个房型）
平峰 BAR ¥680 · 竞争组合 5 家（加权均价 ¥680）
年 OCC 72% · ADR ¥618 · RevPAR ¥445 · 总营收 ¥8,468 万 · GOP 率 32%

如果你的学员来自不同酒店，把数字替换成他们的真实数据即可，方法完全通用。
不同档次的酒店见 `SPEC.md` 的适配说明。
