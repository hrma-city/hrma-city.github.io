一、垂类情报：这个赛道谁在写

1. 胡质健 —— 行业权威，且已占住你要的高地

已核实事实：《饭店收益管理》专著作者（中国旅游出版社，2016 一版 / 2021 二版 / 2024 三版）； 《酒店收益管理人员职业能力要求》团体标准执笔起草人；全国酒店收益管理技能大赛专家评审组副组长； 中国旅游饭店业协会、中国饭店协会理事；北京第二外国语学院中瑞酒店管理学院客座教授；清华大学继续教育学院酒店管理高级课程班特聘教师； 美国饭店协会教育学院 CHE / CHT；迈点网、环球旅讯、酒店评论专栏作者。曾任建国国际营销总监、PriceMatch 大中华区收益管理高级咨询顾问、众荟高级顾问、多家饭店总经理。
这条情报直接改变你的两处做法

① 你不能做"从业人员职业能力标准"。该领域的团体标准已由他执笔起草。你若再推一份《酒店收益管理人员能力规范》，不仅撞车，而且你没有任何机构身份背书，站不住。 → 你的《能力规范》必须改定位为 "教学标准 / 课程标准"（收益管理课程该怎么开、考什么、达到什么教学终点），这是他没做也没打算做的方向。

② 院校线并非无人，但占法完全不同。他是"被请去讲课的客座教授"，你是"教老师怎么开出这门课的人"。 他去一所学校赚一次课酬；你帮一所学校建起一门课后可以复利。他占据的是"权威"，你占据的是"方法"——不要去比谁更权威，那是必输的比赛。

2. 浅谈 Revenue Management —— 一线实操派，写法值得直接学

公众号，面向一线收益人员。其典型文章（价格调整时间点）结构如下，这是垂类内已被验证的写法：

  • 第一人称口语化开场（"那么今天我们就来聊一聊…"）
  • 先说大多数人的错误做法（出租率到 60% 换一档价格体系、80% 再换一档）
  • 再给正确做法 + 一个真实案例（某酒店提前把团队价与 BAR 拉平，展会期间 ADR 高出一倍）
  • 给具体数字标准（月度预测偏差 3%–5%，列入收益人员 KPI）
  • 文末留作业："本周作业：你觉得市场热度最重要的判断标准是什么？欢迎评论区分享"
  • 固定收尾口号 + 引导关注

可迁移的两点：① "先讲大家做错的做法，再讲对的"——这个结构天然产生完读率（算法第一权重）； ② 文末留作业——这是垂类内极少有人做、且几乎零成本的互动率提升手段（互动权重 15%）。建议你直接采用。

3. 张小姐看酒店生意（露丹）—— 告诉你流量天花板有多低

十几年酒店收益管理经验，做喜马拉雅播客 + 小红书同名账号，节目定位"用真实案例，讲清酒店利润背后的生意逻辑"。 关键情报：其播客单集播放量在数百量级（622 / 204），订阅数二十余。

这条数据比任何方法论都重要

一个做了十几年、内容质量不差的从业者，在音频+小红书赛道上的真实数据是几百播放、二十几个订阅。 这说明：酒店收益管理是一个极窄的垂类，公域流量天花板很低。
→ 所以千万不要把公众号当流量生意做。指望阅读量涨到几万后自然变现，在这个垂类里不成立。
→ 正确预期是 Alina 那句话："我不追求海量粉丝，我要的是 3000 个精准信任我的人——够了。" 对你甚至不需要 3000 个：300 个精准的院校教师 + 酒店收益负责人，就足以撑起你的全部生意。

二、Write to Live 能迁移给你的五条

Alina霖子（个人品牌商业教练、两本畅销书作者、一人公司）的公众号 Write to Live 是纯文字创作变现的成熟样本：不露脸、不讲课、不追流量，靠文字做到连续多年营收百万。以下是能直接迁移的部分。

① 写作 ≠ 产品：三级火箭（最重要）

她的原话："写作≠产品。表达≠服务。分享≠销售。" 内容要经过"结构设计、价值浓缩、应用场景定位"才可能成为可销售的产品。她真实走过的三条路径：模板 → 小册合集 → 训练营。
第一级 · 模板
低价 / 免费
为"想开始但卡在第一步"的人。核心是帮用户越过从 0 到 1 的卡顿，直接套用你的思考结构。她的洞察："能写出来远比写得完美重要"
第二级 · 小册合集
中价
为"想深入理解你的内容系统"的人。不是复制粘贴，而是重排序 + 加导航页 + 补练习。碎片阅读 → 系统理解的桥梁产品
第三级 · 陪伴营
高客单
为"想被你陪一段"的人。不是卖知识，是卖陪伴。成功关键：用陪伴/练习/反馈帮他完成那一小步
好消息

这三级你已经全部建好了，只是没用"火箭"的语言串起来。

  • 第一级模板 = 判定表 Excel / 公式计算表 / 8 套模板（现成，免费钩子）
  • 第二级小册合集 = 32 本口袋书 + 16 册主题书 + 教材 + 指南（现成）
  • 第三级陪伴 = 师资陪跑 / 院校共建（现成，你的利润核心）

你要做的不是造产品，是在每篇文章末尾把读者往上一级推一格。

② 3000 人理论 → 你的 300 人目标

她明确写："少数人 > 大众。我不追求海量粉丝，我要的是 3000 个精准信任我的人——够了。" 在收益管理这个窄垂类，你的数字还要更小。把目标定为 300 个精准读者：其中包含未来会找你做院校陪跑的系主任、专业负责人、酒店收益总监。 这个数字的意义是：让你不再为"阅读量只有 200"而焦虑——那 200 人里只要有 1 个是系主任就值了。

③ 系统写作的四条小机制（非压迫性，专为低能耗设计）

她反复强调自己的系统是"温柔的、一人适用的小系统"，"不是用来管理我的创作，而是用来保护它"。具体机制：

  1. 每周设一个"主题感"——不是选题，是那周最在意、最想靠近的状态
  2. 每天起床前写 5 分钟"不用来发表"的文字——像热身
  3. 每周更新 1–2 篇，"不管有没有人等，都当作定期和自己对话的仪式"
  4. 每月一次内容回顾：整理高反馈内容，看是否可以做成深度稿、课程雏形或互动问答
第四条对你价值最大

她每月把高反馈文章升级成课程雏形——而你的情况更夸张：你的高反馈文章可以直接长成口袋书的一章、教案的一节、判定表的一张。 因为文章与你的书系本来就是同源的。"文章 → 书 → 课程 → 陪跑"在你这里不是比喻，是同一份内容原子的四种包装。 每月回顾这一小时，是你整个系统里回报率最高的动作。

另有一条她的铁律值得抄："不写我不相信的东西。" 她试过写"鸡汤"和"方法论"讨好市场，结果"整个人都很疲惫"，定下这条规则后"结果反而更好"。你是二十年实战专家，这条对你天然成立——不要为了讨好算法去写你不信的内容。

④ 反差句式人设（可直接套用）

她的自我介绍是三段反差，极有记忆点：

不喜欢社交，却有来自全球 10+ 个国家的商业咨询客户。 不擅长表达，却出版了两本个人品牌商业书籍。 不追逐流量，却连续 3 年营收百万。

句式 = "我不 X，却 Y"。用它把你的"弱点"变成辨识度。你的版本建议：

不带酒店人做实操，却帮院校把收益管理课真正开起来。 不做销售，却拿下一个个院校陪跑年框。 只写判定表，不写观点文。

注意第三句——"只写判定表，不写观点文"是极强的差异化声明：它同时拒绝了热点、拒绝了大量同行在写的感想文，并让读者一眼知道这里有什么。

⑤ 转化不是设计出来的（与你的"被动接单"完全一致）

她的描述："这些收入，没有设计过销售漏斗，没有推广计划。只是因为：表达是通的，信任就来了；信任来了，收入也不会远。" 有人加微信想聊聊项目、有人问能不能开小班、有人在文章底下直接问"你有没有一对一咨询"。

这与你已定的"被动接单、不做主动 BD"策略完全同构。她的工作哲学也值得抄： "干了再说，错了就改，对了就重复干，重复干就写 SOP。"以及"凡是累都不对——如果很累，说明方法错了"——这句话应该成为你运营公众号时的止损线。

三、整合后的打法

定位一句话

收益管理教学教练 —— 不带酒店人做实操，只陪高校教师把收益管理课真正开起来。

胡质健教酒店人怎么做收益，浅谈 RM 教一线怎么调价，张小姐讲酒店生意经。没有人教"如何把这门课开起来"——而你全部的资产（14 模块、15 判定表、教案、考核、申报清单）都是为这件事造的。

⚠ 本定位已由用户确认为"收益管理教练，主攻收益管理教学"，完整定稿见 《HRMA-定位定稿-收益管理教学教练》（含：教练身份三重好处、与胡质健最终对照、 "异步教练"四条规定以匹配精力结构、账号文案定稿、双合集栏目结构、产品语言改写表）。 本文件以下内容（一稿两用、三级火箭、90 天清单）仍然有效，仅定位表述以定稿为准。

核心机制：一稿两用（一篇同时喂饱两类读者）

这是本方案最重要的机制设计。你之前纠结"写从业者的还是写教师的"——答案是不用选，一篇里都写，因为：

  • 从业者要的是"这张表怎么用"（可操作）
  • 教师要的是"这个知识点怎么教"（可教学化）

同一张判定表，两个角度。做法：正文写从业者怎么用，文末固定加一个栏目《给教师的一句话》（3–5 行），讲这篇怎么变成一节课/一个课堂活动/一道考题。

正文 · 面向从业者（起量 / 搜索 / 收藏）

《竞品降价了，跟不跟？三步判断》

场景 → 大多数人的错误做法 → 正确三步 → 案例 + 数字 → 文末留作业 → 回复【竞品】领对照表

文末固定栏目 · 面向教师（转化大单）

《给教师的一句话》

"这节课可以这么上：给学生两组真实数据，一组跟价一组不跟，让他们算 30 天后的 RevPAR 差值。 这是本模块最容易讲活的 15 分钟。"→ 回复【教案】领本课时教案

成本：每篇多写 3–5 行。收益：同一篇文章同时承担"起量"和"转化"两个职能，且不稀释垂直度（两栏都是收益管理）。

内容配比修订（v1 的 70/30 → 改为一稿两用）

v1 方案定的是 70% 从业者 + 30% 教师。看完竞品后修正：不再按篇数分配，改为每篇内置双栏。理由： 纯教师内容在微信搜一搜里几乎没有搜索量（教师不会主动搜"收益管理教案"），起不了量； 但纯从业者内容又错失你的高客单客户。一稿两用同时解决两个问题。

唯一例外：政策类选题（1+X 移交、等级认定）单独成篇，且只写教师——那是教师会主动搜、且全网几乎无人写透的破圈内容。

三级火箭的推进节奏

阶段文章在做什么把读者推向哪一级
0–3 个月判定表 / 公式类，免费给推向第一级模板：回复关键词领 Excel。目标：领表次数
3–6 个月建合集，形成体系感推向第二级小册：口袋书 / 主题书 / 教材。目标：主动咨询
6 个月后教师向 + 政策向内容推向第三级陪跑：院校共建。目标：签约

四、人设与账号设置

名称：酒店收益管理（首选，含搜索关键词；次选"酒店收益管理手册"） 简介： 酒店收益管理｜15 张判定表免费领 不带人实操，只教怎么开课、怎么判断 回复【判定表】领 Excel · 回复【大纲】领课程大纲 被关注回复： 欢迎。这里只做两件事：给从业者发判定表，给教师发开课方法。 回复【判定表】领自检表 ｜ 回复【大纲】领 16 周课程大纲

关键词一律 2 字短词（判定表 / 大纲 / 预测 / 日历），不要用长句子。 头像不要用风景或酒店图——用纯色底 + 账号名文字，专业且易在订阅列表里被认出。

五、三个必须避开的坑（基于情报）

  • 不要碰"从业人员职业能力标准"——胡质健已是《酒店收益管理人员职业能力要求》团标执笔起草人。你只做"教学/课程标准"，且不说"首个""首创"
  • 不要做播客 / 音频 / 短视频——张小姐已验证该赛道天花板极低（数百播放），且音频能耗远高于文字。你的精力只够一个形态：文字
  • 不要追阅读量，也不要和胡质健比权威——前者在这个垂类不成立（几百阅读是常态），后者是必输比赛。你比的是"谁能让一个老师真的把课开起来"

沿用 v1 已定的合规红线：AI 辅助创作必须人工加工并勾选声明；不得暗示国家认可；不得承诺就业；案例数据必须脱敏。

六、修订后的 90 天清单

  • 第 1 周：注册 + 定名 + 简介 + 配置"被关注回复"和 2 个关键词回复。不发文章
  • 第 2 周：发第 1 篇《15 项收益自检表》+ 文末首次使用《给教师的一句话》栏目 + 配 Excel 钩子
  • 第 3 周：发第 2 篇（每天该看哪 9 个数）+ 建"判定表"合集
  • 第 4 周：发第 3 篇（RevPAR 加权算法，搜索友好）+ 文末开始留作业（学浅谈 RM）
  • 第 5–8 周：按选题库周更；其中一周发政策解读《1+X 移交后院校该往哪走》（教师向单篇，破圈用）
  • 第 9 周：第一次月度回顾——挑出反馈最好的 1–2 篇，升级成口袋书的一章 / 教案的一节
  • 第 10–12 周：继续周更；优化前 8 篇的标题 + 120 字搜索摘要 + 标签
  • 第 13 周：第二次月度回顾；此时判断是否有读者主动咨询——有即验证成立，可开始推第二级（书系）

止损线（来自 Alina 的一句话）："凡是累都不对——如果很累，说明方法错了。" 如果连续两周一篇都发不出，不要加大意志力，而是把篇幅从 1500 字降到 800 字、把频率从周更降到半月更。 降级继续 > 中断停止。这个账号的价值在于"持续在煮"，不在于"温度高"。
