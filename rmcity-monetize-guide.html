公众号发布与变现 · 操作说明

订阅号助手与网页后台的位置、小程序与游戏是否需要投入、教材章节付费图文的设置路径与开通条件。本文只讲可执行的动作与真实成本。

02小程序、游戏：现在都不用做

后台看到的「小程序」「小游戏」是平台给开发者的另一套产品，和"发文章测教师认可度"不是一回事。个人主体订阅号在变现上有硬限制，先看清成本：

项目个人主体能不能做真实成本结论
小程序（个人）能注册，不能开微信支付、不能经营交易、不能做电商/付费内容注册 0 元；认证自愿，30 元/次只能做展示/工具，做不成收费，不建议
小程序（个体户 / 企业）可开微信支付、可做经营需营业执照；微信认证 300 元/次（个体户限时 30 元）；微信支付商户号免费申请，按笔收手续费（常见约 0.6%）；另需开发等销量验证后再说
小游戏个人主体不开放游戏类目，不能开虚拟道具内购企业主体 + 游戏版号（ISBN，代办数万元、周期数月）+ 软著 + 开发与教材变现无关，不做
微信支付商户号个人主体订阅号无法申请需企业或个体工商户营业执照当前账号开不了
判断：目标是"发教材章节测教师真实认可度、卖付费文章"。这件事用公众号自带的付费图文就能完成，不需要额外主体、不需要认证费、不需要开发。小程序与游戏是"确定要做课程/工具产品之后"才考虑的下一步，现在投入只会分散精力、且个人号根本开不了收费。
另外，站点里已有的模拟器、卡牌、角色扮演等教具都是网页版，本地就能用，与微信小游戏无关，不必迁移。

03付费图文：开通条件（先看清这一条）

当前账号还开不了付费。微信付费图文不是自动拥有的功能，需同时满足：① 公众号注册满 3 个月；② 近 3 个月无严重违规记录；③ 已发表至少 3 篇原创文章（用文章模式并开启原创声明，单纯图文模式不计）；④ 平台对符合条件的账号开放入口（历史上长期为灰度邀请，入口以后台「收入变现 / 付费功能」实际显示为准）。
本账号刚接入、草稿尚未群发，前三条都不满足。所以现在的顺序应该是：先把免费的教材大纲章与案例发出去、声明原创，攒够条件，再开付费。这并不耽误测认可度——免费期的阅读、在看、留言、转发本身就是最真实的反应数据。

开通后怎么设（每章重复一次）

1
电脑登录 mp.weixin.qq.com → 草稿箱 → 打开对应章节草稿。
2
编辑器底部「图文类型」选择 付费图文（默认为普通图文）；会默认触发原创声明，声明失败则无法群发。
3
拖动试读线到「本章大纲」与「完整内容」之间那条分割线的位置——大纲免费可见，完整内容需付费解锁。教材草稿已按这个结构排好，不用再改正文。
4
设定价格（平台给固定档位，早期为 1–208 元 35 档，新版本为微信豆，按后台实际显示选），填前言，先预览再群发。
5
群发后价格、试读比例、前言永久锁定不可改；付费文章不支持赞赏、转载与插入广告。定价建议先用低档（5–20 元或等值微信豆）测真实付费意愿，别一上来定高价。

结算与分成

  • 安卓端：一般按月结算；平台可能收取技术服务/分成，历史灰度期曾暂不抽成，以「付费功能」页面公告为准。
  • iOS 端：走苹果应用内支付（IAP），在平台分成之外还会再扣一道渠道成本，到账更慢、实际到手更少。
  • 需绑定与主体一致的实名结算账户；个人主体收益按劳务报酬由平台代扣代缴个税。

04教材章节草稿的结构

46 章主教材按章推入草稿箱，每篇都是同一套结构：

  • 免费区本章大纲——3–5 条要点 + 一句话带走，读者不用付费就能判断这一章值不值得买。
  • 分界一条分割线，就是你在编辑器里拖试读线的落点。
  • 付费区完整内容——场景故事、要点拆解、例子、结论。

标题、作者（RMCity）、摘要、黑金封面均已随草稿生成。正文里的模板引导语、关注回复、连载角标等痕迹已清除，与案例文章同一套视觉。

技术边界：微信「新建草稿」接口只能建普通图文，无法写入付费开关、试读比例和价格。脚本能做到的是把正文按"大纲 / 分割线 / 完整内容"排好并推入草稿箱；把文章切成付费图文这最后一步必须在后台编辑器手动完成，且前提是账号已开通付费能力。这一点没有自动化捷径。

05建议的推进顺序

  1. 先免费群发 3 篇（可从案例文章里挑，或从教材前 3 章里挑），每篇开原创声明 —— 这同时是在攒付费功能的开通资格。
  2. 看教师端真实反应：阅读完成率、在看、留言、后台提问。哪几章被追问得最多，就是最值得做付费的那几章。
  3. 注册满 3 个月、原创够 3 篇后，去后台查「收入变现 / 付费功能」入口是否出现。
  4. 入口出现后，把教材章逐个改成付费图文（试读线拉到大纲结束处），低档定价，逐章观察付费转化。
  5. 若教材付费转化成立、确实需要系统化课程/教具/会员，再考虑个体工商户主体 + 小程序。小程序与游戏永远排在这之后。
