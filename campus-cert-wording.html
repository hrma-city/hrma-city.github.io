统一口径说明：达标证明 / 能力等级 / 1+X

本页是站点内所有院校材料的措辞基准。7 页既有页面已按此统一修订，每页正文开头均插入口径声明并链回本页。凡对外材料、洽谈话术、申报文本，一律以本页为准。

一、为什么必须改

核查发现，院校真正能写进人才培养方案、能抵学分的那本证，是 1+X 酒店收益管理职业技能等级证书（北京三快在线科技 / 美团颁证，第四批试点，标准代码 540002，2021 年 2.0 版）；另有中国贸促会商业行业委员会的「酒店收益管理师」师资 / 资质路径。我们自建的 L1/L2/L3 没有外部背书，若继续写「发证 / 抵学分 / 对接 1+X」，院校一句「你们证谁认」就会问穿。此外晨鸟杯已占住赛事平台与判分生态，我们的价值在内容与标准，不在发证资格。
改口径不减价值。教材 46 章中 36 章已逐条对标官方条款（见 1+X 逐条映射大表），我们提供的是「照表上课即覆盖备考范围」与「超出标准的高阶能力评价」——这比自称发证更站得住。

二、统一措辞对照表

左列为禁用或需加限定的旧说法，右列为统一改法。所有页面、PPT、洽谈与申报文本同样适用。

旧说法（禁用）统一改法理由
技能证书 / 职业技能等级证书校本达标证明 / 能力等级「职业技能等级证书」是 1+X 专有称谓，不能借用
我们发证 / 签发证书出具达标证明 / 生成能力等级卡发证主体是培训评价组织，不是内容供应商

对接 1+X，可直接换算拟对接 1+X；能力范围已逐条对标，是否换算由考核站点认定我们只能对标能力，不能替考核站点决定换算
证书线 L1=60 / L2=80 / L3=92能力等级线（自建刻度，非 1+X 分数线）1+X 为 100 分制机考 60 分合格，口径完全不同

五、对外三句话（洽谈可直接用）

① 关于证：「1+X 那本证由北京三快在线（美团）颁发，我们不发；我们做的是把 46 章教材、判定项和赛项逐条对标到官方 167 条技能要求，教师照表上课就覆盖了备考范围。」
② 关于我们的证明：「校赛后由贵校盖章出具校本达标证明，我们提供版式、编号规则、验真与台账工具，作为过程性评价材料；是否抵学分、如何换算，由贵校教务与 1+X 考核站点认定。」
③ 关于差异化：「官方标准考的是会不会按流程做，我们的 C / D 类赛项考的是扰动下还能不能做对——教材覆盖考核范围，赛项补上标准之外的高阶能力评价。」

六、边界与待办

仍然待办：① 团体标准《酒店收益管理人员职业能力要求》（2019-08-01 实施）与祖长生「酒店收益管理师」师资路径，条款细分未公开，宜另做一张对照表后再写进正式材料；② 各校考点采用的 1+X 版本需逐校确认；③ 本页与映射大表均为能力对标工具，不构成官方认可、不等同考核大纲、不构成本校学分认定依据。
