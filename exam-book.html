环节 1　确定竞组与市场定位

1. D　竞组要看「三同」：同档次、同商圈、同客群。五星（¥1,050）档次差太远会拉高竞组均价、让你的 ARI 虚低；10 公里外不同客源；经济型不在一个市场。只有 B 同时满足三同。
2. A　「三同」= 同档次（ADR ±20%）、同商圈（约 3 公里）、同客群。数量 3–5 家：太少受单店促销扰动，太多会混入不同档次。只选 1 家则样本不足。
3. B　竞组超过 5 家通常就会混入不同价格带的酒店，导致竞组均价不能代表你的真实竞争环境，指数反而失真。3–5 家为宜。
4. A　停业/装修期的酒店挂牌价不代表真实竞争，会污染竞组均价，让你的 ARI 虚高、从而不敢提价。应立即移出，恢复营业并价格稳定后再评估。
5. B　换 PMS 影响的是你自己的数据口径（应按 1.3 做口径校准），与竞组成员是否变化无关。换牌、停业装修、档次变动都会让该成员失去代表性，需立即复核。
6. C　固定频率保证不遗漏（每季度），事件触发保证及时性（新开、停业、换牌、档次变动）。两者缺一不可。
7. D　指数比较的前提是同口径。含早与不含早相差通常 ¥60–120/间，足以让 ARI 偏差 10 个点以上。必须先把早餐价值从本店 ADR 中剥离，或改用竞组的含早价。
8. B　RGI（收益指数）= MPI（渗透指数）× ARI（价格指数）。这个等式可以用来验算数据口径是否一致——偏差超过 2% 通常说明口径有问题。
9. C　这个等式是恒等关系，数学上必然成立。出现 5% 的偏差只可能是数据本身不同源——含税口径、含早口径、纳入房型范围或统计时间段不一致。

环节 2　年度预算与目标分解

10. C　÷12 会同时犯两个错：淡季为凑数低价甩卖（伤价），旺季早已卖满无房可提价（少赚）。必须按季节系数 × 日型分解。
11. D　季节系数解决「哪个月高哪个月低」，日型系数解决「周几高周几低」。两者相乘才能把年度目标合理拆到每一天。
12. D　按季节系数分解：3600 × 12% = 432 万。平均分（300 万）会让 7 月目标过低、早早卖完却不再提价，白白损失旺季溢价。
13. D　单指标必然被博弈。考核 OCC，前台就会用价格换出租率；考核 ADR，前台就会惜售导致高空置。必须成对考核，或直接用 RevPAR / GOPPAR。
14. D　单指标必然被博弈：只考核 OCC 会低价抛售，只考核 ADR 会惜售空置。成对考核或直接用 RevPAR / GOPPAR 才能避免。
15. A　NRevPAR 扣掉了佣金与渠道成本，能揭示不同渠道的真实净贡献。OTA 佣金约 15%、直销约 3%，这 12 个点的差异只有 NRevPAR 能体现。
16. C　连续同向偏差通常说明预算假设（季节系数、事件日历、客群结构）错了，属于模型问题；偶发偏差才是执行问题。先诊断再动手，否则会越纠越偏。
17. A　滚动预测 = 实际（已发生）+ 最新预测（未来 3 个月）。只看未来或只看过去都会让偏差发现得太晚。
18. C　±5% 是常用的行动阈值。太敏感（±1%）会被噪音干扰，太宽松（±20%）则错过纠偏窗口。连续两个月同向偏差通常说明是预算模型问题而非执行问题。

环节 3　价格体系与房型价差搭建

19. B　BAR 是「当日散客公开渠道可售的最高弹性房价」，必须贴近真实成交水平。用虚高的门市价当锚，会让所有折扣率失真、渠道价格打架。
20. A　BAR 是「当日散客公开渠道可售的最高弹性房价」，是整套价格体系的锚。注意它既不是最低价，也不是虚高的门市价。
21. D　以虚高价为锚去打折，会让协议价、会员价、OTA 价的折扣率全部失真，同一房型在不同渠道出现大差价，既引发客诉又破坏价格体系。
22. A　价差必须与可感知价值匹配。定太高，高价房无人付费，只能当升级池消耗掉，既损失收入又让真正愿意付费的客人觉得不值。
23. D　长期售罄 = 定低了，本可以卖更贵。长期空置 = 定高了。销售结构是校验价差最好的信号。
24. B　相邻房型价差通常 15%–25%，需与可感知的价值差异（面积、景观、设施、权益）匹配。太小客人全升级，太大高价房无人问津。
25. A　公开破价违反表 H：会被平台降权、被客人比价后投诉、并永久拉低价格锚。用权益做差异化，既能吸引直订又不伤价格体系。
26. C　公开挂牌价必须一致；差异只能通过权益实现（积分、取消政策、升级、早餐）。公开破价会被平台降权、被客人比价投诉，并永久拉低价格锚。
27. D　破价越早纠正损失越小。既要改回来，也要排查原因（手工改价？接口同步延迟？），否则会反复发生。把官网也降下来等于承认破价，是最糟的处理。

环节 4　数据采集与市场细分

28. D　没有干净的细分数据，就无法区分客群、无法差别定价、也算不准 No-show。补数据是地基工程，先于一切调价动作。
29. D　至少需要 24 个月日度数据，才能覆盖完整的季节周期与年度事件（节假日位移、展会周期），让季节系数有意义。
30. B　填报质量会随时间漂移（新人不会填、忙碌时乱填）。每月抽查才能维持数据可用性——脏数据是收益管理最大的隐性杀手。
31. A　提前期是最有效的分群维度之一：远期需求用折扣换确定性（早鸟锁量），临近需求更急、愿意付高价，应保留库存承接。统一价会两头都丢。
32. D　常用细分维度是渠道、提前期与价格敏感度。员工在职年限与客群划分无关。
33. C　远期客人计划性强、比价时间充裕，价格相对敏感，适合用早鸟折扣换确定性（提前锁量）。临期客人更急、更肯出高价。
34. B　超售要按「No-show + 取消」的合计来算。实际 20% 却只超售 5 间（约 1.6%），意味着大量本可补卖的房夜被浪费。当然超售上限还要受房量 5% 等约束。
35. B　No-show 率 = 预订未到店 ÷ 预订量。它与取消率是两个独立参数，都要统计，合计后才作为超售计算的输入。
36. D　No-show 与取消率会随预付占比、取消政策、客群结构变化而变，必须每月重算。参数变了超售就得跟着变，否则要么浪费、要么步行。

环节 5　需求预测与在手追踪

37. D　周末与工作日的需求差异，往往远大于不同月份之间的差异。颗粒度只到月或周，就会把周末的溢价空间和平日的放量需求一起抹平。
38. B　如果颗粒度只到月或周，周末的溢价空间与平日的放量需求会被一起抹平，导致周末卖便宜、平日卖不动。
39. D　基线 = 历史同期 × 季节系数 + 当前在手预订。员工排班属于运营安排，不是需求预测的输入。
40. A　在手量的绝对值会骗人，增速才是先行指标。增速远高于历史同档，说明需求正在快速涌入，此时降价等于把后期的钱提前送掉。
41. C　Pickup 是一段时间内的新增预订量，代表需求的「增速」。看增速而不是某一时点的绝对值，才能提前判断需求强弱。
42. B　在手量高但增速停滞，说明后续没有新增需求涌入，很可能就停在 60% 左右。此时应考虑放量（如尾单），而不是提价。
43. A　花期、迁徙、赛事这类事件的日期每年会前后移动 7–14 天，而模型基于「去年同期 + 平滑」，天生捕捉不到这种位移。这是结构性缺陷，必须靠事件日历人工补位。
44. A　事件日历要记录的是会影响需求的外部事件，并标注历史日期与波动幅度，供次年校准预测使用。这是模型补不了的部分。
45. B　提前 30 天把价格提到旺季档并设 MinLOS，才能吃到早期需求；等需求上来了再提，早期预订已按低价卖掉了。

环节 6　日型划分与库存分配

46. A　只用两档会把一年中最好的几天（展会、节假日核心日）按普通周末价卖掉。这些日子需求刚性、价格极不敏感，是全年溢价空间最大的窗口，损失不可逆。
47. A　日型按需求强度分四档：D1 峰值（展会/节假日核心日）、D2 高涨（周末/旺季）、D3 平峰（普通工作日）、D4 低谷（淡季/周日）。这个划分决定价格档与库存策略。
48. B　峰值日（展会、节假日核心日）需求刚性、客人转换成本高，价格敏感度低，是全年溢价空间最大的窗口。平峰日则相反，提价容易掉量。
49. A　没有嵌套，各房型库存互不相通，就会出现「高价房卖完了、低价房还空着」的结构错配。嵌套让高价房型可以吃掉下级的剩余量。
50. D　嵌套式库存：高价房型可用量 = 自身 + 所有下级房型余量，卖出后从最低可用级开始扣减。这样既不会过早关闭高价房型，也不会让高价需求挤占低价房。
51. A　各房型库存互不相通时，会出现「高级房卖完了、标准房还空着」的错配：想订高级房的被拒，标准房却卖不掉，整体 OCC 上不去。
52. A　预留不设时限或到期不释放，会把本可散卖的房量长期锁死。约定就是约定，到期释放并立即补挂渠道，才能赶上散客需求窗口。
53. A　T-14 是常用约定。到期未确认自动释放并立即补挂全渠道，才能赶上散客需求窗口。永不释放会把本可散卖的房长期锁死。
54. C　释放只是第一步，必须立即补挂到各公开渠道，否则这段时间实际上还是「不可售」，白白浪费。这一步最容易被漏掉。

环节 7　动态定价

55. A　「OCC 高 + ARI 低」是最典型的「卖满了却没卖贵」。此时提价的风险最小、收益最大，应小步多次（每次 2%–3%）提价并观察 OCC 反应。
56. B　小步快跑（2%–3%）便于观察市场反应、可随时刹车；一次性大幅提价容易吓退需求且不可逆。单日累计通常不超过 8%。
57. B　刹车线是提价的安全阀。例如约定 OCC 跌破 82% 立即暂停提价，避免为了追 ADR 把量也追丢了，最终 RevPAR 反而下降。
58. A　公开甩卖会永久拉低价格锚；完全不卖则房晚归零。正确做法是牌价不动、用限时与隔离渠道清仓，且成交价只要高于变动成本（本例 ¥180）就比空着强。
59. A　房晚易逝，空着就是零。只要成交价高于单房变动成本（清洁+布草+易耗+水电+早餐），卖掉就有正贡献。低于变动成本则卖得越多亏得越多。
60. B　公开降牌价会永久拉低客人的价格认知并影响后续议价；限时 + 隔离渠道（会员/小程序/最后一分钟产品）只作用于当天剩余房量，代价最小。
61. B　三个指标都处于健康区间时，最优动作就是不动。频繁调价会打乱价格预期、增加执行成本，反而损害收益。守价也是一种决策。
62. A　守价的典型区间是：在手量合理（平峰 50%–75%）、增速与历史同档接近、ARI 在 95–105 之间。三个都健康时最优动作就是不动。
63. D　每次调价都有执行成本与沟通成本，还会让价格信号变得不可信。指标健康时保持稳定，反而有利于建立稳定的价格预期。

环节 8　库存控制与超售

64. D　需求强时继续开放低价房型，等于用低价把高价需求挤走。关闭低价房型 + 设最短住期，才能把有限的房量分配给肯出高价、住得久的客人。
65. A　MinLOS 是需求强时的筛选工具：设 2–3 晚可过滤掉短住低价需求，把有限房量分配给住得久、价值更高的客人。需求弱时应取消以承接短住。
66. B　多渠道环境下，改完配置必须逐个渠道核对同步结果。本案例就曾因漏同步一家 OTA，导致该平台仍按旧价卖出 22 间，损失约 ¥1.4 万。
67. C　不超售会把可补卖的房白白浪费；超售超过预期 No-show 则必然步行。正确区间是「不超过预期 No-show」且「不超过房量 5%」——本例约 16 间（房量 5%）。注意两个约束取小值。
68. A　两个约束取小值：① 不超过预期 No-show（否则会步行）；② 通常不超过房量的 5%（控制风险暴露）。

70. A　保证订房（担保卡已扣款）具有最强的履约义务，walk 掉这类客人既违约又最容易引发公开投诉。超售扣减应从「不保证」的订单开始。
71. A　行业惯例约按「房费 1.5 倍 + ¥300 安置费」赔付，并承担交通与差价。此外还有难以量化的口碑损失，所以预防（算准超售）远比事后赔付划算。

73. A　需求强时不需要靠 OTA 走量，反而应该把有限的房量留给净贡献更高的直销与高价渠道。原则是「旺季控渠道、淡季借渠道」。

78. D　直销占比提升的核心收益是省下佣金，直接体现在 NRevPAR 上升。OCC 与 ADR 不一定同步上升（甚至可能微降），但净利润会改善。
79. A　全服务酒店的会议价值 = 客房 + 餐饮 + 会场 + 设备。只看客房会把划算的会误拒；但置换损失要按「本可卖出的间夜」算，按满房算会高估损失。

82. B　表 M 的顺序是：07:30 取数 → 08:10 比价 → 08:30 查表 → 09:10 执行 → 17:00 巡检。先有数据、再比竞对、然后查表，顺序不能颠倒。

第二部分　答案与解析

一 · 业态与星级

1. B　置换分析算的是「本可卖出的间夜」。直接按满房间夜算会严重高估损失，从而误拒一个划算的会议单。本例历史 OCC 仅 62%，散客实际只能卖出约 279 间夜，而非 380 间。
2. C　表 K 是「会议／宴会综合收益联动表」：会议价值 = 客房 + 餐饮 + 会场租金 + 设备/其他。本例客房净收益仅 +¥3.2 万，但餐饮会场净贡献约 ¥52 万，综合 +¥55 万——只看客房会误拒。
3. D　一刀切提价会流失核心客户；分层处理才能既提 ADR 又保住量。本例后 40% 的协议公司只贡献 8% 间夜，却占着最低价——这部分才是问题所在。
4. C　没有有效期和保量条款，价格就会变成刚性——市场涨了你也涨不了。本例正是三年前签了无期限最低价，导致 ADR 被锁死三年。
5. C　公开破价违反表 H 价格一致，会被平台降权、被客人比价后投诉，还会永久拉低价格锚。用权益做差异化才能既提直订又不伤价格体系。
6. D　RevPAR 与 ADR 都不含渠道成本。OTA 佣金约 15%、直销成本约 3%，中间 12 个点就是利润差异——只有 NRevPAR 能看出来。
7. A　闭店省下的成本是显性的，但 OTA 排名、搜索权重、会员心智的流失是隐性的，次年重开要花更大代价才能拿回来。这类成本必须写进决策。
8. B　「买二送一」在客人感知里是优惠，在账面上保住了牌价；而直接降牌价会拉低价格锚并污染公开渠道。本例用 ¥1,299/3 晚套餐把 OCC 从 28% 拉到 47%。
9. D　配比必须是动态的。只用当月到期的房源做短租，短租永远不会侵蚀长租基本盘；展会月全部转短租，非展会月优先续约。
10. B　降租会体现在合同价上，续签、评估、新客报价都会被拉低；免租期是一次性优惠，账面租金仍可维持并逐年上调。本例续约涨 4% 而非市场价 8%，差额以免租期补偿。
11. D　小体量永远打不赢价格战。把「房间」卖成「体验」，客人比价的维度就变了；再把 OTA 当曝光，用内容把人引到私域成交，才能摆脱佣金。本例直订从 22% 升到 63%。
12. C　公开破价违反表 H，会被平台降权、被客人比价投诉，还会永久拉低价格锚；全部下架则直接失去曝光，小店承受不起。小店的流量不来自预算，来自内容——把 OTA 当「广告位」，成交引回私域，佣金才能降到接近零。本例直订占比从 22% 升到 63%。
13. A　99 × (1−15%) = ¥84.15 < 变动成本 ¥95，卖得越多亏得越多，还会把客人的价格锚永久拉到三位数以下。
14. D　底线是成交价必须高于变动成本。用权益包提升感知价值，用限时尾单在 17:00 后清剩余房量，既参与竞争又不破牌价。

二 · 经济周期

15. A　RGI 100 是「假持平」：MPI>100 说明抢到份额，ARI<100 说明是用低价换的。在需求普涨 22% 而 ADR 只涨 4% 时，典型的漏损就是不敢提价。
16. A　一次性大幅提价容易吓退需求且不可逆；小步快跑可以随时观察反应。设刹车线（如 OCC 跌破 82% 暂停）能防止过量。
17. D　降价 15% 后 RevPAR 需靠 OCC 提升约 9pp 才能打平，但整体需求在萎缩，这个增量几乎不可能——所以降价大概率是净损失。
18. A　降价解决不了需求萎缩。转向相对稳定的本地客群（考试、陪护、微度假），用权益而非降价留住协议客，再用餐饮二消补客房缺口，才是可持续的。
19. B　单一信号容易误判。三个信号交叉验证能显著降低风险：增速连续 3 周 >30%、竞对已提价、未来 30 天在手量达去年同期的 112%。
20. B　远期客人计划性强、比价成本低但价格敏感度相对低；临近期需求更急、对价格更敏感。先提远期可以在不影响近期转化的情况下试探市场。

三 · 季节

21. A　本例：立即按 ¥880 卖得 ¥10,560；等到 T-1 有 80% 概率以 ¥1,800+ 卖出 = ¥21,600。用期望值算，等待更优。这是可量化的判断，不是拍脑袋。
22. B　等待是有风险的。设兜底（本例 T-1 下午 ¥1,280 释放）能把最坏情况锁定在可接受区间——本例最终 12 间平均 ¥1,720 售出。
23. A　周末需求不是「同样的客人嫌贵」，而是「商务客根本不来」。换客群、换产品才是解法；降价只会拉低平日价格锚。
24. A　周末套餐摊薄了 ADR，但带来了餐饮与联名收入。只看 ADR 会低估周末改造的价值，应看 TrevPAR 甚至 GOPPAR。
25. C　花期、迁徙、赛事这类事件每年日期会前后移动 7–14 天，而模型基于「去年同期+平滑」，无法捕捉这种位移。这是结构性缺陷，不是数据量的事。
26. B　模型补不了的部分要靠机制补：事件日历把外部变量显性化，校准会在换季前统一修正，监控频率提高则保证发现及时。

四 · 节假日

27. B　除夕–初三本地人回家过年、需求低；初四–初七旅游与返程叠加、需求爆满。统一价会导致前段空置、后段没赚够。
28. D　用餐饮把客房价值包起来，既保住了牌价又拉高了 OCC 与 TrevPAR。本例前段 OCC 从 32% 升到 61%，餐饮收入同比 +34%。
29. C　到达目的地后，更换酒店的时间与交通成本很高，需求接近刚性——这是溢价能力最强的窗口。而 D1 出发日游客仍在比价，弹性大得多。
30. C　早鸟的目的是锁量，应该用在需求弱的日型；把核心日放进早鸟等于把最高的价格提前打折卖掉。
31. C　本例 T-11 在手仅 38% 看似疲软，但 T-6 已升到 61%（+23pp/5 天）。只看绝对值会误判降价，把后面爆发的需求低价卖光。
32. C　短假期窗口短、变化快，临场判断容易被情绪左右。预设阈值（在手<50% 且增速<10pp/周 → 降；50–75% → 守；>75% 或增速>20pp/周 → 提）能让动作稳定可复现。
33. D　限制长住会产生大量难以补满的「空档日」。长住客的价值是稳定高 OCC 与可预期的二消，应该用产品和二消把这块价值兑现。
34. A　家庭客的客房 ADR 弹性小，但餐饮、儿童俱乐部等二消弹性大。只看 ADR 会低估暑期，应看 TrevPAR。

五 · 特殊事件

35. B　展会需求刚性且价格不敏感，几乎不存在卖不掉的风险；真正的漏损是核心三日被早鸟或保守定价提前锁死。
36. A　展会客多为刚性出行，No-show 远低于平日。沿用月度参数会超售过度，产生步行客人与赔付。本例重算后零步行。
37. B　本例比竞对晚知道 40 分钟，直接决定了可操作空间。第一次 2 小时售罄说明定低了；建立活动监控清单后，第二次 15 分钟内提价，多赚 ¥3.4 万。
38. C　售罄速度是价格信号。快速售罄意味着需求远大于供给，此时加价仍能卖出大部分房源，总收入更高。
39. A　本例直接机会成本 ¥22.9 万，但政务接待资质与次年会议资源是隐性收益，赛事取消风险则被包场对冲。三笔账合看才不会误判。
40. C　折中方案能同时拿到确定性收益与上行空间；合同写「若赛事取消，剩余房量可自由销售」则把风险也管住了。
41. D　不可抗力硬扛会引发舆情与平台处罚；但直接全部取消则损失未来收入。本例改期转化率 41%，保留了 ¥18 万的未来收入。
42. B　灾害期间恶意抬价有合规风险，且会永久伤害品牌。本例仅 +10%，换来零投诉与 OTA 评分上升 0.12，长期收益远大于短期溢价。
43. C　本例测算：降价到 ¥700 后 RevPAR ¥497，反而低于维持 ¥880 的 ¥685。根因是服务缺陷，降价只是把问题放大。
44. D　补偿包成本 ¥85/间远低于降价 ¥180/间，且不会拉低价格锚；把可售房量控制在 85% 能留出服务余量，避免边修边新增差评。
45. B　同样一次接口异常，3 小时 20 分才发现损失 ¥21.7 万；若有告警在 10 分钟内熔断，损失可控制在 ¥2 万以内。速度决定损失量级。
46. C　告警负责「发现得快」，熔断负责「自动止损」，巡检负责「兜底复核」。三层缺一，就会重演本例的 3 小时空窗。
47. B　本例测算：跟降到 ¥520 后 RevPAR ¥374，反而低于维持 ¥640 的 ¥390。而且促销期通常 3–6 个月，跟降是长期损失换短期安慰。
48. C　本店优势是老客户、协议客、本地餐饮与停车——这些是硬件劣势无法复制的。把省下的降价空间用于翻新，冲击期反而是最好的施工窗口。
