# 第 21 章 · 年度预算：把一年拆到每天 教案

> 教材定位：第三篇 · 运营篇 ｜ 模块 E · 计划与支撑 ｜ 第 21 章 ｜ 建议课时：2 课时（每课时 90 分钟）｜ 配套正文：教材第 21 章
> 配套资源：教师用书同章（`textbook-teacher.html#tch21`）｜ 学员自学页：`learn.html#ch21`

## 一、学完这一章，学生能做到什么

- 读完能做：把一个年度目标，变成每天该卖多少钱、留多少房。
- 月指数：每个月的生意占全年的比例（淡旺不同，绝不能平均分成十二份）。
- 拆解链路：年度目标 → 月 → 周 → 日，且同时拆房量与房价（双目标）。
- 年中校准一次：7 月用上半年实际重算下半年（唯一一次正式修订）。

## 三、讲这一章要用的公式与定义

- **核心公式**：月指数 = 该月历史 RevPAR ÷ 全年月均 RevPAR 月目标 = 年度目标 × 月指数 日目标 = 月目标 ÷ 天数（再按星期几微调）
- **算例 3 · 一次年中滚动重算**：年度目标 3,000 万 上半年实际 1,320 万（预算 1,400 万，缺口 −80 万） 下半年原预算 1,600 万 选项甲：把缺口全部压到下半年 → 下半年需 1,680 万（+5%） 选项乙：申请下调年度目标至 2,920 万 → 下半年 1,600 万 选项丙：重新评估市场，下调至 2,880 万并配套新策略

## 四、讲这一章要用的判定表

### 本章判定表 · 预算做得对不对

| 判据 | 结论 |
|---|---|
| 是否用月指数 | 必须；平均分成十二份 = 错误 |
| 历史数据年限 | 2–3 年加权，剔除异常年 |
| 是否双目标 | 必须有房量(OCC) + 房价(ADR)双目标——只有收入会被"降价换量"蒙混 |
| 是否拆到日 | 拆到日才有每日判据；停在月度无法执行 |
| 修订频率 | 一年只允许年中一次正式修订；频繁改等于没有预算 |
| 是否宣贯 | 分解到部门与责任人，否则只是财务的数字 |
| 是否含市场假设 | 增长、新竞品、政策变化要写下来，否则年底无法归因 |

### 场景：年底验收明年的预算方案

| 判据 | 结论 |
|---|---|
| 用月指数了吗？ | 按月指数分解 → ✓（若平均分成 12 份 → ✗） |
| 历史年限 | 用近 3 年加权，剔除 1 个异常年 → ✓ |
| 有双目标吗？ | 同时给出 OCC 与 ADR → ✓ |
| 拆到日了吗？ | 按星期几加权拆到日 → ✓ |
| 有市场假设吗？ | 写明"新竞品 Q3 开业、预计分流 5%" → ✓ |
| 宣贯了吗？ | 已分解到前厅/销售/市场并签字 → ✓ |
| 修订机制 | 写明"仅 7 月一次滚动重算" → ✓ |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| 老板给了年度数字 | 先问"怎么拆""何时校准"——这两句比数字本身重要 |
| 各部门说"目标是财务的" | 做预算宣贯：前厅领 OCC、销售领 ADR、市场领渠道结构 |
| 淡季月月完不成 | 多半是平均分成十二份了 → 改用月指数 |
| 用降价完成了收入目标 | 说明缺双目标（OCC+ADR）→ 补上 |
| 上半年没达标 | 7 月滚动重算；偏差要连同补救措施一起上报，不能只改数字 |


## 五、课堂案例（直接用正文里的）

### 案例 · 两个版本的预算

A 店：3,000 万 ÷ 12 = 每月 250 万。B 店：按月指数分解，旺季月 340 万、淡季月 160 万。 结果：A 店淡季月月完不成、团队士气低落；旺季月月超额但没多加价（因为目标太低，没人有动力）。 / B 店每月目标贴合实际，旺季敢加价、淡季会做促销。 / 年底 B 店完成 3,120 万，A 店 2,780 万。 / 同样的目标，拆法不同，结果不同。

### 案例三 · 预算里的市场假设救了一次复盘

某店年度目标差 9% 未完成。年底复盘时，团队差点被定性为"执行力差"。 由于年初预算里写明了三条市场假设（两条竞品新开业、一条地铁施工围挡），复盘时逐条核对： / 三条假设全部发生，且实际影响大于预估。 / 结论修正为：市场影响约 −11%，团队实际超额完成相对目标。 / 结论：没有市场假设的预算，年底只能靠吵架收场；有了它，复盘才有依据。

### 案例四 · 一次预算宣贯会（含对话）

年初预算宣贯： / 总经理："今年 3,200 万，我来讲怎么分。" / 前厅："我这边是多少？" / 总经理："你负责 OCC 目标：全年 76%，其中 8 月要 90%。这意味着你要配合超售与升级池的安排。" / 销售："我？" / 总经理："你负责 ADR 目标：全年 520。协议价重谈后，平均不能低于 460。" / 市场："我？" / 总经理："你负责渠道结构：直销从 20% 提到 28%。" / 收益："我负责把这三个目标拆到每一天，并每周复查缺口。" 关键点：预算不是财务的数字，是四个部门各自认领的目标。 / 一年后的结果：完成 3,240 万（102%）。而未宣贯的前一年只完成 91%。 / 结论：同样的目标，宣贯到人与不宣贯，执行力差出一个数量级。因为没认领的目标，没人会为它调整自己的日常动作。


## 六、容易讲错的地方

- 自学者提示：做预算最容易犯的错是"用单一年份算月指数"。某年有个偶然大单，会把该月指数抬歪。至少用 2–3 年加权，并剔除异常年。

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- 算例：年度目标 3,000 万，全年月均 250 万。 / 8 月历史 RevPAR 高，月指数 1.3 → 8 月目标 = 250 × 1.3 = 325 万。 / 2 月淡季，月指数 0.6 → 目标 150 万。 / 若平均分成十二份，每月 250 万——8 月会轻松超额、2 月永远完不成，预算失去指导意义。
- 推荐：甲或丙，不推荐乙。 / 乙的问题在于"悄悄把目标改小"而不改变打法——这会让预算失去意义。 / 正确做法：偏差必须显性化，并连同"补救措施"一起上报。要么加码下半年动作，要么正式下调并说明原因与对策。 / 这就是"一年只允许修订一次"的原因——它逼你把偏差讲清楚，而不是随手改数字。
- 用法：年度预算验收清单：有月指数、有双目标、拆到日、有市场假设、已宣贯到人——五条全有才算合格预算。填表示例 · 这份预算合格吗场景：年底验收明年的预算方案 用月指数了吗？按月指数分解 → ✓（若平均分成 12 份 → ✗） 历史年限用近 3 年加权，剔除 1 个异常年 → ✓ 有双目标吗？同时给出 OCC 与 ADR → ✓ 拆到日了吗？按星期几加权拆到日 → ✓ 有市场假设吗？写明"新竞品 Q3 开业、预计分流 5%" → ✓ 宣贯了吗？已分解到前厅/销售/市场并签字 → ✓ 修订机制写明"仅 7 月一次滚动重算" → ✓ 结论：七项全中 → 合格预算。 / 最常被漏掉的是第 5 行"市场
- 练习 年度 2,400 万，月均 200 万，某月月指数 1.45，求该月目标。 为什么预算要同时有房量和房价目标？ 为什么一年只允许年中修订一次？ 若某店只有收入目标，团队可能用什么方式"蒙混过关"？ 列出合格预算的五条验收标准。 本章小结（5 条，可复述） 月指数＝该月历史 RevPAR ÷ 全年月均；目标 × 月指数 = 月目标。 绝不能平均分成十二份——会让旺季没动力、淡季永远完不成。 双目标：OCC ＋ ADR，防止"降价换量"蒙混过关。 拆到日才有每日判据；停在月度无法执行。 写市场假设（新竞品、政策变化），否则年底无法复盘归因。
