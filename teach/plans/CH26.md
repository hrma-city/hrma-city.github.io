# 第 26 章 · 成本与利润：降价的底线在哪 教案

> 教材定位：第四篇 · 组织篇 ｜ 组织与支撑 ｜ 第 26 章 ｜ 建议课时：2 课时（每课时 90 分钟）｜ 配套正文：教材第 26 章

## 一、学完这一章，学生能做到什么

- 读完能说出：这间房最低能卖多少钱——低于这个数就是亏。
- 变动成本：随每卖一间而发生的成本（洗涤、易耗品、能耗、早餐、佣金、返现）。
- 边际贡献 ＝ 净价 − 变动成本。
- 只要边际贡献为正，卖就比空着好——因为固定成本照付。
- 降价的绝对底线是变动成本，不是"看起来别太离谱"。
- 但还要注意机会成本（第 12 章）。

## 三、讲这一章要用的公式与定义

- **核心公式**：边际贡献 = 净价 − 变动成本 保本出租率 = 固定成本 ÷ (ADR − 变动成本) ÷ 可售房数 GOPPAR = 经营毛利 ÷ 可售房数（真正的经营指标）
- **算例 3 · RevPAR 与 GOPPAR 的背离**：A 店：OCC 85% × ADR 380 = RevPAR 323 但 70% 走 OTA（佣金 15%）→ 净 RevPAR ≈ 285 减变动成本 120 → GOPPAR ≈ 165 B 店：OCC 72% × ADR 450 = RevPAR 324 直销占 45% → 净 RevPAR ≈ 305 减变动成本 120 → GOPPAR ≈ 185

## 四、讲这一章要用的判定表

### 本章判定表 · 这个价能不能卖

| 判据 | 结论 |
|---|---|
| 净价 − 变动成本 &gt; 0 | 是 → 可以卖（比空着好）；否 → 绝对不卖 |
| 变动成本含哪些 | 洗涤、易耗品、能耗、早餐、佣金、渠道返现 |
| 是否含固定成本 | 短期决策不含（房租人工照付）；长期定价必须覆盖 |
| 是否考虑机会成本 | 若还有高价客可能来 → 底线应高于变动成本（第 12 章） |
| 是否用净价算 | 必须用扣佣后的净价，不是售价（第 13 章） |
| 终极指标 | RevPAR 不够，要看 GOPPAR |
| 红线 | 任何低于变动成本的销售，无论多"划算"都不做 |

### 场景：销售要求放出 199 元特价冲量（平日 BAR 450）

| 判据 | 结论 |
|---|---|
| 净价多少？ | 199 走 OTA（佣金 15%）→ 净价 169 |
| 变动成本？ | 150（含洗涤、能耗、早餐） |
| 边际贡献 | 169 − 150 = 19 &gt; 0 → 勉强为正 |
| 机会成本？ | 若这些房本可卖 450 → 每间损失 281 → 巨大 |
| 有栅栏吗？ | 面向全体 → 无栅栏 ✗ |
| 限量吗？ | 不限量 → ✗ |
| 综合判定 | 边际贡献仅 19，机会成本 281 → 严重不划算，否决 |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| 有人提"卖一点是一点" | 先问净价与变动成本；低于成本坚决不卖 |
| 长期低价客源要不要保留 | 重算：净价 vs 变动成本 vs 机会成本，三者一起看 |
| RevPAR 达标但利润没达标 | 查渠道结构与GOPPAR——收入相同利润可差很多 |
| 要不要停业装修 | 算保本点；安排在客流最低的时段（亏得最少） |
| 不知道变动成本 | 今天就向财务要：每间房多少、含不含早餐 |


## 五、课堂案例（直接用正文里的）

### 案例 · "填满房"如何毁灭利润

某店为冲出租率，把大量房量以 199 元投给低价渠道。出租率冲到 92%，全店庆祝。 财务核算：变动成本 120，边际贡献仅 79；而这些房量挤掉了原本可卖 450 的散客。 / 剔除渠道佣金后，当月 GOP 反而低于上月（出租率 78% 但均价高）。 / 结论：出租率是手段，GOP 是目的。用降价换来的出租率，常常是负资产。

### 案例三 · 保本点救了一次决策

某店淡季考虑停业装修两周。用保本点测算：月固定成本 60 万，ADR 400，变动成本 120 → 保本需卖约 2,143 间/月（日均 71 间）。 而淡季实际日均仅 45 间——即便不装修，这半个月本来也是亏的。 / 于是决定：停业装修，且安排在客流最低的两周。 / 结论：保本点不只是用来"算要卖多少"，它还能告诉你"什么时候亏得最少"——这直接影响停业、检修、淡季策略等重大决策。

### 案例四 · 一次"砍掉亏损生意"

某店有一批长期的低价团队客（300 间/月 @280），一直被视为"基础盘"。 / 用成本与置换口径重算： / · 净价：280 走批发（佣金 10%）→ 252 / · 变动成本：150 → 边际贡献 102/间 / · 机会成本：这些房在平季可卖 480 → 每间损失 228 / · 月合计：300 × 228 = 68,400 元的隐性损失 决策：不全部砍掉（会伤关系），而是提价到 380 并限量 150 间/月，剩余房量投向商务协议与会员。 / 三个月后：该客户接受了一半的量与提价；释放的 150 间以均价 470 卖出。 / 月贡献变化：原 30,600 → 新（150×230 + 150×320）= 82,500。 / 结论："基础盘"常常是最该重新审视的部分——因为它太久没被算过账。不知道变动成本，就永远不知道自己在亏什么。


## 六、容易讲错的地方

- 自学者提示：今天就去问财务一个数：每间房的变动成本是多少，含不含早餐。没有这个数，你所有的降价决策都是在赌——而这通常是收益岗最容易忽略、也最该先搞清楚的一个数字。

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- 算例 1（底线）：售价 300，变动成本 120 → 边际贡献 180（&gt;0，值得卖）。 / 售价 200 → 边际贡献 80（&gt;0，仍比空着好）。 / 售价 100 → 边际贡献 −20（&lt;0，卖一间亏一间）。 / 所以底线不是"不亏"，是"边际贡献为正"——哪怕只赚 80，也比空房的 0 好。 / / 算例 2（保本点）：100 间房，月固定成本 60 万，ADR 450，变动成本 120。 / 每间边际贡献 330 → 需卖 600,000 ÷ 330 ≈ 1,818 间/月 → 日均 60 间 → 保本出租率 60%。
- 两店 RevPAR 几乎相同，但 B 店 GOPPAR 高 20。 / 若只考核 RevPAR，A 店经理会觉得"我和 B 店一样好"——实际差 12% 的利润。 / 结论：这就是为什么第 2 章说"RevPAR 之上还有 GOPPAR"。收入相同的生意，利润可以差很多。
- 用法：今天就向财务要一个数：每间房的变动成本是多少，含不含早餐。把它写在判定表顶部。填表示例 · 这个特价能不能放场景：销售要求放出 199 元特价冲量（平日 BAR 450） 净价多少？199 走 OTA（佣金 15%）→ 净价 169 变动成本？150（含洗涤、能耗、早餐） 边际贡献169 − 150 = 19 &gt; 0 → 勉强为正 机会成本？若这些房本可卖 450 → 每间损失 281 → 巨大 有栅栏吗？面向全体 → 无栅栏 ✗ 限量吗？不限量 → ✗ 综合判定边际贡献仅 19，机会成本 281 → 严重不划算，否决 结论：否决。 / 注意第 3、4 行的对比——"边际贡献为正"
- 练习 净价 260，变动成本 130，边际贡献多少？该卖吗？ 为什么说"边际贡献为正就比空着好"，但又说"不能只看这个"？ 为什么终极指标是 GOPPAR 而不是 RevPAR？ 100 间房、月固定成本 50 万、ADR 400、变动成本 100，求保本出租率。 为什么算贡献必须用净价而不是售价？ 本章小结（5 条，可复述） 变动成本：洗涤、易耗、能耗、早餐、佣金、返现（要向财务要完整清单）。 边际贡献＝净价 − 变动成本；为正才比空着好。 降价的绝对底线是变动成本，不是"看起来别太离谱"。 还要比机会成本：本可卖给高价客的部分，才是真实损失。 终极指标是 GOPPAR：RevPAR 相同，
