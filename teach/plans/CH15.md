# 第 15 章 · 团队置换：这个团该不该接 教案

> 教材定位：第二篇 · 决策篇 ｜ 模块 C · 客源与渠道决策 ｜ 第 15 章 ｜ 建议课时：2 课时（每课时 90 分钟）｜ 配套正文：教材第 15 章

## 一、学完这一章，学生能做到什么

- 读完能算清：一个 50 间的大团，是机会还是陷阱。
- 置换分析：接团前先算这个团会挤掉多少散客、被挤掉的散客本来能卖多少钱。
- 团队价底线：团队价 × 团房量必须 ≥ 被挤掉散客的期望收益（不是散客的实际收入）。
- 期望收益要乘概率：散客不一定会来，所以要按历史概率折算——这是最容易被忽略的一步。

## 三、讲这一章要用的公式与定义

- **核心公式**：置换净收益 = 团队收入 − 被挤掉散客的期望收益 被挤掉散客期望收益 = 预计散客需求 × 散客净价 接受条件：团队收入 ≥ 被挤掉散客期望收益
- **算例 3 · 最优团量的推导**：剩 60 间，散客期望需求 25 间（净价 600），团队价 400 接 0 间 ：散客期望 25×600 = 15,000 接 20 间：20×400 + 剩余散客 25×600 = 8,000+15,000 = 23,000 接 35 间：35×400 + (60−40 限) ... 散客被挤至 0 → 14,000 最优 ：剩房 60 − 散客期望 25 = 接 35 间以内，但需保证散客 25 间不被占

## 四、讲这一章要用的判定表

### 本章判定表 · 团队接不接、接多少

| 判据 | 结论 |
|---|---|
| 团量 vs 剩余房量 | 团量 ≤ 剩余的 50% → 通常可接；占比过高 → 谨慎 |
| 散客期望需求 | 历史散客需求强 → 少接；需求弱 → 多接 |
| 团队价 vs 散客净价 | 团队价 ≥ 散客净价 × 70% → 可谈；低于 60% → 基本不接 |
| 团队取消率 | 高取消率的团要按期望值算（不是按满团算） |
| 是否含其他消费 | 含餐、含会议 → 计入综合贡献，可提高接受度（第 30 章） |
| 是否旺季 | 旺季/紧俏日 → 严控团队量；淡季 → 可放宽 |
| 最优团量 | 通常 = 剩余房量 − 散客期望需求 |

### 场景：旺季周三，剩 50 间，团队要 40 间 @380

| 判据 | 结论 |
|---|---|
| 团量 vs 剩余 | 40/50 = 80% → 占比过高 ✗ |
| 散客期望需求 | 历史散客期望 22 间，净价 600 → 期望收益 13,200 |
| 团队价 vs 散客净价 | 380/600 = 63% → 低于 70% 门槛 ✗ |
| 团队取消率 | 历史该团队取消 15% → 按期望 34 间算 |
| 含其他消费？ | 含午餐（贡献约 40/人）→ 可适当放宽 ✓ |
| 是否旺季？ | 是 → 严控 ✗ |
| 最优团量 | 50 − 22 = 28 间（留 10% 余量 → 接 25 间） |
| 谈判建议 | 接 25 间，或提价到 460 接 40 间 |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| 销售问"这个团接不接" | 改问"接多少"：最优团量 = 剩余房 − 散客期望需求 |
| 客户要的量超过最优团量 | 提价：团价提到"团收入 ≥ 散客期望收益"为止 |
| 淡季来团 | 散客机会成本低 → 可以放宽，甚至是好生意 |
| 旺季来团 | 散客机会成本高 → 严控，或改期/提价 |
| 团队含餐含会 | 计入综合贡献，会改变结论（第 30 章） |
| 团队临时缩规模 | 合同必须约定阶梯与违约，否则酒店承担全部损失 |


## 五、课堂案例（直接用正文里的）

### 案例一 · 只接一半反而更好

旺季某周，团队要 50 间 @380。历史散客期望需求 35 间，散客净价 600。见算例 3。 全接亏 2,000，只接 15 间最优（合计 26,700）。 / 销售起初不理解，看到对比数据后改为只接 15 间，并把剩余房量推给散客渠道。 / 结论：会算置换，销售才能把"拒绝"变成"有条件地接受"。

### 案例二 · 淡季的团队是好生意

淡季周三，剩余 70 间，散客期望需求仅 15 间。团队要 40 间 @320。 散客期望收益 = 15 × 550 = 8,250；团队收入 = 40 × 320 = 12,800。 / 12,800 &gt; 8,250，且团量（40）远低于剩余（70）→ 该接，甚至可以多接。 / 结论：淡季散客机会成本低，团队是填量的好生意。同一个价，在不同日子是两笔完全不同的生意。

### 案例三 · 淡季的团队好生意

淡季周二，剩 70 间，散客期望仅 12 间。团队要 45 间 @330。 散客期望收益 = 12 × 550 = 6,600；团队收入 = 45 × 330 = 14,850。 / 14,850 &gt; 6,600，且团量（45）远低于剩余（70）→ 该接，甚至可以多接。 / 结论：淡季散客机会成本低，团队是填量的好生意。同一个价、同一个客户，在不同日子是两笔完全不同的生意。


## 六、容易讲错的地方

- 自学者提示：置换分析的核心是"期望"二字。散客需求是不确定的，所以要用历史概率折算，不能只看"昨天散客卖了 35 间"——那是一个已经发生的结果，不是期望。

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- 算例 1（不该接）：某日剩 40 间。团队要 30 间 @350，收入 10,500。 / 历史显示该日散客需求期望 25 间（不一定来满），散客净价 550 → 期望收益 13,750。 / 10,500 &lt; 13,750 → 不该接（或只接 10–15 间）。 / / 算例 2（临界）：若团队价提到 460：30 × 460 = 13,800 ≥ 13,750 → 临界，可以接。 / / 算例 3（接多少）：旺季某周，团队要 50 间 @380，散客期望需求 35 间、净价 600。 / 全接：19,000 − 21,000 = −2,000（亏）。 / 只接 15 间：15×380
- 更精确的做法：接团量 = 剩余房 − 散客期望需求 = 60 − 25 = 35 间（临界）。 / 实际操作中留 10–20% 余量，通常接 25–30 间。 / 结论：最优解常常是"部分接受"，而不是全接或全拒。

- 练习 剩 50 间，团队要 30 间 @400，散客期望需求 20 间、净价 600。接不接？ 为什么要用"期望收益"而不是"实际收入"来比？ 淡季接团队的标准为什么可以放宽？ 剩 60 间、散客期望 20 间，团队要 50 间。最优团量是多少？ 团队含三餐与会议室，如何改变置换分析的结论？ 本章小结（5 条，可复述） 置换净收益＝团队收入 − 被挤散客的期望收益。 期望值要乘概率：散客不一定来，不能只看"昨天卖了多少"。 最优团量＝剩余房 − 散客期望需求（再留 10–20% 余量）。 淡季放宽、旺季严控：同一个价在不同日子是两笔生意。 含餐含会要计入综合贡献，这会改变结论。
