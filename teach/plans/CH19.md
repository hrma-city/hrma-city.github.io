## 一、学完这一章，学生能做到什么

- 读完能判断：做到什么程度算合格，以及怎么让团队持续做对。
- 每个决策对应一张判定表（全书共 32 张，索引见附录 A）。
- 用法：逐行勾选，满足全部必达项才执行该动作。
- 反馈不写主观评价，只写"判定表第几项不达标"——标准统一、无法争论。

## 三、讲这一章要用的公式与定义

- **批改三档（用于作业与复盘）**：A 档 · 可直接用：达到全部必达项 B 档 · 需小改：核心齐全，缺 1–2 项，改 1 小时可用 C 档 · 需重做：结构性问题，给出返工指引
- **算例 · 一次例会的标准产出**：看数：未来 14 天中 3 天在手低于目标 18–22% 找缺口：查 MPI 与 ARI → MPI 94、ARI 104 → 定性为"量差" 定动作：① 开放会员专享（提前 7 天不可退） ② OTA 临时配额 +10 间/日（3 天） ③ 销售定向拜访 4 家协议客户

## 四、讲这一章要用的判定表

### 本章判定表 · 例会标准议程

| 判据 | 结论 |
|---|---|
| 看数 10′ | 拉 RevPAR / RGI 与缺口，所有人看同一张表 |
| 找缺口 10′ | 量差还是价差（MPI↓ 还是 ARI↓），定位责任段 |
| 定动作 15′ | 调价 / 开停渠 / 置换——落到具体动作，不是讨论方向 |
| 分责任 5′ | 谁跟进、何时回看 |
| 记结论 5′ | 写入纪要，下次例会第一项复查 |

### 场景：季度末检查收益管理是否真在运转

| 判据 | 结论 |
|---|---|
| 有无留痕 | 抽查 10 次调价，能否找到"原因 + 批准人"？ |
| 有无用表 | 抽查 5 个决策，能否指到判定表某行？ |
| 有无例会 | 过去 12 周，开了几次？&lt;8 次即不合格 |
| 有无复盘 | 上月预测偏差有复盘记录吗？ |
| 有无授权 | 销售能否绕过收益岗直接放价？能 → 体系有洞 |
| 综合判定 | 五项全过 → 运转中；缺 2 项以上 → 形同虚设 |

### 执行是否合格 · 四项检查

| 判据 | 结论 |
|---|---|
| 有无留痕 | 每次调价记录"改了什么、为什么、谁批"——无记录等于没做 |
| 有无用表 | 决策能否指到"判定表第几条"——凭感觉即不合格 |
| 有无例会 | 每周固定一次；临时开会＝没有例会 |
| 有无复盘 | 每月回头看预测偏差与决策成败，修正下轮 |
| 有无授权 | 收益岗是否真有价格/可得性决策权（第 25 章） |
| 常见漏洞 | 销售现场放价绕过收益岗——价格体系第一大漏洞 |


## 五、课堂案例（直接用正文里的）

### 案例 · 判定表如何止住争论

销售要求给某客户降价，收益认为不该降。过去每次都靠谁嗓门大、谁资历老。 引入判定表后：逐项勾选"是否低于变动成本""有无栅栏""离入住几天""竞品是否跟随"。 / 四项中两项不达标 → 不降。 / 销售虽然不满意，但无法反驳——因为结论不是某个人下的，是条件共同决定的。 / 结论：判定表把"人之间的争论"变成"条件之间的核对"。这正是它最重要的价值——它保护的是关系，不只是利润。

### 案例二 · 一页反馈 vs 三页反馈

两位收益经理带教新人：A 写三页个性化反馈，B 只给判定表勾选 + 3 条意见。 三个月后：A 累得不堪重负，且新人说"每次反馈都不一样，我不知该听哪条"；B 轻松，且新人明确知道"要改哪三项"。 / 结论：标准化反馈既省自己，也帮对方。个性化长文看似负责，实际是精力黑洞，且标准不统一。

### 案例四 · 例会如何止住"降价惯性"

某店长期有个问题：只要出租率一低，第一反应就是降价。引入判定表与例会后的一次转变： / 会前：销售准备提议"降到 399 冲量"。 / 会中：收益经理拿出判定表逐项勾选—— / · 低于变动成本？399 &gt; 130，未破 ✓ / · 有栅栏？提议是"对所有渠道"→ ✗ / · 上周 MPI？96（仅略低）→ 不是严重丢量 → ✗ / · 竞品在降吗？竞品稳定 → ✗ / 结论：四项中三项不支持 → 不降；改为"官网会员专享 + 提前 7 天不可退"的限量促销。 两个月后对比：该店 ADR 比去年同期高 6%，而出租率仅低 1 个百分点，RevPAR 更高。 / 结论：例会 + 判定表的作用，是把"降价"从一个本能反应，变成一个需要过审的决定。这一条改变，通常比任何调价技巧都值钱。


## 六、容易讲错的地方

- 自学者提示：判断一个团队是否真在做收益管理，只看一件事——他们的决策能不能指到某张判定表的某一行。指不到，就是在凭经验，再忙也不是收益管理。

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- 关键：反馈不超过一页，只写 3 条改进意见。 / 长篇个性化反馈是精力黑洞，且标准不统一、无法复用。 / 正确做法是：指向"判定表第几项扣分"，而不是写一段主观评价。
- 产出必须是"动作 + 责任人 + 复查时间"，不是"要加强销售"这类方向。 / 下次例会第一项：复查这三条的执行情况与效果。 / 没有复查项的例会，开十次也等于零次。 二、收益例会：45 分钟，每周一次 本章判定表 · 例会标准议程 看数 10′拉 RevPAR / RGI 与缺口，所有人看同一张表 找缺口 10′量差还是价差（MPI↓ 还是 ARI↓），定位责任段 定动作 15′调价 / 开停渠 / 置换——落到具体动作，不是讨论方向 分责任 5′谁跟进、何时回看 记结论 5′写入纪要，下次例会第一项复查 填表示例 · 执行合格自查场景：季度末检查收益管理是否真在运转 有无留痕抽查 10 次
- 用法：每月用这六项自查一次。任一项不合格，流程就形同虚设。
- 练习 批改三档分别是什么？为什么反馈要限制在一页内？ 设计一次 45 分钟例会的议程与产出。 为什么"凭感觉定价"在判定表面前会失效？ 为什么例会必须包含"上次结论复查"？ 用四项检查，评估你所在的团队（或实习酒店）执行是否合格。 本章小结（5 条，可复述） 判定表：逐行勾选，满足必达项才执行；反馈指"第几项不达标"而非主观评价。 批改三档：A 直接用 / B 给 3 条意见 / C 给返工指引；反馈不超过一页。 例会 45 分钟：看数 10′ → 找缺口 10′ → 定动作 15′ → 分责任 5′ → 记结论 5′。 产出必须是"动作 + 责任人 + 复查时间"，不是方向。 四项检查：留痕
