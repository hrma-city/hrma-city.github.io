## 一、学完这一章，学生能做到什么

- 读完能分清：旺季该"守"，淡季该"放"，以及事件日怎么提前布。
- 旺季：守价 + 加限制。
- 目标是卖得贵，不追求 100% 住满（剩几间等高价客是合理的）。
- 淡季：放量 + 做价值。
- 目标是填满，但用栅栏和套餐，而不是裸降价。
- 整改评分、重谈协议、打磨系统数据、培训人员——为下一个旺季做准备。

## 三、讲这一章要用的公式与定义

- **淡旺打法对照**：旺季：提高 BAR、拉大房型价差、设 MinLOS、收紧低价渠道、提高保护位 淡季：收窄价差、开放低价档（带栅栏）、推套餐、加大团队与协议、做直销
- **算例 3 · 事件日分阶段布价**：历史同日 RevPAR 300，演唱会系数 1.4 → 目标 420 D-60：BAR 500 → 560（观察 pickup 无异常） D-30：560 → 620，设 MinLOS=2（pickup 略快） D-14：620 → 700，关低价档（pickup 仍快） D-7 ：pickup 开始放缓 → 维持 700，不再上调 最终：满房，ADR 700
- **事件日调整系数**：大型展会 1.3–1.8 演唱会/赛事 1.2–1.5 节假日 1.4–2.0 考试季 1.1–1.3 事件日预估 RevPAR = 历史同日 RevPAR × 系数

## 四、讲这一章要用的判定表

### 本章判定表 · 淡旺切换与事件日布价

| 判据 | 结论 |
|---|---|
| 当前处于什么季 | 看需求日历等级（第 20 章）：峰值→旺季打法；低→淡季打法 |
| 切换时机 | 提前 4–8 周切换，不要等到当季才反应 |
| 旺季目标 | 收入最大化，不是住满；剩几间是合理的 |
| 淡季目标 | 填满，但用栅栏/套餐，不裸降价 |
| 事件日提前量 | 大型事件 6–12 个月标注；小型 1–3 个月 |
| 事件日配套 | 常配 MinLOS=2~3，带动前后日；当日通常停接低价团队 |
| 事后必须做 | 复盘实际系数，修正下一年 |
| 常见错误 | 旺季追求 100% 出租率；事件日当天才知道 |

### 场景：查日历，某日标注为"大型展会第 2 天"

| 判据 | 结论 |
|---|---|
| 需求等级 | 峰值 → 旺季打法 ✓ |
| 剩余房量 | 剩 12% → 达到关档临界 ✓ |
| 房型价差 | 拉大到 28% ✓ |
| MinLOS | 设 2 晚（展会通常连住）✓ |
| 低价渠道 | 收紧配额（D-7 已执行）✓ |
| 团队 | 停止接低价团队（散客收益更高）✓ |
| 保护位 | 提高至高价期望需求 ✓ |
| 事后 | 复盘实际系数（用于修正明年日历）✓ |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| 淡季空房多 | 放量 + 做价值：收窄价差、推套餐、放宽团队、做直销 |
| 旺季要住满吗 | 不追求 100%——剩几间等高价客是合理的 |
| 发现明天有演唱会 | 太晚了；事件日应提前 6–12 个月标注 |
| 事件日怎么布价 | 分阶段（D-60/30/14/7），每阶段看 pickup；放缓就停 |
| 淡季没事干 | 练内功：整改评分、重谈协议、治理数据、培训 |
| 只标法定假期够吗 | 不够——本地展会、考试季、演出常常影响更大 |


## 五、课堂案例（直接用正文里的）

### 案例 · 一次演出的两种结果

A 店当天才知道有演唱会，按平时价售完；B 店提前 8 个月标注，分四阶段调价。 A 店 ADR 520；B 店 ADR 890，且通过 MinLOS 带动前后两日出租率提升 20 个百分点。 / 同一晚，B 店客房收入约为 A 店的 1.8 倍。 / 结论：事件日收益的差距，不来自定价技巧，来自"有没有提前知道"。

### 案例三 · 淡季的一个反直觉发现

某店淡季把房型价差从 25% 收窄到 12%，本以为会拉低 ADR。 结果：高价房型销量提升 40%，RevPAR 反而上升 6%。 / 原因：淡季客人在意"性价比"，价差太大时他们会直接选最便宜的；收窄后，一部分客人愿意加一点钱升级。 / 结论：淡季收窄价差看似在"让步价"，实际是在"换结构"——把原本会空置的高价值库存卖出去。

### 案例四 · 淡旺季切换的完整清单

某店从旺季切到淡季的标准动作清单（提前 6 周执行）： / 价格：BAR 下调 8–12%；房型价差从 28% 收窄到 12% / 限制：撤除 MinLOS 与 CTA（旺季遗留） / 渠道：恢复低价渠道配额；推会员专享（提前 14 天不可退） / 产品：上线淡季套餐（含早/下午茶/延迟退房） / 客源：放宽团队标准（散客机会成本低）；加大会议销售 / 内务：整改评分（差评高频项）；协议价重谈；系统数据治理；人员培训 关键在最后一行：淡季不只是"淡"，它是一年中唯一有时间练内功的窗口。 / 该店坚持两年后，淡季 RevPAR 提升 11%，且第三年旺季的 ADR 起点更高（因为评分与协议价都改善了）。 / 结论：把淡季当成"整改季"，是收益管理里被最严重低估的一条策略。


## 六、容易讲错的地方

- 自学者提示：现在就打开日历，把你所在城市明年的展会、演出、假期标出来。这是收益管理里投入产出比最高的一件事，且几乎不花钱。

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- 算例：旺季某周末剩 15 间 → 正确做法是关低价档、加 MinLOS=2，宁可剩几间也要守住高价。 / 淡季周三剩 80 间 → 应开放会员专享价（提前 7 天不可退）+ 推套餐，把量做起来，同时保住 BAR 不裸降。
- 关键在 D-7 那一步：看到 pickup 放缓就停止加价。 / 若机械地按原计划涨到 780，很可能造成滞销。 / 结论：分阶段布价的意义，就是给自己留出"看见变化就停"的机会。一次涨到位则没有这个机会。 二、事件日：全年最容易赚的钱 事件日调整系数
- 算例：某周三历史 RevPAR 280，当晚有演唱会（系数 1.4）→ 预估 392。 / 布价节奏：D-60 上调一档 → D-30 再调一档并设 MinLOS=2 → D-14 关低价档 → D-7 视 pickup 决定是否再调。 / 关键：分阶段调，给自己留修正余地，不要一次涨到位。
- 用法：每年做一张"全年事件日清单"，提前 6–12 个月开始布价。这是全年投入产出比最高的一件事。填表示例 · 这个日子该怎么打场景：查日历，某日标注为"大型展会第 2 天" 需求等级峰值 → 旺季打法 ✓ 剩余房量剩 12% → 达到关档临界 ✓ 房型价差拉大到 28% ✓ MinLOS设 2 晚（展会通常连住）✓ 低价渠道收紧配额（D-7 已执行）✓ 团队停止接低价团队（散客收益更高）✓ 保护位提高至高价期望需求 ✓ 事后复盘实际系数（用于修正明年日历）✓ 结论：全套旺季打法，且事件日额外加两条——停团队、提保护位。 / 最后一行别忘了：事后复盘实际系数，日历才会越来越准。
