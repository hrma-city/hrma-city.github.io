## 一、学完这一章，学生能做到什么

- 读完能判断：对手降价时，你该跟、该守、还是该反向操作。
- 先看对手为什么降价：新开业爬坡（3–6 个月会回）？经营困难甩卖（长期）？短期促销（不理）？原因不同，应对方略完全相反。
- 价格战对弱者更不利：谁的产品和口碑更强，谁更该守价。
- 降价是把自己的优势让出去。
- 不降价的替代手段很多：加价值（早餐、升级、积分）、加栅栏、转直销——都比直接降价好，且成本更低。

## 三、讲这一章要用的公式与定义

- **核心判据**：跟降的条件（三条必须全中）： ① 对手降价是长期行为（非短期促销、非爬坡期） ② 你的 MPI 明显下滑（确实在丢量，不只是感觉） ③ 你的产品力不占优（口碑/位置评分不如对手） 三条不全中 → 不跟价，改用「加价值不降价格」
- **算例 3 · 跟降与加价值的对比**：你现价 500，对手降到 400（差 100） 跟降：收入 −100/间；若要回本需量涨 25% 加价值：加早餐(成本30)+升级券(20)+延迟退房(0) = 成本 50，客人感知价值 +150

## 四、讲这一章要用的判定表

### 本章判定表 · 竞品降价怎么应对

| 判据 | 结论 |
|---|---|
| 对手为什么降 | 新开业（3–6 个月会回）→ 守；经营困难（长期）→ 需重视；短期促销 → 不理 |
| 你的 MPI 变化 | 明显下滑 → 确实在丢量；稳定 → 不必跟（可能只是心理紧张） |
| 你的产品力 | 口碑/位置占优 → 守价；不占优 → 需跟或用价值补偿 |
| 你的成本底线 | 跟降后是否仍高于变动成本？否 → 绝对不跟（第 26 章） |
| 首选动作顺序 | 加价值（早餐/升级/积分）＞ 加栅栏 ＞ 降渠道价 ＞ 降公开价 |
| 观察期 | 对手降价后观察 2–4 周再看自己的 MPI，不要当天反应 |
| 红线 | 不得因跟降破坏 BAR 层级（第 22 章） |

### 场景：隔壁新店开业，价格比你低 25%

| 判据 | 结论 |
|---|---|
| 对手为什么降？ | 新开业爬坡，行业经验 3–6 个月 → 守 ✓ |
| 我的 MPI 变化？ | 观察 2 周：MPI 从 105 降到 101 → 基本没丢量 ✓ |
| 我的产品力？ | 评分 4.6 vs 对手 4.4 → 占优，更该守 ✓ |
| 成本底线？ | 若跟降到其价位，仍高于变动成本 → 未破线（但不代表该跟） |
| 首选动作 | 加价值（早餐/升级/积分），不动公开价 ✓ |
| 观察期 | 继续观察 4 周，每周看一次 MPI ✓ |
| 红线 | 不动 BAR，不做无栅栏的降价 ✓ |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| 隔壁新店开业大降价 | 先观察 2 周 MPI；爬坡期通常 3–6 个月会回价 |
| 竞品降价但我的 MPI 没掉 | 说明没真丢量 → 不跟，最多加价值 |
| 销售连夜要求跟降 | 拿出判定表逐项勾选；四项中两项不满足就不降 |
| 竞品是长期经营困难甩卖 | 三条跟降条件可能全中 → 但仍用有栅栏的方式跟 |
| 已经跟降了，现在想涨回去 | 很难；优先加价值而非直接提价（客人已有锚点） |


## 五、课堂案例（直接用正文里的）

### 案例一 · 守价反而赢了

新对手低价入市 3 个月。A 店跟降到 350，B 店守 480 但加赠早餐与延迟退房。 3 个月后新对手价格回到 500。 / A 店已被客人认定为"350 档"的酒店，涨价困难，且价格体系受损；B 店价格体系完好，直接随市场回到 500。 / 结论：价格一旦降下去，想涨回来比登天难。守价 + 加价值，通常是更优解。

### 案例二 · 该跟的一次

某景区酒店，周边三家竞品因整体客流下滑同时长期降价 20%，且该店 MPI 连续两月下滑 15 个点。 三条跟降条件全中（长期、确实丢量、产品力不占优）→ 该跟。 / 但做法是：通过会员专享与打包套餐让利，而非直接砍公开价——保留了回升的通道。 / 结论：即使该跟，也要用有栅栏的方式跟。

### 案例三 · 一次冷静的"不跟"

竞品降价 20%，销售连夜要求跟降。总经理要求先观察两周 MPI。 两周后数据：MPI 从 104 降到 102（几乎没丢量），但 OTA 上的咨询量上升。 / 诊断：客人在比价，但大部分最终仍选择本店（评分更高）。 / 应对：不降价，仅在 OTA 上增加"含早"选项（成本 30），把比价客人的注意力从"裸价"引到"总价值"。 / 结果：四周后出租率与价格双双稳定，而跟降的竞品陷入价格战。 / 结论：观察两周的成本几乎为零，而冲动跟降的成本可能是一整年。


## 六、容易讲错的地方

- 自学者提示：常备三种"加值武器"在手：赠送早餐、房型升级券、会员积分。它们能随时替代 50–80 元的价差，且不破坏价格体系。这是应对竞品降价最实用的工具箱。

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- 算例：对手从 500 降到 350（−30%）。你若跟降，按第 4 章，量要涨 42.9% 才回本——几乎不可能。 / 替代方案：维持 500，加赠早餐（成本 30）+ 升级券（成本 20），合计 50。 / 相当于"隐性让利 10%"而非 30%——保住了价格体系，也留住了客人。 / 若仍不够，可再叠加会员专享的有限折扣（带栅栏），但仍不动公开价。
- 跟降的真实代价：假设月售 2,000 间夜，跟降后月损失 200,000 元，且不可逆。 / 加价值的代价：2,000 × 50 = 100,000 元，且可随时取消。 / 结论：加价值的花费约为跟降的一半，且保留了价格体系的完整性。这就是为什么它应是首选。
- 用法：对手降价当天不做决策。先填这张表，观察 2–4 周的 MPI 变化，再决定。急于反应是这一章最大的敌人。填表示例 · 对手降价后的标准动作场景：隔壁新店开业，价格比你低 25% 对手为什么降？新开业爬坡，行业经验 3–6 个月 → 守 ✓ 我的 MPI 变化？观察 2 周：MPI 从 105 降到 101 → 基本没丢量 ✓ 我的产品力？评分 4.6 vs 对手 4.4 → 占优，更该守 ✓ 成本底线？若跟降到其价位，仍高于变动成本 → 未破线（但不代表该跟） 首选动作加价值（早餐/升级/积分），不动公开价 ✓ 观察期继续观察 4 周，每周看一次 MPI ✓ 红线不动 BAR，不做无栅栏
- 练习 对手降价 30%，你跟降需要量涨多少才回本？ 新开业对手的低价一般持续多久？此时该跟吗？ 为什么说"降下去容易涨回来难"？ 对手降价但你 MPI 没下滑，说明什么？ 设计一套"不降公开价"的应对方案（写出具体手段）。 本章小结（5 条，可复述） 先看对手为什么降：新开业爬坡（3–6 个月）→ 守；经营困难（长期）→ 应对；短期促销 → 不理。 跟降三条件全中才跟：长期行为 ＋ MPI 确实下滑 ＋ 产品力不占优。 MPI 是判断"是否真丢量"的唯一依据，不要凭感觉。 动作优先级：加价值 ＞ 加栅栏 ＞ 降渠道价 ＞ 降公开价。 价格黏性：降下去容易，涨回来难——这是不轻易跟降的根本原因。
