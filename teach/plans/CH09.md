# 第 9 章 · 房型价差：差价定多少才合理 教案

## 一、学完这一章，学生能做到什么

- 读完能设计：不同房型之间该差多少钱——差错了等于白送。
- 价差要体现价值差：面积、楼层、视野、含早、行政待遇——差多少价值就差多少钱。
- 没有价值支撑的价差，客人一眼看穿。
- 价差要引导客人上移：太小会让所有人挤在高房型（酒店少赚），太大则低房型滞销（库存浪费）。
- 价差是动态的：紧俏日拉大价差（多赚），淡季收窄价差（好卖）。
- 价差结构每年重审，季度只微调。

## 三、讲这一章要用的公式与定义

- **核心公式**：房型价差率 = (高房型价 − 低房型价) ÷ 低房型价 经验区间：相邻房型价差 10%–25% 自检信号：看各房型的「售罄顺序」
- **算例 3 · 用净利差判断价差是否合理**：高级房 500（变动成本 80）→ 毛利 420 行政房 650（变动成本 170，含酒廊）→ 毛利 480 售价差 = 150（30%） 毛利差 = 60（14%）

## 四、讲这一章要用的判定表

### 本章判定表 · 房型价差是否合理

| 判据 | 结论 |
|---|---|
| 相邻房型价差率 | 10%–25% 合理；&lt;10% 太小；&gt;30% 需有硬价值支撑 |
| 各房型售罄顺序 | 应从低到高依次售罄（正常）；高房型先空 → 价差过大 |
| 低房型最后剩余 | 常年剩很多 → 价差太小或低房型体验太差 |
| 是否有升级池 | 保留少量高房型用于升级（会员/补救），不要全卖光 |
| 紧俏日调整 | 紧俏日可拉大到 25–30%；淡季收窄到 10–15% |
| 价值支撑是否真实 | 行政待遇/含早是否真的存在？没有价值支撑的高价会反噬评分 |
| 是否与竞品可比 | 同档次同房型的价差率应对标竞品，偏离过大需说明 |

### 场景：某店三个房型，观察一周售罄顺序

| 判据 | 结论 |
|---|---|
| 标准房(400) | 第 3 个售罄（最慢）→ 有剩余 |
| 豪华房(460) | 第 2 个售罄 |
| 行政房(700) | 第 1 个售罄（最快） → 异常信号 |
| 诊断 | 行政房最早卖完 → 价差过大或行政房供给太少 |
| 价差率核算 | 豪华→行政 = 240/460 = 52%（远超 25% 经验上限） |
| 动作 | 行政房降到 620（价差 35%，有酒廊支撑），或增加行政房数量 |
| 复查 | 调整后观察 2 周售罄顺序是否恢复"由低到高" |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| 最高房型总是最先售罄 | 两种可能：价差太小 或 该房型数量太少；结合价差率判断 |
| 最低房型最后剩很多 | 价差太大，或低房型体验太差 → 收窄价差或改进低房型 |
| 旺季/淡季要不要改价差 | 旺季拉大（25–30%），淡季收窄（10–15%） |
| 会员到店要求升级没房 | 说明没留升级池 → 每晚预留 2–3 间高房型不卖 |
| 想给房型调价 | 先看售罄顺序（最便宜的诊断工具），不要拍脑袋 |


## 五、课堂案例（直接用正文里的）

### 案例一 · 把价差从 50 元改成 150 元

原：高级房 500，行政房 550（价差 10%）。现象：行政房天天最早售罄，高级房最后还剩。 调整：行政房提到 650（价差 30%，但行政房含早 + 行政酒廊，价值支撑足够）。 / 结果：行政房仍能卖出，但速度放缓；高级房提前售罄。总收入上升，因为高价房型卖出了更多间。

### 案例二 · 淡季收窄价差

某店淡季仍维持 25% 的价差，高房型几乎卖不动，大量空置。 淡季将价差收窄到 12% 后，高房型销量提升 40%。 / 虽然单价降了，但把原本会空置的高价值库存卖出去了，RevPAR 反而上升 6%。 / 结论：淡季的目标是"卖出去"，旺季的目标才是"卖得贵"。

### 案例三 · 升级池的价值

某店旺季把行政房全部卖出，当晚有 2 位白金会员要求升级（权益承诺），另有 1 间因设施故障需换房——全部无房可用。 结果：会员投诉、故障房客人不满，产生 3 条差评。 / 改为每晚预留 2–3 间行政房作为"升级池"不卖后，类似问题得以解决，而损失的可售房量仅 2–3 间（占 2–3%）。 / 结论：升级池是保险。把最高房型 100% 卖光，等于放弃了所有服务补救的余地。


## 六、容易讲错的地方

- 自学者提示：想知道价差对不对，去 OTA 上看 3–5 家同档次酒店各房型的价格，算出它们的价差率取平均——那就是行业基准。再对比自己的，偏离在哪一目了然。
