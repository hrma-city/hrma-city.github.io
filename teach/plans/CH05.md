## 一、学完这一章，学生能做到什么

- 读完能说出：涨价不是拍脑袋，是看三个信号。
- 看在手（BOH, book on hand）：已经订出去多少，对比历史同期同日。
- 这是"已经确定的部分"。
- 看 pickup（预订进度）：新预订进来的速度是否快于历史。
- 这是"需求来的速度"，比在手更重要——因为它预示未来。
- 看剩余天数：同样剩 8 间，提前 30 天和提前 1 天，决策完全相反。
- 时间决定了你还有没有机会等高价客。

## 三、讲这一章要用的公式与定义

- **核心判据（三条信号）**：① 在手 ≥ 历史同期在手 × (1 + 阈值) ② pickup 速度 &gt; 历史同期 ③ 剩余天数 &gt; 最低提前期 三条全中 → 涨；缺任一 → 不动或改用可得性控制
- **算例 4 · 三条信号的四种组合**：① 在手高 + pickup 快 + 时间充裕 → 涨（最标准的涨价信号） ② 在手高 + pickup 慢 + 时间充裕 → 不涨（警惕早期大单虚高） ③ 在手高 + pickup 快 + 时间紧迫 → 谨慎（宁可卖掉，别贪） ④ 在手低 + pickup 快 + 时间充裕 → 观察（可能后劲足，再等两天）

## 四、讲这一章要用的判定表

### 本章判定表 · 涨价决策

| 判据 | 结论 |
|---|---|
| 在手 vs 历史同期 | 高出阈值（建议 10–15%）→ 考虑涨；持平或低于 → 不涨 |
| pickup 速度 | 快于历史 → 涨；慢于历史 → 即使在手高也不涨（警惕团队虚高） |
| 剩余天数 | &gt;7 天 → 可从容涨；2–7 天 → 小幅涨；≤1 天 → 慎涨（宁可卖掉） |
| 竞品价格 | 已高于竞品 15% 以上 → 再涨会流失；明显低于竞品 → 可涨 |
| 库存水位 | 剩余 ≤10–15% → 优先关低价档（可得性控制），而非直接提价 |
| 动作顺序 | 先关低价档 → 再加限制（MinLOS）→ 最后才提 BAR |
| 涨后观察 | 涨价后 24 小时内盯 pickup；若明显变慢 → 立即回撤 |

### 场景：距某周六还有 9 天，当前在手 58 间

| 判据 | 结论 |
|---|---|
| 在手 vs 历史同期 | 去年同日 44 间 → 高出 32%（阈值 10%）→ ✓ |
| pickup 速度 | 近 3 天日均 10 间，历史 6 间 → 偏快 → ✓ |
| 剩余天数 | 9 天 &gt; 7 天 → 可从容调整 → ✓ |
| 竞品价格 | 竞品均价 620，我方 560（低 10%）→ 有空间 → ✓ |
| 库存水位 | 剩 22% → 尚未到"关低价档"的临界（≤15%） |
| 动作顺序 | 先关最低价档 → 再上调 BAR 一档 → 观察 24h |
| 涨后观察 | 若 pickup 明显变慢 → 立即回撤 ✓ |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| 在手比去年高 20%，想涨价 | 别急——还要看 pickup 是否也快；只看在手不够 |
| 在手高但 pickup 慢 | 可能是早期一个大团队撑起来的 → 不涨 |
| 只剩 1 天、剩几间 | 保守，宁可卖掉；此时涨价最容易把客人吓走 |
| 已高于竞品 15% 以上 | 再涨会流失 → 停手，改关低价档 |
| 涨价后 pickup 明显变慢 | 立即回撤，不要硬扛到入住日 |


## 五、课堂案例（直接用正文里的）

### 案例一 · 提前 3 周的展会

距展会 21 天，在手已达 65 间（历史同期 30 间），pickup 日均 9 间（历史 4 间）。 三条信号全中。该店分三步走： / ① 先关闭低价档（不给折扣房型）→ ② 提高 BAR 一档 → ③ 加 MinLOS 两晚。 / 注意顺序：先动可得性，后动价格。关掉低价档不会吓跑客人，只会把他们往上推。

### 案例二 · 涨错了的一次

周六剩 6 间，前台直接报 999（平时 500）。客人当场挂电话。 当天只卖出 2 间，剩余 4 间空置。 / 错误在于：只看"剩 6 间"就翻价，没看 pickup 也没看剩余时间。 / 正确做法：先看 pickup 是否快于历史。若只是普通周末、pickup 正常，那"剩 6 间"只是正常水位，不该翻倍涨价——最多关掉低价档。

### 案例三 · 分三步涨 vs 一步涨到位

同为展会日（提前 21 天，信号全中）。A 店一次把 BAR 从 500 提到 800；B 店分三步：500→600（D-21）→680（D-14）→760（D-7），每步后观察 pickup。 A 店：涨完后 pickup 骤降 45%，恐慌回撤，最终均价 620 且损失了大量早期预订。 / B 店：每步 pickup 都稳定，最终 760 且满房。 / 结论：涨价要小步快跑。一次到位的最大风险不是"涨太高"，而是你失去了观察市场反应的机会。


## 六、容易讲错的地方

- 自学者提示：最快的练习是每天记两个数——"今日在手"和"去年同期同日在手"。坚持两周，你就能看出 pickup 的规律，也能第一次凭数据而非感觉判断"该不该涨"。

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- 算例 1（全中，涨）：距入住 14 天，在手 52 间（去年同期 40 间）→ 高出 30%，阈值 10% → ①满足。 / 近 3 天日均 pickup 12 间（历史 7 间）→ ②满足。剩 14 天 → ③满足。 / 三条全中 → 上调 BAR 一档。 / / 算例 2（缺一，不动）：在手 52（高 30%），但 pickup 日均 4 间（历史 7 间，更慢）。 / 说明需求后劲不足（可能是早期一个大团队撑起来的）→ 不涨。 / / 算例 3（时间紧）：只剩 1 天，剩 5 间，在手高、pickup 快。 / 但时间太短，涨价可能把客人吓走 → 应保守，宁可卖掉。
- 只有第 ① 种是明确的涨价信号。 / 很多酒店犯的错是把第 ② 种当成信号——看到一个团队订了 40 间就以为需求很旺，结果散客一直没来。 / 记住：pickup 才是速度表，在手只是里程表。
- 用法：每天对照这七项。关键是第 6 行的顺序——先动可得性，最后才动价格。直接提价是最贵的一种涨法。填表示例 · 今天到底涨不涨场景：距某周六还有 9 天，当前在手 58 间 在手 vs 历史同期去年同日 44 间 → 高出 32%（阈值 10%）→ ✓ pickup 速度近 3 天日均 10 间，历史 6 间 → 偏快 → ✓ 剩余天数9 天 &gt; 7 天 → 可从容调整 → ✓ 竞品价格竞品均价 620，我方 560（低 10%）→ 有空间 → ✓ 库存水位剩 22% → 尚未到"关低价档"的临界（≤15%） 动作顺序先关最低价档 → 再上调 BAR 一档 → 观察 24h 涨后观察若
- 练习 在手高出历史 20%，但 pickup 慢于历史，该涨吗？为什么？ 只剩 1 天、剩 5 间房，应该大涨还是保守？ 为什么"先关低价档、后提价"比"直接提价"更好？ 已高于竞品 20%，还能再涨吗？ 涨价后 pickup 明显变慢，应该怎么办？ 本章小结（5 条，可复述） 三条信号：在手高于历史（阈值 10–15%）＋ pickup 快于历史 ＋ 剩余天数充足。 三条全中才涨；缺任一条则不动或只动可得性。 pickup 比在手重要：在手是里程表，pickup 是速度表。 时间决定策略：&gt;7 天从容涨；2–7 天小幅；≤1 天保守（宁可卖掉）。 动作顺序：先关低价档 → 再加限制 →
