## 一、学完这一章，学生能做到什么

- 读完能列出：收益岗每天、每周、每月必看的表。
- 日报看动作：今天该调价还是该关档？——看在手、pickup、竞品、配额。
- 周报看趋势：未来两周的缺口在哪？——看滚动预测与需求日历。
- 月报看结构：量的问题还是价的问题？——看 RGI/MPI/ARI 与客源渠道结构。

## 三、讲这一章要用的公式与定义

- **核心报表清单**：每日（4）：在手表 / pickup 表 / 竞品价表 / 渠道配额表 每周（3）：14 天滚动预测表 / 需求日历 / 竞品周报 每月（2）：RGI·MPI·ARI 表 / 客源贡献与渠道净价表
- **算例 · 一张好报表的三要素**：① 有数值：今日在手 62 间 ② 有基准：去年同期 48 间、预算对应 55 间 ③ 指向动作：高出预算 13% → 检查是否需要收紧低价档

## 四、讲这一章要用的判定表

### 本章判定表 · 报表是否合格

| 判据 | 结论 |
|---|---|
| 能否指向动作 | 看完能说出"今天该做什么"→ 合格；只能"知道情况"→ 不合格 |
| 是否有对比基准 | 必须有历史同期与预算两条基准线 |
| 是否有竞品维度 | 没有竞品对标的表，无法判断相对位置 |
| 更新频率 | 日表每天更新；周表周一更新；月表月初 3 日内出 |
| 是否有人看 | 没人看的报表应删掉——报表不是越多越好 |
| 是否口径统一 | 与财务、前厅口径一致（可售房、免费房如何处理） |
| 是否留痕 | 报表应能导出归档，作为复盘依据 |

### 场景：季度清理报表，逐张过

| 判据 | 结论 |
|---|---|
| 谁在看？ | 能说出姓名 → 保留；"好像有人看" → 删 |
| 看完做什么？ | 能说出一个动作 → 保留；"了解一下" → 删 |
| 有基准吗？ | 有历史同期/预算 → 保留；孤立数字 → 补或删 |
| 多久用一次？ | 每周以上 → 保留；季度一次 → 改为季报 |
| 口径统一吗？ | 与财务一致 → 保留；两套数字 → 必须先统一 |
| 本季清理结果 | 60 张 → 9 张，读表时间从 2 小时降到 20 分钟 |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| 系统里有 60 张表 | 给每张贴便签写"用来做什么"；写不出的删 |
| 看了报表还是不知做什么 | 说明缺基准或指向动作 → 补上这两栏 |
| 两份报表数字对不上 | 先统一口径并写入制度，否则分析再对也没说服力 |
| 不知道该看日/周/月哪种 | 日报看动作、周报看趋势、月报看结构 |
| 报表越做越细 | 细到 SKU 会淹没关键；按决策频率做 |


## 五、课堂案例（直接用正文里的）

### 案例 · 从 60 张表到 9 张表

某店收益经理每天看 60 张系统报表，耗时 2 小时，但决策仍靠经验。 重做：只保留 9 张（日 4 / 周 3 / 月 2），每张都加"对比基准"和"建议动作"两栏。 / 结果：每日读表时间降到 20 分钟，决策速度反而更快、更准。 / 结论：报表的目的是触发动作，不是陈列数据。

### 案例三 · 两套数字的代价

某店收益部与财务部对"出租率"的算法不同（是否计入免费房），两边报表长期对不上。 后果：经营会上每次都要先花 20 分钟争论"哪个数是对的"，而真正的议题被挤掉。 / 统一口径后（写入制度、双方签字），会议效率大幅提升，且收益部的数据第一次被财务采信。 / 结论：口径不统一，你的分析再对也没有说服力。这是收益岗最该先解决的政治问题。

### 案例四 · 一张报表如何改变决策

某店原来的月报只有一行："本月出租率 78%、平均房价 460"。 / 改造后加入三要素——数值 + 基准 + 指向动作： / · 数值：RevPAR 359 / · 基准：预算 372（−3.5%）、去年同期 341（+5.3%）、市场 RGI 103 / · 动作：量略低于预算但跑赢市场 → 不需降价，补渠道曝光即可 改造前后对比： / 旧月报下，团队看到"出租率 78%"会觉得不错，或看到"低于预期"就提议降价。 / 新月报下，团队能立刻判断"是否跑赢市场""缺口在量还是在价""该不该降价"。 / 结论：报表的差别不在于数据多少，而在于有没有基准和动作。没有这两样，再多的数字也只是噪音。


## 六、容易讲错的地方

- 自学者提示：给自己做一张"晨间 15 分钟表"：今日在手、昨日实际、未来 7 日在手、竞品最低价、昨日取消数。五个数字，每天记一次，两周就能看出规律——这比看 60 张报表有用得多。

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- 算例（日报核心三行）： / ① 今日在手 78 间（去年同期 65）→ 高出 20% / ② 近 3 日 pickup 日均 11 间（历史 7）→ 偏快 / ③ 竞品 A 已提价 8%，我方未动 → 有提价空间 / 三行数据直接指向一个动作：今日上调 BAR 一档。 / 这就是"能指向动作"的报表——好的报表应该这样。
- 缺了第 ② 条，数字无法判断高低；缺了第 ③ 条，看完不知道做什么。 / 只有数值的报表叫"数据"，三样齐全才叫"管理报表"。这就是为什么很多酒店系统里有 60 张表却依然靠感觉决策。
- 用法：每季度清理一次报表。问每个看表的人："看完你会做什么？"答不上来的表，删。填表示例 · 这张表要不要保留场景：季度清理报表，逐张过 谁在看？能说出姓名 → 保留；"好像有人看" → 删 看完做什么？能说出一个动作 → 保留；"了解一下" → 删 有基准吗？有历史同期/预算 → 保留；孤立数字 → 补或删 多久用一次？每周以上 → 保留；季度一次 → 改为季报 口径统一吗？与财务一致 → 保留；两套数字 → 必须先统一 本季清理结果60 张 → 9 张，读表时间从 2 小时降到 20 分钟 结论：报表的合格线是"看完能说出一个动作"。 / 达不到这条线的表，无论做得多精美，都是在消耗而不是
- 练习 设计你自己的"晨间 15 分钟表"，列出要记的 5 个数字。 为什么报表必须有对比基准？ 什么样的报表应该被删掉？ 日报、周报、月报分别回答什么问题？ 为什么报表口径要与财务统一？ 本章小结（5 条，可复述） 日报看动作、周报看趋势、月报看结构。 合格报表的三要素：数值 ＋ 基准（预算/同期）＋ 指向动作。 没有基准的数字无法判断高低，也就无法触发动作。 口径必须与财务统一，否则分析再对也没有说服力。 每季度清理一次报表：写不出"用来做什么"的就删。
