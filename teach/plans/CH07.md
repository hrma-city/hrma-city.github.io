## 一、学完这一章，学生能做到什么

- 读完能判断：折扣是药还是毒——关键看有没有栅栏。
- 折扣必须配栅栏：提前期、不可取消、会员身份、指定渠道、资质证明——至少有一条。
- 栅栏的作用是把"价格敏感的人"和"时间敏感的人"分开。
- 折扣要有期限与额度：明确起止日期、限量，且写进系统与合同。
- 优先"加价值"而非"降价格"：赠早餐、升级、积分——成本更低且不伤价格体系，客人感知却往往更好。

## 三、讲这一章要用的公式与定义

- **核心公式**：折扣的真实成本 = 降价额 × 因折扣新增的人数 + 降价额 × 本来会全价购买的人数（buy-down 损失） 有效折扣 = 只作用于「不打折就不来」的那部分人
- **算例 3 · 三种栅栏的效果对比**：房价 600，让利 120（八折），预计带来 100 间夜 无栅栏 ：其中 40 间为 buy-down → 真实成本 16,800 提前21天 ：其中 20 间为 buy-down → 真实成本 14,400 提前+不可退+会员：其中 8 间为 buy-down → 真实成本 12,960

## 四、讲这一章要用的判定表

### 本章判定表 · 这个折扣该不该做（七项勾选）

| 判据 | 结论 |
|---|---|
| 有没有栅栏 | 无栅栏 → 不做（等于永久降价） |
| 有没有期限与额度 | 无期限/无限量 → 不做 |
| 是否低于变动成本 | 是 → 绝对不做（第 26 章） |
| 是否破坏 BAR 层级 | 会让公开价高于促销价过多 → 调整幅度或改加价值 |
| 目标客群 | 只针对价格敏感的新客 → 做；面向全体 → 不做 |
| 结束后能否恢复 | 若客人已形成低价预期 → 该折扣是失败的 |
| 能否用加价值替代 | 能 → 优先加价值（成本更低、不伤体系） |

### 场景：HR 提出给员工亲友价 5 折，不限时不限量

| 判据 | 结论 |
|---|---|
| 有没有栅栏？ | 无时间、无数量、无身份核验 → 无栅栏 ✗ |
| 有没有期限额度？ | "长期有效、不限量" → 无 ✗ |
| 低于变动成本？ | 600×0.5=300 &gt; 120 → 未破底线 ✓ |
| 破坏 BAR 层级？ | 5 折远低于任何公开档，严重破坏 ✗ |
| 面向谁？ | 名义员工亲友，实际会外溢到普通客 ✗ |
| 能恢复吗？ | 一旦外溢形成口碑，极难恢复 ✗ |
| 能否加价值替代？ | 可改为"员工权益包"（含早餐/升级），不动房价 ✓ |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| HR 要"员工亲友价 5 折" | 改为限量 + 需审批 + 含早不含房价折扣；不动裸价 |
| 要做"全场八折" | 否决；改为会员专享 + 提前订 + 不可退 + 限量 |
| 活动结束后 ADR 回不去 | 说明折扣已锚定客人预期 → 下次务必加栅栏与期限 |
| 折扣带来很多"老客户" | 是 buy-down，不是增量 → 加严栅栏 |
| 预算有限想让利 | 优先加价值（早餐/升级/积分），成本约为降价的一半 |


## 五、课堂案例（直接用正文里的）

### 案例一 · 同样的让利，两种做法

淡季需让利约 100 元/间来刺激需求。 / 方案一：全场降 100。方案二：官网会员专享，提前 7 天订、不可退，赠早餐（成本 30）+ 升级机会。 方案一：所有客人都能拿到，包括原本全价客 → buy-down 严重，价格体系受损。 / 方案二：只有提前订、能接受不可退的客人才拿得到 → 精准作用于价格敏感人群，成本更低。 / 结论：折扣的价值不在"降多少"，在"降给谁"。

### 案例二 · 一条栅栏救回的利润

某店"提前预订 8 折"活动，因无其他限制，老客户纷纷改用，ADR 下滑 11%。 改为"提前 21 天预订 + 不可取消 + 仅限官网会员"后，同样 8 折： / 使用量下降约 30%（说明这部分本来就是价格敏感的新客），但 ADR 回升 8%。 / 结论：栅栏会筛掉"本来就会买的人"，留下的才是真正被激励出来的增量。

### 案例三 · 促销的"剂量控制"

某店淡季促销，把 8 折房量限制在"每日 20 间、共 30 天"，且仅限官网会员提前 14 天订。 结果：促销房量占总量不到 12%，却带动整体出租率上升 9 个百分点；活动结束后价格顺利恢复，无客诉。 / 对比该店去年"无限量八折"：出租率提升类似，但 ADR 受损且三个月未恢复。 / 结论：促销要像用药——有剂量、有疗程、有适应症。无限量促销不是促销，是改价。


## 六、容易讲错的地方

- 自学者提示：判断一个促销好不好，只问一句："一个愿意付全价、临时订房的商务客，能不能拿到这个折扣？"如果能，说明栅栏失效，这个促销正在吃掉你的利润。
