## 一、学完这一章，学生能做到什么

- 读完能说出：收益管理在一年、一季、一月、一周、一天分别做什么——先有总览，再看细节。
- 年：定目标、建日历、审价格体系——把一年变成一张作战地图。
- 季：滚动重算、切换淡旺季策略——市场变了要换挡。
- 月：月报复盘、次月目标分解到日——校准偏差。
- 周：更新需求日历、临近回收、竞品对标——提前布动作。
- 日：取数 → 判表 → 执行 → 收口——把计划落到每一天。

## 三、讲这一章要用的公式与定义

- **节奏的本质**：越外层越「定方向」，越内层越「做动作」 年(目标) → 季(换挡) → 月(校准) → 周(布动作) → 日(执行+记录)
- **算例 · 年度目标如何流到每天**：年度客房收入目标 3,000 万 → 8 月月指数 1.3 → 8 月目标 325 万 → 8 月按星期几加权 → 某周六日目标 ≈ 13.5 万 → 可售房 100 间 → 该日 RevPAR 目标 ≈ 1,350 → 对应：OCC 90% × ADR 1,500（或等价组合）

## 四、讲这一章要用的判定表

### 本章判定表 · 各周期该做什么

| 判据 | 结论 |
|---|---|
| 年 | 市场假设 → 年度预算（目标×月指数）→ 全年需求日历 → BAR 体系年审 → 协议价重谈 |
| 季 | 滚动重算剩余月份 → 淡旺季策略切换 → 竞争群更新 → 协议与大客户预谈 → 季度复盘 |
| 月 | 结帐核对 → 月报（RGI/MPI/ARI）→ 渠道净价复盘 → 价目表复核 → 次月目标分解到日 |
| 周 | 周一更新需求日历（滚动+7 天）→ D-7 收紧 / D-3 回收 → 竞品周报 |
| 日 | 取数 → 判表 → 执行 → 收口（详见第 18 章） |
| 年中 | 7 月一次正式滚动重算（一年仅此一次修订预算） |
| 红线 | 预算一经批准，年内只允许年中一次修订；频繁改等于没有预算 |

### 场景：你是新接手的收益岗，第一个月该怎么排

| 判据 | 结论 |
|---|---|
| 先看"年"层是否健全 | 年度预算有吗？拆到日了吗？需求日历有吗？ |
| 若年层缺失 | 先补日历与日目标（成本最低、见效最快）✓ |
| 再看"月"层 | 上月月报做了吗？RGI 拆了吗？ |
| 再看"周"层 | 每周一是否固定更新日历与回收动作？ |
| 最后看"日"层 | 每日四阶段是否跑起来了？（第 18 章） |
| 常见顺序错误 | 先做日报再做年预算 → 越忙越乱 ✗ |
| 建议顺序 | 年(目标/日历) → 周(更新机制) → 日(四阶段) → 月(复盘) |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| 刚接手，不知从哪下手 | 先补"年"层（日历 + 日目标），不要先做日报 |
| 每天很忙但没方向 | 多半是年/季/月层缺失 → 先建年度目标与需求日历 |
| 只能先补一层 | 先补"周"层的日历更新（最便宜、见效最快） |
| 事件日当天才知道 | 建立信息源清单 + 指定销售每月同步 30 分钟 |
| 年底目标没完成 | 查年初市场假设是否写明——没写就无法归因 |


## 五、课堂案例（直接用正文里的）

### 案例 · 有节奏和没节奏

A 店每天很忙，但只在当天看当天；B 店按年→季→月→周→日五层运转。 A 店永远在救火：事件日当天才发现、月底才知道完不成目标、竞品降价后手忙脚乱。 / B 店提前 60 天布价、每周滚动更新、每天只做当天该做的动作。 / 同样的 12 个决策工具，有没有节奏，结果是两回事。

### 案例二 · 只补一层带来的变化

某店此前完全没有节奏。新收益经理第一个月只补了一件事：每周一更新需求日历。 四周后变化：事件日提前 2–4 周被发现并布价，其中一次本地展会日的 ADR 比去年同期高 31%。 / 仅这一层，当月 RevPAR 就提升了 4.2%。 / 结论：如果只能先补一层，先补"周"层的日历更新——它最便宜，见效最快。

### 案例四 · 五层节奏如何配合（含对话）

年度经营会上的一段对话： / 总经理："明年目标 3,200 万，你们怎么拆？" / 收益："先按月指数拆到月，再按星期几拆到日。8 月指数 1.3 → 目标 347 万，日均约 11.2 万。" / 销售："那我每个月该做什么？" / 收益："你负责'年'层的协议价重谈（1 月）和'季'层的大客户预谈（每季中）。" / 前厅："我呢？" / 收益："你负责'日'层的早会同步与超售额度执行。" / 市场："我？" / 收益："你负责'周'层的竞品周报和'月'层的渠道复盘。" / 总经理："所以每个人在不同层上有不同的责任。" 收益："对。收益管理不是一个人在五层上跑，是五个人各守一层。我只负责把它们串起来。" / 结论：节奏的价值之一是"分责"。五层清晰，每个部门才知道自己在什么时候该做什么——否则所有人都在最后一层（日）上救火。


## 六、容易讲错的地方

- 自学者提示：先别急着背这张表。你只要记住一句话：越早的那层越重要——年度目标没拆到日，后面全是救火。 / 练习：拿一张纸，写下你所在酒店（或实习酒店）去年做过"年、季、月、周、日"中的哪几层？缺的那层，就是最该补的。

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- 关键：外层没定好，内层再忙也是救火。 / 年度目标没拆到日 → 每天没有"该卖多少"的判据，只能凭当天感觉； / 需求日历没建 → 事件日当天才知道，来不及布价。 / 这就是为什么本书把"运营"排在第二篇之后——先有工具，再学怎么把它们排进时间。
- 到了这一天，收益岗看到的不是"今天行情如何"，而是"今天目标是 RevPAR 1,350，当前在手对应多少"。 / 有了日目标，"该不该调价"就不再是感觉问题，而是缺口问题。这是整本书从"方法"走向"管理"的关键一步。 二、各周期的固定动作 本章判定表 · 各周期该做什么 年市场假设 → 年度预算（目标×月指数）→ 全年需求日历 → BAR 体系年审 → 协议价重谈 季滚动重算剩余月份 → 淡旺季策略切换 → 竞争群更新 → 协议与大客户预谈 → 季度复盘 月结帐核对 → 月报（RGI/MPI/ARI）→ 渠道净价复盘 → 价目表复核 → 次月目标分解到日 周周一更新需求日历（滚动+7 天）→
- 练习 五层节奏分别解决什么问题？ 为什么"年度目标没拆到日"会导致每天只能救火？ 一年允许修订几次预算？在什么时候？ 如果只能先补一层，你会先补哪层？为什么？ 层与层之间如何连通？举一个例子。 本章小结（5 条，可复述） 五层节奏：年（定目标）→ 季（换挡）→ 月（校准）→ 周（布动作）→ 日（执行+记录）。 越外层越"定方向"：外层没定好，内层再忙也是救火。 层与层要连通：年度目标拆到日；月报回头修正年度假设。 年度目标应拆到日——这样"该不该调价"才是缺口问题，不是感觉问题。 一年只允许年中修订一次（7 月），逼你把偏差讲清楚。
- 练习（进阶） 五层节奏分别由哪个部门主责？试着给你所在的机构分一下。 把"年度 3,000 万"拆到某一天（给出月度指数、日均、RevPAR 目标）。 为什么"一年只修订一次"反而让预算更有效？ 常见场景速查遇到下面这些情况，直接按"动作"做 刚接手，不知从哪下手先补"年"层（日历 + 日目标），不要先做日报 每天很忙但没方向多半是年/季/月层缺失 → 先建年度目标与需求日历 只能先补一层先补"周"层的日历更新（最便宜、见效最快） 事件日当天才知道建立信息源清单 + 指定销售每月同步 30 分钟 年底目标没完成查年初市场假设是否写明——没写就无法归因
