## 一、学完这一章，学生能做到什么

- 读完能算清：为什么直销是收益管理里最重要的一件事。
- 直销净价最高：无佣金，且能掌握客人数据（可做复购与精准营销）。
- 会员体系是直销的载体：用权益（而非裸价折扣）换忠诚度——裸价折扣会与 OTA 打架并拉低整体价格。
- 直销靠"独有权益"而非"低价"：延迟退房、免费升级、积分、专属客服——这些 OTA 给不了。

## 三、讲这一章要用的公式与定义

- **核心公式**：渠道成本节约 = 转到直销的间夜数 × 售价 × OTA 佣金率 会员价值 = 复购次数 × 客单价 × (1 − 维护成本率)
- **算例 3 · 直销提升的整体账**：年售 20,000 间夜，售价 500，OTA 佣金 15% 直销占比 20% → 35%：转移 3,000 间夜 节约佣金 = 3,000 × 500 × 15% = 225,000 会员权益投入（升级+早餐+系统）= 约 60,000 净增利润 ≈ 165,000/年

## 四、讲这一章要用的判定表

### 本章判定表 · 直销怎么做才有效

| 判据 | 结论 |
|---|---|
| 靠什么吸引 | 独有权益（延迟退房/免费升级/积分/专属客服）＞ 裸价折扣 |
| 价格是否一致 | 官网与 OTA 同房型同价（差异体现在权益，不是裸价） |
| 是否有会员分层 | 至少 2–3 级，权益逐级递增，给客人升级的理由 |
| 是否有复购机制 | 入住后 7 日内触达、生日/纪念日营销、积分到期提醒 |
| 前台是否参与 | 前台引导复购转直销是最有效的动作（成本最低、转化最高） |
| 是否有数据沉淀 | 会员数据要能支撑复购分析，否则只是打折卡 |
| 常见错误 | 官网比 OTA 明显便宜 → 引发 OTA 不满（可能降权）且拉低价格体系 |

### 场景：市场部提议官网裸价比 OTA 低 10% 拉直销

| 判据 | 结论 |
|---|---|
| 靠什么吸引？ | 提议靠"裸价更低" → 应改为权益 ✗ |
| 价格一致性 | 同房型不同价 → 破坏一致性 ✗ |
| 会员分层？ | 无分层，只是打折 → ✗ |
| 复购机制？ | 无离店触达 → ✗ |
| 前台参与？ | 前台未引导 → ✗ |
| 数据沉淀？ | 无会员数据 → ✗ |
| OTA 反应 | 会被检测价差并降权 → 风险 ✗ |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| 市场部要"官网比 OTA 便宜" | 否决——会引发 OTA 降权并拉低整体价格体系 |
| 直销拉不动 | 最有效的动作是前台退房时一句话（成本近零） |
| 会员办了但不复购 | 缺分层与复购触达（离店 7 天回访、生日、积分提醒） |
| 要不要给会员折扣 | 给权益（升级/延迟退房/积分），不给裸价折扣 |
| 算直销值不值 | 节约佣金 = 转移间夜 × 售价 × 佣金率；再减权益成本 |


## 五、课堂案例（直接用正文里的）

### 案例一 · 前台一句话的价值

某店要求前台在退房时对客人说一句："下次直接通过我们官网订，可享延迟退房和免费升级机会。" 三个月后，官网直销占比从 12% 升到 21%。 / 按年售 20,000 间夜、佣金 15%、售价 500 算，节约佣金约 90 万元/年。 / 而投入只是一句话——这是收益管理里投入产出比最高的动作之一。

### 案例二 · 官网低价的反噬

某店为拉直销，把官网裸价定得比 OTA 低 12%。 短期直销占比上升；但 OTA 检测到价差后降低该店权重，OTA 渠道间夜大跌；同时客人习惯了"官网更便宜"，价格体系被拉低。 / 半年后总 RevPAR 反而下降。 / 结论：直销要靠"权益差异"，不能靠"裸价差异"。

### 案例三 · 会员分层的效果

某店会员体系原本只有一级、"全部 9 折"。改为三级：银卡 95 折、金卡 9 折、白金 85 折 + 升级 + 延迟退房。 结果：会员数增长 30%，更重要的是已有会员为升级而增加入住频次——金卡会员年均入住从 2.8 次升到 4.1 次。 / 结论：会员体系的价值不在"打折"，在"给一个往上走的理由"。没有分层，就没有忠诚，只有搭便车。


## 六、容易讲错的地方

- 自学者提示：直销的核心不是"把 OTA 的客人抢过来"，而是"让住过的人下次直接找你"。复购客人才是直销的主力——这也是为什么"前台一句话"和"退房后 7 日触达"如此有效。

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- 算例 1：年售 20,000 间夜，OTA 佣金 15%，售价 500。 / 若把 OTA 占比从 55% 降到 40%（3,000 间夜转到直销）： / 节约佣金 = 3,000 × 500 × 15% = 225,000 元/年。 / 而会员权益投入（升级、早餐、积分）远低于此。 / / 算例 2（复购的价值）：一位会员年均住 4 次、客单 500 → 年贡献 2,000 元。 / 若维护成本率 10%，会员价值 ≈ 1,800 元/年。 / 这就是为什么要投入会员体系——它的价值是多年复购，不是单次。
- 净增 16.5 万/年，而主要动作只是"前台一句话"和"离店回访"。 / 若再叠加复购提升（42%→55%），长期价值更高。 / 结论：直销是收益管理里少有的"成本极低、回报极高、且可持续"的动作。
- 用法：直销的第一抓手不是做广告，是让前台在退房时说一句话——成本几乎为零，转化率最高。填表示例 · 官网该不该比 OTA 便宜场景：市场部提议官网裸价比 OTA 低 10% 拉直销 靠什么吸引？提议靠"裸价更低" → 应改为权益 ✗ 价格一致性同房型不同价 → 破坏一致性 ✗ 会员分层？无分层，只是打折 → ✗ 复购机制？无离店触达 → ✗ 前台参与？前台未引导 → ✗ 数据沉淀？无会员数据 → ✗ OTA 反应会被检测价差并降权 → 风险 ✗ 结论：七项全不满足 → 否决。 / 替代方案：官网与 OTA 同价，但官网额外给"延迟退房 + 升级机会 + 积分加倍"；同时让前台在退房时引导客人下
- 练习 年售 15,000 间夜，售价 480，佣金 16%，若直销占比提升 10 个百分点，节约多少？ 为什么官网不宜比 OTA 明显便宜？ 列举 3 项"非价格"的会员权益。 为什么会员体系需要分层？ 为什么"让住过的人下次直接找你"比拉新客更重要？ 本章小结（5 条，可复述） 直销价值有二：净价最高（无佣金）＋ 掌握客人数据（可复购触达）。 靠权益不靠裸价：延迟退房、升级、积分、专属客服——OTA 给不了。 会员分层是核心：没有升级路径，就没有忠诚，只有搭便车。 前台一句话是最高效的动作：成本近零、转化率最高。 看终身价值：获客投入应对标高复购客源，而非一次性订单。
