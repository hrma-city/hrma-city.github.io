## 一、学完这一章，学生能做到什么

- 读完能迁移：把收益管理用到酒店之外。
- 套用第 1 章判定表：易逝、固定、波动、可分层——四条全中即可用。
- 换的是参数，不是逻辑：把"房晚"换成"座位/车位/机位/时段"，逻辑完全一样。
- 行业差异在栅栏形式：酒店用"提前订/不可退"，影院用"时段"，健身房用"年卡/次卡"。

## 三、讲这一章要用的公式与定义

- **迁移公式（通用）**：产能单位：房晚 → 座位 / 车位 / 机位 / 时段 / 舱位 核心指标：RevPAR → RevPASH（餐饮）/ RASM（航空）/ 单位时段收入 控制阀门：价格 + 可得性（开关某价档 / 加限制条件）
- **算例 3 · 停车场的完整迁移**：产能＝车位×小时（易逝、固定） 需求＝早晚高峰 vs 夜间（波动） 客群＝临停 / 月租 / 预约（可分层） 栅栏＝时段（夜间包月不可白天用） 指标＝车位小时收入（对应 RevPAR） 动作＝高峰提价、闲时包月、月租限量、预约配额

## 四、讲这一章要用的判定表

### 本章判定表 · 这个行业能不能用（回到第 1 章）

| 判据 | 结论 |
|---|---|
| 产能是否易逝 | 过期作废 → 可；可储存 → 不可 |
| 产能是否短期固定 | 无法快速扩产 → 可 |
| 需求是否波动 | 有明显时段/季节差 → 可 |
| 客群是否可分层 | 支付意愿不同 → 可 |
| 能否提前预订 | 能 → 可做预测与保护位；不能 → 只能现场定价 |
| 栅栏是什么 | 找出该行业天然的"限制条件"（时段/会员/不可退/资质） |
| 指标怎么换 | 把 RevPAR 换成"单位产能单位时间的收入" |

### 场景：有人问"剧本杀门店"能做收益管理吗

| 判据 | 结论 |
|---|---|
| 产能是否易逝？ | 一场卖不掉即归零 → 是 ✓ |
| 产能是否固定？ | 房间数与场次短期固定 → 是 ✓ |
| 需求是否波动？ | 周末与工作日晚间差异极大 → 是 ✓ |
| 客群可分层？ | 有拼场客、包场客、会员 → 是 ✓ |
| 能否提前预订？ | 可线上预约 → 是 ✓ |
| 天然栅栏？ | 场次 + 时段（工作日场更便宜）✓ |
| 指标怎么换？ | 每房每小时收入（对应 RevPAR）✓ |

### 要把这套方法用到新行业，先答这六个问题

| 判据 | 结论 |
|---|---|
| ① 产能单位是什么？ | 房晚 → 座位 / 车位 / 机位 / 时段 / 诊位 |
| ② 是否过期作废？ | 是 → 需收益管理；可储存 → 不适用 |
| ③ 需求是否波动？ | 有明显时段差 → 适用 |
| ④ 客群能否分层？ | 支付意愿不同 → 适用 |
| ⑤ 天然栅栏是什么？ | 时段 / 会员 / 预付不可退 / 场次——要去找 |
| ⑥ 指标怎么换？ | 改成"单位产能单位时间的收入" |


## 五、课堂案例（直接用正文里的）

### 案例一 · 长短租配比（公寓）

某公寓 50 套。长租月租 4,000（稳定），短租日均 320（波动，淡季常空）。 旺季短租月化可达 320 × 30 × 85% = 8,160 &gt; 4,000 → 旺季增量转短租。 / 淡季短租月化约 320 × 30 × 40% = 3,840 &lt; 4,000 → 淡季转长租。 / 关键：保留长租基本盘（如 70%），用剩余 30% 做短租弹性。

### 案例二 · 健身房的一次"收益管理"

健身房晚 7–9 点器械排队，下午 2–5 点几乎没人。 做法：推出"午后卡"（价格低 40%，限工作日 14:00–17:00 入场）。 / 结果：闲时利用率提升，晚间拥挤缓解，且年卡价格体系未被侵蚀（因为栅栏是"时段"）。 / 这正是酒店的"淡季套餐 + 栅栏"逻辑——换了个产能单位而已。

### 案例三 · 一次失败的迁移

某学员把酒店的做法直接搬到生鲜超市：对临期商品"提前预订打折"。 失败原因：生鲜的问题不是"卖给谁"，而是"损耗速度不可控"——产能确实易逝，但需求预测精度极低，且客群分层不明显（所有人都要便宜的）。 / 判定表第 3、4 项实际不满足。 / 结论：判定表不是走过场。前四项中任一项不满足，迁移就会失败——这能帮你省下试错成本。


## 六、容易讲错的地方

- 自学者提示：练习迁移最好的方法：挑一个你熟悉的行业，把它的产能单位、易逝性、客群分层、天然栅栏写下来，然后套用第 12 章的保护位和第 10 章的栅栏。你能迁移成功一次，就真正掌握了这门学科。

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- 算例（停车场）：产能＝车位×小时，易逝、固定；需求早晚高峰波动；客群分临停/月租/预约。 / 做法：高峰提价、闲时套餐（夜间包月）、月租限量、预约配额。 / 完全对应酒店的：旺季守价、淡季套餐、团队置换、渠道配额。
- 六项全部对应酒店的六个概念——产能易逝、需求波动、客群分层、栅栏、指标、动作。 / 结论：迁移的不是公式，是这六个问题的答案。答出这六个，任何行业都能用。
- 用法：拿到一个新行业，先填这七项。前五项全中，就一定能用；第六项决定你用什么栅栏。填表示例 · 一个新行业能不能用场景：有人问"剧本杀门店"能做收益管理吗 产能是否易逝？一场卖不掉即归零 → 是 ✓ 产能是否固定？房间数与场次短期固定 → 是 ✓ 需求是否波动？周末与工作日晚间差异极大 → 是 ✓ 客群可分层？有拼场客、包场客、会员 → 是 ✓ 能否提前预订？可线上预约 → 是 ✓ 天然栅栏？场次 + 时段（工作日场更便宜）✓ 指标怎么换？每房每小时收入（对应 RevPAR）✓ 结论：全中 → 完全适用。 / 具体打法：工作日场降价（带栅栏）、周末场守价、拼场与包场分设保护位（第 12 章）、
- 练习 用判定表判断：医美诊所预约是否适用收益管理？ 航空业的核心指标 RASM 对应酒店的什么？ 举一个"产能可储存、因此不适用"的生意。 停车场的天然栅栏是什么？ 挑一个你熟悉的行业，写出它的产能单位与三个客群分层。 本章小结（5 条，可复述） 迁移六问：产能单位、是否易逝、是否波动、能否分层、天然栅栏、指标怎么换。 前四项全中才适用；后两项决定"用什么栅栏、看什么指标"。 搬逻辑，不搬形式——房型、MinLOS 是酒店的形式，不是逻辑本身。 每个行业都有天然栅栏：时段、会员、预付不可退、场次——要去找。 判定表能帮你省下试错成本：不满足就不要硬搬。
