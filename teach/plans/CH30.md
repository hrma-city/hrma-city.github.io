## 一、学完这一章，学生能做到什么

- 读完能评估：一个会议该不该接——看的是综合贡献，不是房价。
- 会议要算综合贡献：客房 + 餐饮 + 场地 + 其他消费，减去全部变动成本。
- 要算机会成本：会议室和客房被占用，挤掉了什么？（置换分析，第 15 章） 会议常能填淡季：这是它最大的价值——填的是本来会空的日子。

## 三、讲这一章要用的公式与定义

- **核心公式**：会议综合贡献 = 客房贡献 + 餐饮贡献 + 场地贡献 − 被挤掉的散客期望收益 判定：综合贡献 &gt; 0 且高于替代方案 → 接
- **算例 3 · 一次会议的完整测算**：会议：80 间夜 @380，餐饮 6 万，场地 2.5 万 客房让利：80 × (520−380) = 11,200（负） 餐饮贡献：60,000 × 35% = 21,000 场地贡献：25,000 × 70% = 17,500 挤出散客：旺季散客期望 30 间 × 520 = 15,600（负） 综合 = −11,200 + 21,000 + 17,500 − 15,600 = +11,700

## 四、讲这一章要用的判定表

### 本章判定表 · 会议该不该接

| 判据 | 结论 |
|---|---|
| 是否填淡季 | 淡季/平季 → 放宽；旺季 → 严格（散客更值） |
| 综合贡献 | 必须为正且高于替代方案（不能只看房价） |
| 占用多少可售房 | 占用 &gt;30% 可售房 → 谨慎（挤散客风险大） |
| 餐饮与场地贡献 | 必须实际核算，不能"感觉有" |
| 取消与缩减风险 | 会议常临时缩规模 → 合同须约定阶梯与违约 |
| 是否需要会议室 | 占用会议室可能挤掉其他高价值宴会，要一起算 |
| 最佳用途 | 用会议填淡季与周中——这是它最正确的用法 |

### 场景：旺季周五，会议要 60 间 @400 + 宴会

| 判据 | 结论 |
|---|---|
| 填淡季吗？ | 周五旺季 → 不是 ✗ |
| 综合贡献 | 初步算 +8,000 → 为正但不高 △ |
| 占可售房比例 | 60/100 = 60% → 远超 30% 警戒线 ✗ |
| 挤出散客 | 旺季散客期望 45 间 × 560 = 25,200 → 损失大 ✗ |
| 会议室冲突 | 当天有婚宴询价（场地贡献更高）→ 冲突 ✗ |
| 缩减风险 | 无违约条款 → ✗ |
| 建议动作 | ① 改期到周中/淡季；② 或提价到 520；③ 或只接 30 间 |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| 销售问这个会接不接 | 填综合贡献表：客房+餐饮+场地−被挤散客期望收益 |
| 客户要的量太大 | 给三个替代方案：减量 / 提价 / 改期 |
| 旺季周末来会议 | 挤出散客损失大 → 谨慎；优先建议改期到周中 |
| 客户要一口价 | 改阶梯报价（房量/餐饮/场地分列）——更易成交且保收益 |
| 会议临时缩规模 | 合同必须约定阶梯与违约 |
| 场地收入怎么算贡献 | 按净贡献（通常 60–75%），不是按全额 |


## 五、课堂案例（直接用正文里的）

### 案例 · 旺季拒接，淡季接

同一家公司两个会：一个在旺季周末（要 80 间 @380），一个在淡季周三（要 80 间 @380）。 旺季周末：散客净价 650，挤掉散客损失大，且餐饮场地贡献补不回 → 婉拒或提价。 / 淡季周三：散客需求弱，原本要空 80 间 → 接，且综合贡献为正。 / 结论：同一个价、同一个客户，在不同日子是两笔完全不同的生意。

### 案例三 · 阶梯报价救了一单

某客户要求"一口价"。销售改为阶梯报价：房量 30/50/80 分别对应 480/430/390，餐饮与场地单列。 客户最终选了 50 间 @430 + 精简餐饮，比原一口价方案总贡献更高，且客户觉得"可以自己选，很灵活"。 / 结论：阶梯报价既保护了收益（量越大价越低但可控），又给了客户选择感——比一口价更容易成交。

### 案例四 · 一次会议改期的谈判（含对话）

销售与客户的对话： / 客户："我们要 80 间，周五到周日，400 一间。" / 销售："周五是旺季，全天满房风险高。这个日期我们最多给 30 间 @480。" / 客户："那太少了。" / 销售："如果改到周日至周二，80 间可以按 380，而且会议室免费升级。" / 客户："改期有点难……但便宜不少。" / 销售："另外，周中的餐饮我们可以给更好的方案，因为厨房不忙。" / 客户："那我回去商量一下。" 结果：客户改到周日至周二，80 间 @380 + 会议室升级。 / 酒店侧核算：旺季周五的散客机会成本很高（约 520/间），改到周中后机会成本近乎为零 → 综合贡献反而更高，且客户更满意（价格更低 + 会议室升级）。 / 结论：会议谈判的最佳筹码不是价格，是"日期"。会算机会成本的销售，能用"改期"同时满足客户和酒店。


## 六、容易讲错的地方

- 自学者提示：会议报价不要一口价。做阶梯报价（房量、餐饮、场地分开报），便于调整组合，也避免客户只挑便宜的部分——这是销售的常识，也是收益的防线。

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- 算例：某会议 100 间夜 @350（散客净价 500），餐饮 80,000，场地 30,000。 / 客房少赚：100 × (500 − 350) = 15,000。 / 餐饮贡献（按 35% 边际）：28,000；场地贡献（按 70%）：21,000。 / 综合 = −15,000 + 28,000 + 21,000 = +34,000 → 可接。 / 若该会议在旺季（散客需求强），还要再扣被挤散客的机会成本——结论可能反转。
- 若为旺季，挤出损失大 → 仅 +11,700，风险不小；若改到淡季（挤出损失≈0）→ 综合可达 +27,300。 / 结论：同一个会议，换到淡季价值翻倍。这正是"会议最佳用途是填淡季"的算术依据。
- 用法：会议报价不要一口价。做阶梯报价（房量、餐饮、场地分开报），便于调整组合，也避免客户只挑便宜的部分。填表示例 · 这个会议接不接场景：旺季周五，会议要 60 间 @400 + 宴会 填淡季吗？周五旺季 → 不是 ✗ 综合贡献初步算 +8,000 → 为正但不高 △ 占可售房比例60/100 = 60% → 远超 30% 警戒线 ✗ 挤出散客旺季散客期望 45 间 × 560 = 25,200 → 损失大 ✗ 会议室冲突当天有婚宴询价（场地贡献更高）→ 冲突 ✗ 缩减风险无违约条款 → ✗ 建议动作① 改期到周中/淡季；② 或提价到 520；③ 或只接 30 间 结论：原方案不接，给出三个替
- 练习 会议 80 间夜 @360，散客净价 520，餐饮贡献 25,000，场地贡献 18,000。综合贡献多少？ 为什么同一个会议在旺季和淡季结论不同？ 会议合同为什么要约定缩减与违约条款？ 为什么会议报价要做阶梯报价？ 占用会议室可能挤掉什么？如何计入？ 本章小结（5 条，可复述） 综合贡献＝客房 + 餐饮 + 场地 − 被挤散客的期望收益。 不能只看房价——房价让利可能由餐饮与场地补回。 会议最佳用途是填淡季与周中（机会成本近乎为零）。 占用 &gt;30% 可售房要谨慎；旺季尤其要控团量。 阶梯报价 + 违约条款：便于组合调整，也防临时缩规模。
