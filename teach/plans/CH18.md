## 四、讲这一章要用的判定表

### 本章判定表 · 一天的完整时间轴

| 判据 | 结论 |
|---|---|
| 07:30–08:10 | 取数：今日在手、昨日实际、pickup 新增、取消/No-show、竞品价、渠道配额 |
| 08:10–08:40 | 判表：对照需求日历与判定表——量差还是价差、缺口多大、还剩几天 |
| 08:40–09:00 | 早会 15′：与前厅/销售同步今日开关哪些价档、限制条件、超售额度 |
| 09:00–12:00 | 执行：调价、开关渠道、设/撤 MinLOS·CTA·CTD、超售设置、团队决策 |
| 12:00–14:00 | 盯盘：监控 pickup 与竞品变动，偏离阈值即刻调整（不等明天） |
| 14:00–16:00 | 滚动未来窗：修正未来 7–14 天的保护位与价档（不只盯今天） |
| 16:00–17:00 | 临近回收：D-7 收紧（关低价、加限制）；D-3 回收（收团队预留） |
| 17:00–18:00 | 收口：记录改了什么、为什么、谁批；写日报；交接夜班 |

### 场景：14:00 滚动未来窗，检查未来 7 天

| 判据 | 结论 |
|---|---|
| 未来 7 日在手 vs 去年 | 高 14% → 整体偏强 ✓ |
| 哪几天异常？ | 第 5 天低于去年 12% → 需要单独处理 |
| 该日是什么日子？ | 查日历：非事件日、周三 → 普通日 |
| 当前价档？ | 已开到第三档（偏低）→ 有收紧空间 |
| 动作 | 该日关掉最低两档，保留中高两档 |
| 其余 6 天 | 保持现状，不动作 |
| 记录 | 写入日报："D+5 收紧两档，原因：在手低于去年 12%" |

### 每日三条红线

| 判据 | 结论 |
|---|---|
| 价格 ≥ 变动成本 | 否则多卖一间多亏一间（第 26 章） |
| 超售 ≤ walk 容忍率 | 否则赔客户还毁口碑（第 11 章） |
| 不破 BAR 层级 | 公开价不得高于协议/会员价，否则失公平、引投诉（第 22 章） |


## 五、课堂案例（直接用正文里的）

### 案例 · 只盯今天的代价

某店每天只调当天价格，从不看未来 7–14 天。 结果：所有动作都发生在最后 48 小时，此时要么已卖光、要么只能贱卖。 / 改为每天下午固定 2 小时滚动看未来窗后，同样的房量，ADR 提升 9%。 / 结论：收益管理管的不是"今天"，是"未来的每一天"。今天的结果，是过去 30 天的决策决定的。

### 案例二 · 收口这一行字的价值

某店坚持每天写"改了什么、为什么、谁批"。半年后做复盘时，他们发现一个规律：凡是由销售要求、收益岗未留痕的降价，事后 80% 被证明是不必要的。 有了这个证据，店长在经营会上推动了一条新规：所有偏离 BAR 的价格必须书面申请。 / 一条规则，堵住了最大的漏洞。 / 结论：记录不是为了追责，是为了让"感觉"变成"证据"。没有记录，你在会上永远说不过嗓门大的人。

### 案例四 · 一天的完整记录（日报范本）

某收益专员一天的日报（可作为模板）： / 日期：6 月 14 日（周五），距某紧俏周六还有 1 天 / 取数：在手 88/100；pickup 昨日 +9（历史 +6）；取消 3（3.4%）；竞品均价 620（我 580）；OTA 配额用 85%；未来 7 日在手高于去年 11% / 判表：在手高 11%（阈值 10%）✓｜pickup 快 ✓｜剩 1 天 ✗｜低于竞品 6% ✓ / 动作：因剩余仅 1 天，不提价；关闭最低价档；超售设 5 间（标准房 5、套房 0） / 早会：同步前台——今日只开中高档，超售 5 间，预留 2 间升级池 / 收口：17:20 记录完毕，交接夜班：关注 3 位未确认到店的客人 这份日报的价值在于：三个月后回看，能立刻知道当时为什么这么做、做对了没有。 / 该店后来统计：坚持写日报后，重复犯同类错误的次数下降了约 60%——因为错误变得可见了。 / 结论：日


## 六、容易讲错的地方

- 自学者提示：把这张时间轴打印出来贴在桌前，照着跑两周。固定动作的价值在于——它让你不用每天重新决定"该干什么"。这两周你会明显感到工作变轻了，而不是变重了。

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- ① 取数：把事实拿全（在手、pickup、竞品、配额、取消） / ② 判表：对照判定表找缺口（量差还是价差、剩几天） / ③ 执行：按优先级做动作（先可得性，后价格） / ④ 收口：记录与交接（改了什么、为什么、谁批）
- 整个判断过程只用了 40 分钟和 6 个数字，而且每个动作都能指到判定表的具体一行。 / 这就是"可复盘"的含义：三个月后回看，你能知道自己当时为什么这么做、做对了没有。
- 用法：照此表执行。下午 14:00–16:00 的"滚动未来窗"最容易被跳过，也最不该跳过——它是把"做事"变成"管理"的关键。填表示例 · 今天要不要动价格场景：14:00 滚动未来窗，检查未来 7 天 未来 7 日在手 vs 去年高 14% → 整体偏强 ✓ 哪几天异常？第 5 天低于去年 12% → 需要单独处理 该日是什么日子？查日历：非事件日、周三 → 普通日 当前价档？已开到第三档（偏低）→ 有收紧空间 动作该日关掉最低两档，保留中高两档 其余 6 天保持现状，不动作 记录写入日报："D+5 收紧两档，原因：在手低于去年 12%" 结论：只动异常的那一天，其余不动。 / 这是滚动未
