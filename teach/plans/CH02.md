# 第 2 章 · 三个核心指标：OCC、ADR、RevPAR 教案

> 教材定位：第一篇 · 认知篇 ｜ 本质与衡量 ｜ 第 2 章 ｜ 建议课时：3 课时（每课时 90 分钟）｜ 配套正文：教材第 2 章
> 配套资源：教师用书同章（`textbook-teacher.html#tch02`）｜ 学员自学页：`learn.html#ch02`

## 一、学完这一章，学生能做到什么

- 读完能算清：一家酒店经营得好不好，不靠感觉。
- OCC（出租率）＝已售房 ÷ 可售房。
- 但单独看会误导——因为它不告诉你卖多少钱。
- 一间 100 元卖掉和 1000 元卖掉，在出租率上是完全一样的。
- ADR（平均房价）＝客房收入 ÷ 已售房。
- 单独看同样误导——因为它不告诉你卖了多少间。
- 只卖 1 间 1000 元的房，ADR 是 1000，但酒店几乎是空的。
- RevPAR（每可售房收入）＝ OCC × ADR ＝客房总收入 ÷ 可售房总数。
- 它是唯一把量与价合在一起的核心指标，也是行业通用的经营结果指标。

## 三、讲这一章要用的公式与定义

- **核心公式**：RevPAR = OCC × ADR = 客房总收入 ÷ 可售房总数
- **算例 4 · 两种提升 RevPAR 的路径**：当前：OCC 60%、ADR 500 → RevPAR 300 路径甲（提价）：OCC 55%、ADR 560 → RevPAR 308 路径乙（放量）：OCC 70%、ADR 470 → RevPAR 329

## 四、讲这一章要用的判定表

### 本章判定表 · 用哪个指标评价经营

| 判据 | 结论 |
|---|---|
| 看"卖得满不满" | 用 OCC，但绝不能单独用它做奖惩（会诱发低价填房） |
| 看"卖得贵不贵" | 用 ADR，同样不能单独用（会诱发空房死守高价） |
| 看"整体经营结果" | 用 RevPAR（量与价的乘积）——行业通用 |
| 看"赚不赚钱" | RevPAR 不够，要看 GOPPAR（第 26 章）——渠道佣金会吃掉收入 |
| 看"相对市场" | 要看 RGI（第 3 章）——市场普跌时跌得少就是赢 |
| 降价是否划算 | 降 X% 价，量必须涨超过 X% 才划算（第 4 章） |
| 常见错误 | 用"平均房价"代替"实际到手价"；用"出租率"代替"收入" |

### 场景：月底经营会，你只有 3 分钟汇报

| 判据 | 结论 |
|---|---|
| 先看结果指标 | 报 RevPAR（并与预算、去年同期比）✓ |
| 再看相对位置 | 报 RGI（市场涨跌时尤其重要）✓ |
| 补充量与价 | 同时给出 OCC 与 ADR，说明变化来自哪一侧 ✓ |
| 是否报出租率 | 可作参考，但不得单独作为成绩 ✗ |
| 是否报平均房价 | 同上，不得单独作为成绩 ✗ |
| 是否扣渠道成本 | 季度/年度汇报必须给出 GOPPAR ✓ |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| 要汇报本月经营 | 必报 RevPAR + RGI，并同时给出 OCC 与 ADR 说明变化来自哪一侧 |
| 出租率很高但收入不高 | 算 RevPAR，多半是房价太低；查渠道结构（第 13 章） |
| 房价很高但收入不高 | 算 RevPAR，多半是出租率太低；查渠道曝光与竞品（第 3、24 章） |
| 有人提议降价冲量 | 先算临界量：降 X% 需量涨超 X%（10%→11.1%） |
| 要定明年目标 | 不能用"今年+10%"，要按月指数拆到日（第 21 章） |


## 五、课堂案例（直接用正文里的）

### 案例一 · 降价换量是否划算

100 间房，当前 OCC 60%、ADR 500，RevPAR = 300。 / 方案：降价到 450，预计出租率升到 70%。 新 RevPAR = 70% × 450 = 315 &gt; 300 → 划算。 / 但如果出租率只升到 64%：64% × 450 = 288 &lt; 300 → 不划算。 / 关键：降价是否划算，完全取决于能否换来足够的量。

### 案例二 · 两个团队，两种考核

A 店考核前厅"出租率"，考核销售"平均房价"。B 店两个部门都考核 RevPAR。 A 店：前厅为冲出租率低价甩房，销售为守房价拒绝团队——两个部门互相打架，公司整体受损。 / B 店：两个部门都被迫同时考虑量与价，会主动协商"什么时候该放、什么时候该守"。 / 结论：指标怎么设，团队就怎么干。用单一指标考核，一定会诱发扭曲行为。

### 案例三 · 被指标误导的一次奖惩

某集团对店长考核"出租率排名"，第一名奖励。结果各店纷纷低价甩房冲量。 半年后：集团整体出租率从 72% 升到 81%，但 RevPAR 反而下降 6%，利润下降更明显。 / 集团改为考核 RevPAR 与 GOPPAR 后，出租率回落到 76%，但利润回升。 / 结论：你考核什么，就会得到什么。考核出租率，一定得到低价；考核利润，才能得到经营。


## 六、容易讲错的地方

- 自学者提示：记住一个速判法——降价 X% 后，出租率必须提升超过 X% 才划得来。降 10% 价，量要涨 10% 以上（严格说是 11.1%）。 / 练习方法：随便找一家酒店，用"房价 × 出租率"心算它的 RevPAR，再和上个月比——你会发现自己开始像收益经理一样思考了。

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- 算例 1：100 间房，卖出 70 间，房价 400。 / OCC = 70/100 = 70%；ADR = 400；RevPAR = 70% × 400 = 280 元。 / / 算例 2：另一家 100 间房，卖出 60 间，房价 460。 / OCC = 60%；ADR = 460；RevPAR = 60% × 460 = 276 元。 / 前者出租率高 10 个百分点，RevPAR 只高 4 元。 / / 算例 3（反直觉）：100 间房，只卖 10 间但房价 2,800（某奢侈套房）。 / OCC = 10%；ADR = 2,800；RevPAR = 280。与算例 1 完全相同——
- 本例中放量优于提价——但要注意：放量通常意味着降价，会压缩利润空间。 / 所以 RevPAR 只是第一层判断，最终要看 GOPPAR（第 26 章）。 / 这也解释了为什么"冲出租率"和"守房价"之争永远没有答案——要看哪个路径的利润更高，不是哪个 RevPAR 更高。
- 用法：任何经营汇报，必须同时给出 OCC、ADR、RevPAR 三个数。只给其中一个，都是在回避另一半事实。填表示例 · 月度经营会该怎么汇报场景：月底经营会，你只有 3 分钟汇报 先看结果指标报 RevPAR（并与预算、去年同期比）✓ 再看相对位置报 RGI（市场涨跌时尤其重要）✓ 补充量与价同时给出 OCC 与 ADR，说明变化来自哪一侧 ✓ 是否报出租率可作参考，但不得单独作为成绩 ✗ 是否报平均房价同上，不得单独作为成绩 ✗ 是否扣渠道成本季度/年度汇报必须给出 GOPPAR ✓ 结论：三分钟汇报的标准句式是——"本月 RevPAR 320，完成预算 98%，RGI 103（跑赢市场）
- 练习 120 间房卖 84 间，房价 380，求 OCC、ADR、RevPAR。 RevPAR 320、ADR 400，求出租率。 房价从 500 降到 450（降 10%），出租率要升到多少才能保住原 RevPAR？ A 店 OCC 80%/ADR 400，B 店 OCC 60%/ADR 550，哪家 RevPAR 高？ 为什么不能用"出租率"单独考核前厅？ 本章小结（5 条，可复述） 三个指标：OCC（量）、ADR（价）、RevPAR（量×价）。 单独看会误导：OCC 高可能是低价换来的，ADR 高可能是空房撑的。 核心是 RevPAR＝客房收入 ÷ 可售房数，同时惩罚"空置"与"贱卖"。
