# 第 29 章 · 餐饮收益：RevPASH 与翻台 教案

> 教材定位：第五篇 · 延伸篇 ｜ 迁移与自查 ｜ 第 29 章 ｜ 建议课时：2 课时（每课时 90 分钟）｜ 配套正文：教材第 29 章
> 配套资源：教师用书同章（`textbook-teacher.html#tch29`）｜ 学员自学页：`learn.html#ch29`

## 一、学完这一章，学生能做到什么

- 读完能把收益管理的思路用在餐厅上。
- 餐厅的产能是"座位 × 时间"，比客房更易逝：一小时卖不掉即归零，无法储存。
- RevPASH ＝ 每可用座位每小时收入，是餐饮的核心指标（对应客房的 RevPAR）。
- 调节手段：时段定价（早鸟/下午茶）、限时用餐、套餐、预约配额——本质都是"用条件换价格"。

## 三、讲这一章要用的公式与定义

- **核心公式**：RevPASH = 餐饮收入 ÷ (座位数 × 营业小时数) 翻台率 = 就餐批次 ÷ 座位数（提高翻台＝提高产能利用率） 人均消费 × 翻台率 × 座位数 = 时段收入
- **算例 3 · 翻台与客单的取舍**：100 座，晚餐 3 小时 方案甲（慢翻台）：翻台 1.5 次 × 客单 200 = 300/座·晚 方案乙（快翻台）：翻台 2.2 次 × 客单 160 = 352/座·晚

## 四、讲这一章要用的判定表

### 本章判定表 · 餐饮收益动作

| 判据 | 结论 |
|---|---|
| 核心指标 | 用 RevPASH，不用"上座率"（上座率高但客单低也可能亏） |
| 闲时怎么做 | 时段折扣（早鸟/下午茶/工作日套餐），必须限时（栅栏） |
| 忙时怎么做 | 提高客单（推荐、套餐），而非赶人；必要时设用餐时限 |
| 预约配额 | 给不同渠道设配额（如 OTA 餐饮券限量） |
| 菜单工程 | 分析每道菜的贡献额与受欢迎度，砍掉"高成本低利润"的菜 |
| 与客房联动 | 住客早餐、套餐含餐要计入整体贡献（第 30 章） |
| 红线 | 不得因赶翻台损害体验（会反噬评分，第 24 章） |

### 场景：周一晚餐上座率仅 32%，RevPASH 12

| 判据 | 结论 |
|---|---|
| 核心指标 | RevPASH 12（周末 46）→ 差距明显 |
| 闲时促销 | 推"周一至周三双人套餐"288（原价 400）✓ |
| 有栅栏吗？ | 限周一至周三、限 17:30 前入座 → ✓ |
| 会侵蚀周末吗？ | 周末不可用 → 不会 ✓ |
| 成本真实吗？ | 已与厨房核算套餐成本 → ✓ |
| 预约配额 | 每日限量 30 份 → ✓ |
| 是否赶翻台 | 不设时限（避免伤体验）✓ |
| 预期 | 上座率 32%→55%，RevPASH 12→20（客单降但总量升） |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| 周一晚上没人 | 不要只调人手 → 推限时段的工作日套餐 |
| 上座率很高但没钱赚 | 算 RevPASH与食材成本率；上座率不是利润指标 |
| 想提高翻台 | 优先优化出餐与限时 90 分钟；不要靠压客单 |
| 菜单怎么排 | 按贡献额 × 受欢迎度；销量第一 ≠ 贡献第一 |
| 闲时促销会不会影响周末 | 只要限时段（如仅周一至周三），就不会侵蚀高峰 |


## 五、课堂案例（直接用正文里的）

### 案例 · 周一的问题

某店周一至周三晚餐上座率仅 35%。推出"工作日双人套餐"（原价 400，套餐 288，限周一至周三）。 上座率升到 65%。虽然客单降了，但 RevPASH 从 18 升到 29，且带动了酒水消费。 / 关键：套餐只在工作日可用（栅栏），周末客人无法占用，不侵蚀周末收入。 / 这正是客房"淡季加栅栏促销"的同一套逻辑。

### 案例三 · 菜单工程的发现

某餐厅按"销量"排菜单，把卖得最好的菜放在最显眼位置。 改用"贡献额 × 受欢迎度"两维分析后发现：销量第一的菜贡献额其实很低（食材成本高、制作耗时）；而一道销量中等的菜贡献额排第一。 / 调整后（把高贡献菜前置、重排菜单、优化低贡献菜），人均贡献提升 8%，而客人几乎没察觉变化。 / 结论：销量不等于利润。菜单工程就是餐饮版的"客源结构优化"（第 14 章）——看贡献，不看数量。

### 案例四 · 一间餐厅的时段改造（含数据）

某酒店餐厅 120 座，改造前 RevPASH 全天平均 22，周末晚 46、周一晚 12。 / 改造动作： / ① 按午/晚、周中/周末拆开看 RevPASH → 锁定"周一至周三晚餐"为最大洼地 / ② 推"工作日双人套餐"288（原价 400），限 17:30 前入座、每日 30 份 / ③ 菜单工程：把高贡献菜前置，砍掉两道高成本低利润菜 / ④ 忙时（周末晚）不赶翻台，改为提客单（套餐推荐） 三个月后：周一至周三晚餐上座率 32%→58%，RevPASH 12→21；周末晚维持 46。 / 全天平均 RevPASH 从 22 升到 29（+32%），而厨房人力未增加。 / 结论：餐饮收益的关键动作是"拆分时段找洼地"——整体看RevPASH只会看到平均值，拆开才会看到问题在哪一顿。


## 六、容易讲错的地方

- 自学者提示：餐厅和客房的收益管理完全相通——产能易逝、需求波动、客群分层、用栅栏隔开。学会客房，餐饮自然通；反过来也一样。

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- 算例 1：100 个座位，营业 8 小时，当日收入 24,000。 / RevPASH = 24,000 ÷ (100 × 8) = 30 元。 / 若通过限时 90 分钟把翻台从 2 次提到 2.5 次，收入可升到 30,000 → RevPASH 37.5。 / 注意：限时不能太狠，否则降低客单价与体验（会反噬评分）。 / / 算例 2（闲时）：周一至周三晚餐上座率仅 35%。推出工作日双人套餐（原价 400，套餐 288，限周一至周三）。 / 上座率升到 65%，RevPASH 从 18 升到 29，且带动酒水消费。
- 快翻台收入更高，但客单下降 20%，且可能影响体验与评分（第 24 章）。 / 折中做法：通过限时 90 分钟 + 优化出餐速度提升翻台，而不靠压缩客单。 / 结论：翻台要以"不损伤客单与体验"为前提，否则评分下降的损失会超过翻台收益。
- 用法：每天算一次 RevPASH，并按"时段"拆分（午/晚、周中/周末）——拆开后你会发现，亏损往往集中在某几个时段。填表示例 · 周一晚餐怎么办场景：周一晚餐上座率仅 32%，RevPASH 12 核心指标RevPASH 12（周末 46）→ 差距明显 闲时促销推"周一至周三双人套餐"288（原价 400）✓ 有栅栏吗？限周一至周三、限 17:30 前入座 → ✓ 会侵蚀周末吗？周末不可用 → 不会 ✓ 成本真实吗？已与厨房核算套餐成本 → ✓ 预约配额每日限量 30 份 → ✓ 是否赶翻台不设时限（避免伤体验）✓ 预期上座率 32%→55%，RevPASH 12→20（客单降但总量升） 结
- 练习 120 座，营业 6 小时，收入 18,000，求 RevPASH。 为什么餐饮不能用"上座率"当核心指标？ 设计一个闲时促销（写出栅栏条件）。 为什么"限时用餐"要谨慎？ 菜单工程要分析哪两个维度？ 本章小结（5 条，可复述） 产能＝座位 × 时间；比客房更易逝（一小时卖不掉即归零）。 RevPASH＝收入 ÷(座位数 × 营业小时)；对应客房的 RevPAR。 核心动作是拆时段——整体平均值会掩盖洼地。 闲时促销必须带栅栏（限时段、限份数），否则侵蚀高峰。 菜单工程看"贡献额 × 受欢迎度"，销量高不等于利润高。
