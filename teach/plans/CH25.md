## 一、学完这一章，学生能做到什么

- 读完能说清：收益管理在酒店里是谁的活、怎么协作、为什么多数酒店没落地。
- 收益管理是跨部门职能：需要前厅（房态）、销售（协议/团队）、市场（渠道）、财务（成本）配合，任何一个环节不配合都会失效。
- 关键是授权：收益岗必须有价格与可得性的决策权（至少是最终否决权），否则形同虚设。
- 例会是协作的载体：每周一次收益例会（45 分钟），把各部门拉到同一张表前（第 19 章）。

## 三、讲这一章要用的公式与定义

- **核心机制**：收益例会 45 分钟议程： 看数 10′ → 找缺口 10′ → 定动作 15′ → 分责任 5′ → 记结论 5′
- **算例 · 授权的三种模式对比**：模式甲：收益岗只做报表，定价由销售定 → 结果：价格体系混乱，ADR 停滞 模式乙：收益岗有建议权，销售可随时否决 → 结果：形同虚设，等同于甲 模式丙：收益岗有决定权，销售可书面申诉（申诉期间执行原决定） → 结果：ADR 提升，且销售业绩未受影响

## 四、讲这一章要用的判定表

### 本章判定表 · 收益职能是否真落地（六项）

| 判据 | 结论 |
|---|---|
| 是否有决策权 | 能对价格/可得性做最终决定 → 落地；只能建议 → 虚设 |
| 是否有例会 | 每周固定一次 → 有；临时开会 → 无 |
| 是否有考核 | 考核 RevPAR/RGI，而非仅出租率（第 2 章） |
| 各部门是否同表 | 所有人看同一张预测表 → 口径一致 |
| 是否有留痕 | 每次调价记录"改了什么、为什么、谁批" |
| 常见失效 | 销售现场放价绕过收益岗——最常见的漏洞 |
| 是否有高层支持 | 总经理是否参加例会、是否为收益岗背书 → 决定成败 |

### 场景：你刚接手一家酒店的收益管理

| 判据 | 结论 |
|---|---|
| 我有决策权吗？ | 能直接开关价档吗？不能 → 先解决授权，别谈方法 |
| 有例会吗？ | 过去 8 周开了几次？&lt;6 次 → 先建立例会 |
| 考核什么？ | 若只考核出租率 → 先推动改为 RevPAR/RGI |
| 口径统一吗？ | 与财务的可售房口径一致吗？不一致 → 先统一 |
| 有留痕吗？ | 能查到上月的调价记录与原因吗？ |
| 总经理支持吗？ | 是否参加例会、是否为收益岗背书？这决定成败 |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| 设了收益岗但没效果 | 先查有无决策权；只能建议 = 虚设 |
| 销售绕过收益岗放价 | 这是第一大漏洞 → 收权限 + 改考核 + 开申诉通道 |
| 要给收益岗授权但销售反弹 | 三件事同时改：决策权 + 考核改贡献 + 申诉通道 |
| 例会没人认真参加 | 请总经理每月参加一次——跨部门责任才落得下去 |
| 刚接手新酒店 | 前三个月先补六项基础，不要急着调价 |


## 五、课堂案例（直接用正文里的）

### 案例 · 一次授权改变结果

A 店收益经理只有建议权；B 店收益经理有价格与可得性最终决定权（销售可申诉，但需书面）。 一年后：A 店价格体系混乱（销售为拿单现场放价），ADR 停滞；B 店 ADR 提升 9%，且销售团队仍完成了业绩（因为降价需走流程，反而逼他们去谈客户价值）。 / 结论：收益管理要落地，先解决"谁说了算"。这不是权力之争，是流程之争。

### 案例三 · 总经理参加例会的差别

A 店例会只有收益岗与销售参加，总经理从不出现；B 店总经理每月参加一次。 差别体现在跨部门动作上：A 店的"销售拜访协议客户""市场增加曝光"这类动作经常落空（无人推动）；B 店则能落实，因为总经理在场时责任当场分派。 / 结论：收益管理需要高层背书，不是因为权力，而是因为它天生是跨部门的——没有高层在场，跨部门责任就落不了地。

### 案例四 · 一次授权改革（含对话）

总经理与两位总监的对话： / 总经理："从下月起，价格与可得性的决定权归收益岗。销售可以书面申诉。" / 销售总监："如果我认为客户很重要呢？" / 总经理："那就申诉。但申诉期间先执行收益岗的决定——我们不能让客户等。" / 销售总监："那我的业绩怎么办？" / 总经理："你的业绩指标从'间夜'改成'贡献'。这样你不会为了凑数去压价。" / 收益经理："我会把每个决定都写清楚依据，接受申诉。" 一年后：ADR 提升 9%；销售业绩指标改为贡献后，他们反而开始主动谈高价值客户；共申诉 14 次，其中 5 次被采纳（收益岗确实有判断失误）。 / 结论：授权改革能成功，靠的不是"谁更大"，而是三件事同时变——决策权、考核指标、申诉通道。只改第一个，一定失败。


## 六、容易讲错的地方

- 自学者提示：如果你入职后发现收益岗没有决策权，不要先抱怨——先做出一张别处看不到的数据表（如渠道净价表、置换分析表），用信息优势换话语权。这是最现实的路径。

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- 算例（例会产出）： / 看数：未来 14 天中有 3 天在手低于目标 20% / 找缺口：这 3 天是周三至周五，非展会日，属量差 / 定动作：开放会员专享价 + 给 OTA 临时配额 + 销售定向拜访 3 家协议客户 / 分责任：市场今日出价、销售本周拜访、收益周五复查 / 记结论：写入纪要，下次例会首项复查 / 注意产出必须是"动作 + 责任人"，不是"方向 + 讨论"。
- 只有丙模式真正有效。 / 关键在"申诉期间执行原决定"——它保证了决策的即时性，又保留了纠偏通道。 / 结论：授权的核心不是"谁更大"，而是"决策要有唯一出口"。
- 用法：入职或接手时先做这六项自查。若"决策权"一项不满足，先不要谈方法——先解决授权。填表示例 · 接手时先查这六项场景：你刚接手一家酒店的收益管理 我有决策权吗？能直接开关价档吗？不能 → 先解决授权，别谈方法 有例会吗？过去 8 周开了几次？&lt;6 次 → 先建立例会 考核什么？若只考核出租率 → 先推动改为 RevPAR/RGI 口径统一吗？与财务的可售房口径一致吗？不一致 → 先统一 有留痕吗？能查到上月的调价记录与原因吗？ 总经理支持吗？是否参加例会、是否为收益岗背书？这决定成败 结论：前三个月不要急着调价，先把这六项补齐。 / 在错误的组织基础上做正确的方法，结果仍然是零。
- 练习 收益岗只有建议权会有什么后果？ 为什么考核要用 RGI 而不是出租率？ 设计一次 45 分钟收益例会的议程与产出。 六项自查中，你认为哪一项最关键？为什么？ 若销售坚持给某客户降价，收益岗应如何处理？ 本章小结（5 条，可复述） 收益管理是跨部门职能：前厅、销售、市场、财务缺一不可。 授权是核心：收益岗必须有价格/可得性的决定权，只能建议等于虚设。 三件事同时改：决策权 ＋ 考核指标（改贡献，非间夜）＋ 申诉通道。 例会 45 分钟是协作载体，产出必须是动作 + 责任人。 总经理背书决定成败——因为跨部门责任需要高层在场才落得下去。
