## 一、学完这一章，学生能做到什么

- 读完能说清：为什么同样一间房，昨天卖 300、今天卖 800 都不是乱来——并记住那条贯穿全书的判据。
- 库存易逝：房晚不可储存。
- 今晚卖不掉，这间的价值永久归零——不像衣服能囤到明年卖，也不像产能可以补产。
- 这是收益管理存在的第一前提。
- 成本结构极端：酒店固定成本极高（房租、人工、折旧、能耗），而多卖一间的变动成本极低（洗涤、易耗品，几十元）。
- 这意味着在成本之上多卖的任何一间，几乎都是净利润——但也意味着，把一间本可卖 680 的房以 320 卖掉，损失的是 360 的纯利。
- 客人出价不同：商务客临时出差、时间紧、公司买单，愿意付 680；游客提前一个月规划、自掏腰包，只愿付 320。
- 同样的房，在不同人眼里值不同的钱。
- 所以问题从来不是"定多少钱"，而是"把房留给哪一类人"。

## 三、讲这一章要用的公式与定义

- **核心定义**：收益管理 = 在正确的时间，以正确的价格， 把有限的易逝库存，卖给愿意付最高价的客源
- **算例 3 · 一次"留住"的价值**：剩 10 间房，离入住还有 5 天 方案甲：全部按 400 卖掉 → 收入 4,000 方案乙：关掉 400 档，只留 650 档 → 预计卖出 6 间 → 收入 3,900 剩 4 间空置（损失 1,600） 最终比较：甲 4,000 乙 3,900

## 四、讲这一章要用的判定表

### 本章判定表 · 什么生意需要收益管理（逐项勾选，全中才适用）

| 判据 | 结论 |
|---|---|
| 产能是否易逝？ | 过期作废（房晚/机位/场次/车位）→ 需要；可储存 → 不需要 |
| 产能是否短期固定？ | 短期无法增加（房间数固定）→ 需要；可随时扩产 → 不需要 |
| 需求是否波动？ | 有明显淡旺/时段差异 → 需要；全年平稳 → 不需要 |
| 客群能否分层？ | 不同客群支付意愿不同 → 需要；所有人出价一样 → 不需要 |
| 能否提前预订？ | 可提前预订 → 可做预测与控制；只能现场买 → 只能现场定价 |
| 成本结构如何？ | 固定成本占比高、边际成本低 → 填满空房价值大 |
| 是否有历史数据？ | 有可分析的历史 → 可预测；无 → 只能凭经验 |
| 能否拒绝生意？ | 可以拒绝低价客（如设限制）→ 可做；必须来者不拒 → 难做 |

### 场景：一家新开的共享自习室，问要不要做收益管理

| 判据 | 结论 |
|---|---|
| 产能是否易逝？ | 是——一个晚上的座位卖不掉即归零 ✓ |
| 产能是否固定？ | 是——短期内无法增加座位 ✓ |
| 需求是否波动？ | 是——工作日晚上与考试季爆满，白天很空 ✓ |
| 客群能否分层？ | 是——有月卡学员、次卡用户、临时客 ✓ |
| 能否提前预订？ | 是——可线上预约选座 ✓ |
| 成本结构？ | 固定成本为主（房租），边际成本低 ✓ |
| 有无历史数据？ | 新店暂无，需先积累 2–3 个月 △ |
| 能否拒绝生意？ | 可设"高峰时段不接次卡" ✓ |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| 客人问"今晚还有房吗、多少钱" | 先查在手/去年同期/pickup三个数，再报价——不要凭"剩几间"定价 |
| 剩房不多，想卖贵一点 | 先关低价档（可得性），再考虑提价；不要一步涨到位 |
| 淡季空房很多 | 做带栅栏的促销（提前订/不可退/会员），不裸降价 |
| 销售要接一个大团 | 先算置换：团收入 ≥ 被挤散客的期望收益才接（第 15 章） |
| 老板问"为什么这月收入降了" | 不要只看自己 → 看RGI与竞品（第 3 章） |


## 五、课堂案例（直接用正文里的）

### 案例一 · 两家同样 100 间房的酒店

A 店全年平均出租率 70%、平均房价 400 元。B 店出租率 65%、平均房价 460 元。 / 哪家经营得更好？ A：100 × 70% × 400 = 28,000 元/天。B：100 × 65% × 460 = 29,900 元/天。 / B 店出租率低 5 个百分点，收入反而更高。 / 第一课：不要只看住满没住满，要看卖出了多少钱。

### 案例二 · 一次"填满房"的代价

某店为把出租率从 78% 冲到 90%，把 60 间房以 199 元投给低价渠道（正常价 450）。 多卖的 12 间确实带来了 2,388 元收入；但同期有 8 位愿意付 450 的散客因为没房而流失，损失 3,600 元。 / 净效果：−1,212 元。出租率上去了，钱少了。 / 这就是"填满房"的陷阱——填满不值得填的房，是负资产。

### 案例三 · 把"感觉"变成"数字"

某店店长凭经验判断"下周肯定淡"，准备降价促销。收益专员查了三件事：① 下周有本地马拉松（历史同期出租率高 22%）；② 当前在手已比去年同期高 15%；③ 竞品已悄悄提价 8%。 三条证据全部指向"下周不但不淡，反而紧俏"。该店改为小幅提价 + 设 MinLOS=2。 / 结果：当周 RevPAR 比去年同期高 19%，而如果按店长的直觉降价，将损失约 12% 的收入。 / 结论：收益管理不是取代经验，是给经验装上仪表盘。经验告诉你"可能"，数据告诉你"多少"。


## 六、容易讲错的地方

- 自学者提示：找一家你熟悉的酒店，查它周一和周六的价格。如果不同，说明它在做收益管理。然后试着回答：为什么周一便宜？答案通常是"商务客周末不来，而周末有游客"——这就是客群分层的直觉起点。 / 再进一步：查它提前 30 天和提前 1 天的价格，如果不同，说明它在按"时间"管理。这两组价格，就藏着整门学科。
