# 第 3 章 · 竞争三件套：MPI、ARI、RGI 教案

> 教材定位：第一篇 · 认知篇 ｜ 本质与衡量 ｜ 第 3 章 ｜ 建议课时：2 课时（每课时 90 分钟）｜ 配套正文：教材第 3 章
> 配套资源：教师用书同章（`textbook-teacher.html#tch03`）｜ 学员自学页：`learn.html#ch03`

## 一、学完这一章，学生能做到什么

- 读完能判断：你不是在为难自己，你是在跟市场比赛。
- MPI（市场渗透指数）＝你的 OCC ÷ 竞争群 OCC。
- &gt;100 说明你抢到的量比市场平均多。
- 它回答：我分到的蛋糕比别人大吗？ ARI（平均房价指数）＝你的 ADR ÷ 竞争群 ADR。
- &gt;100 说明你卖得比市场贵。
- 它回答：我卖的单价站得住吗？ RGI（收入产生指数）＝你的 RevPAR ÷ 竞争群 RevPAR ≈ MPI × ARI。
- 这是终极成绩单——它同时反映了量与价，是评价收益管理成败的第一指标。

## 三、讲这一章要用的公式与定义

- **核心公式**：MPI = 你的出租率 ÷ 竞争群出租率 ARI = 你的平均房价 ÷ 竞争群平均房价 RGI = 你的 RevPAR ÷ 竞争群 RevPAR ≈ MPI × ARI
- **算例 3 · 一次完整的归因**：你的 OCC 62%、市场 78% → MPI = 79.5 你的 ADR 520、市场 480 → ARI = 108.3 RGI ≈ 79.5% × 108.3% = 86

## 四、讲这一章要用的判定表

### 本章判定表 · RGI 不达标时的归因与动作

| 判据 | 结论 |
|---|---|
| RGI&lt;100 且 MPI↓ | 量不够 → 动渠道、促销、团队、开放低价档填量 |
| RGI&lt;100 且 ARI↓ | 价不够 → 动价档、加限制条件（MinLOS）、关低价档 |
| MPI&gt;100 但 ARI&lt;100 | 靠低价换量 → 警惕：量有了但钱没赚到，需提价 |
| MPI&lt;100 但 ARI&gt;100 | 守价但缺量 → 补渠道与曝光，不要降价 |
| MPI&lt;100 且 ARI&lt;100 | 全面落后 → 先看产品与口碑（第 24 章），再谈定价 |
| 前提动作 | 竞争群要选对（同档次、同区位 3–5 家），否则三个指数全是假的 |
| 观察频率 | 每月看 RGI；每周看竞品价格变动（不每周算指数） |

### 场景：某月 RGI = 92，老板问"怎么办"

| 判据 | 结论 |
|---|---|
| 先看 RGI | 92 &lt; 100 → 落后市场，需要动作 ✓ |
| 拆 MPI | MPI = 88 → 量不够（低于市场 12%）✓ |
| 拆 ARI | ARI = 105 → 价有优势，不是价的问题 ✓ |
| 定性 | 量差 → 动渠道、促销、团队、开放低价档 ✓ |
| 排除项 | 不动价——降价会削弱 ARI，让 RGI 更差 ✗ |
| 复查周期 | 动作执行 4 周后再看 RGI 是否改善 ✓ |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| RevPAR 涨了，老板很高兴 | 先别高兴——查市场涨了多少；跑输市场就是退步 |
| RGI &lt; 100 | 拆 MPI / ARI：MPI↓ 补量，ARI↓ 提价；不要直接降价 |
| MPI 高、ARI 低 | 靠低价换量 → 该提价，不是继续促销 |
| 市场普跌 | 目标改为"跌得比竞品少"；RGI 才是成绩单 |
| 指数长期异常低 | 先怀疑竞争群选错（第 3 章案例二），不是自己做得差 |


## 五、课堂案例（直接用正文里的）

### 案例一 · 淡季里的赢家

市场整体 RevPAR 从 400 跌到 300（−25%）。你的店从 380 跌到 310（−18%）。 你的 RevPAR 也跌了，但 RGI 从 95 升到 103——你在淡季跑赢了市场。 / 结论：RGI 低于 100 才需要紧张；市场普跌时跌得比竞品少，就是赢。

### 案例二 · 竞争群选错的后果

某店把自己与 5 家高档酒店对比，长期 RGI 只有 80，团队士气低落，年年降价。 后来重新划定竞争群（改为同档次、同商圈的 4 家），RGI 实为 108。 / 之前的连年降价，是在一个错误的分母下做出的错误决策。 / 结论：竞争群是分母。分母错了，后面所有动作都错。

### 案例三 · 换群之后，决策全变了

某店原与 5 家豪华酒店同群，RGI 长期 78，团队年年降价。重新划群后（改同档次同商圈 4 家），RGI 实为 107。 更关键的是：之前的降价决策，是在一个错误的分母下做出的。这意味着过去两年所有的价格调整方向都错了——不该降的时候降了。 / 结论：竞争群是分母。分母错了，所有相对判断都错，且错得很隐蔽——因为数字看起来"很客观"。


## 六、容易讲错的地方

- 自学者提示：没有竞品数据怎么办？用手工的办法——每天记录 3–5 家同档次酒店在 OTA 上的公开价与房态，坚持两周，你就有了自己的 baseline。这是所有收益经理的入门功课。

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- 算例 1（归因）：你 OCC 70%、市场 80% → MPI = 87.5（量不够）。 / 你 ADR 500、市场 450 → ARI = 111（价不错）。 / RGI ≈ 87.5% × 111% = 97（略低于市场）。 / 诊断：不是价的问题，是量的问题——该补渠道和客流，而不是降价。 / / 算例 2（陷阱）：你 MPI = 110（量很好）、ARI = 85（价很低）→ RGI ≈ 93.5。 / 诊断：靠低价换来了量，但整体仍落后于市场。这种情况下再加促销只会更糟。
- 诊断：价有优势（108），但量严重不足（79.5）→ RGI 86。 / 正确动作：不动价格，去补量——加渠道曝光、做会员拉新、定向拜访协议客户、淡季做有栅栏的促销。 / 错误动作：降价。因为降价只会让 ARI 从 108 掉下来，RGI 可能更低，还白白损失收入。 / 这就是"先拆解再动手"的价值——它能防止你用最贵的方式解决一个不是问题的问题。
- 用法：月报第一件事就是拆 RGI。先用 MPI ↓ 还是 ARI ↓ 定性，再决定动"量"还是动"价"。绝不跳过这一步直接调价。填表示例 · 月报第一件事：拆 RGI场景：某月 RGI = 92，老板问"怎么办" 先看 RGI92 &lt; 100 → 落后市场，需要动作 ✓ 拆 MPIMPI = 88 → 量不够（低于市场 12%）✓ 拆 ARIARI = 105 → 价有优势，不是价的问题 ✓ 定性量差 → 动渠道、促销、团队、开放低价档 ✓ 排除项不动价——降价会削弱 ARI，让 RGI 更差 ✗ 复查周期动作执行 4 周后再看 RGI 是否改善 ✓ 结论：RGI 92 的正确解法是补量
- 练习 你的 OCC 65%、市场 75%；ADR 480、市场 400。求 MPI、ARI、RGI 并给出诊断。 RGI 105 但 MPI 只有 90，说明什么？该动什么？ 为什么竞争群选错会让三个指数全部失真？ 市场 RevPAR 跌 20%，你跌 15%，你的 RGI 是升是降？ 若 MPI 110、ARI 85，应优先补量还是提价？ 本章小结（5 条，可复述） 三个指数：MPI（量）、ARI（价）、RGI（结果），都以竞争群为分母。 RGI 是终极成绩单：&gt;100 跑赢市场，&lt;100 落后。 归因公式：RGI ≈ MPI × ARI —— MPI↓ 补量，ARI↓ 提价。
