# 第 4 章 · 价格弹性：降多少价能换多少量 教案

> 教材定位：第一篇 · 认知篇 ｜ 本质与衡量 ｜ 第 4 章 ｜ 建议课时：2 课时（每课时 90 分钟）｜ 配套正文：教材第 4 章
> 配套资源：教师用书同章（`textbook-teacher.html#tch04`）｜ 学员自学页：`learn.html#ch04`

## 一、学完这一章，学生能做到什么

- 读完能预判：降价之前，先算这一步划不划算。
- 弹性衡量"价格改动能换来多少量"。
- 弹性 &gt;1 表示需求敏感（降价很有效），&lt;1 表示迟钝（降价没用）。
- 需求越紧急越不敏感：商务客临时出差，价格弹性低（涨点价他也得来）；游客提前三个月规划，弹性高（便宜就去，贵就换一家）。
- 没有条件限制的降价，会让原本肯付全价的人也来占便宜——这叫 buy-down（客群下移），是降价最大的隐性成本。

## 三、讲这一章要用的公式与定义

- **核心公式**：价格弹性 E = 需求量变动% ÷ 价格变动% 收入变动 ≈ (1 + 量变动%) × (1 + 价变动%) − 1 临界条件：量变动% &gt; 1/(1 − 降价幅度) − 1
- **算例 4 · 一次带 buy-down 的完整核算**：房价 600，打八折 → 480，每间让利 120 活动带来 150 间夜，其中 60 间本会全价购买 收入变化 = (150-60)×480 + 60×480 - 150×600(原全价假设) 简化：新增 90 间 × 480 = 43,200 损失 60 间 × 120 = 7,200 净效果 = 43,200 − 7,200 = +36,000

## 四、讲这一章要用的判定表

### 本章判定表 · 该不该降这一档价（逐项勾选）

| 判据 | 结论 |
|---|---|
| 降价后量能涨多少？ | 涨幅 &gt; 临界值（见上方速查）→ 划算；否则不划算 |
| 会不会挤走高价客？ | 有栅栏（提前订/不可退/会员/资质）→ 可降；无栅栏 → 先加栅栏再降 |
| 离入住日还有多久？ | 还早 → 有时间等高价客，慎降；临近 → 该降就降（空房归零） |
| 是否低于变动成本？ | 是 → 绝对不降（第 26 章） |
| 竞品会跟吗？ | 会跟 → 降价无意义，只会一起亏；不跟 → 才有效 |
| 能否用"加价值"替代？ | 赠早餐/升级/积分的成本通常低于降价 → 优先加价值 |
| 降了还能涨回来吗？ | 不能 → 这是永久降价，需慎重（第 6 章） |

### 场景：竞品降到 350，销售要求跟降到 350（你现价 500）

| 判据 | 结论 |
|---|---|
| 降幅多少？ | 500→350 = 降 30% → 量需涨 42.9% 才回本 |
| 量能涨这么多吗？ | 历史同类情况最多涨 20% → 不能 ✗ |
| 有栅栏吗？ | 销售提议是"对所有客人" → 无栅栏 ✗ |
| 低于变动成本？ | 变动成本 120，350 &gt; 120 → 未破底线 ✓ |
| 竞品是长期降吗？ | 新开业爬坡，预计 3–6 个月 → 不是长期 ✗ |
| 能否加价值替代？ | 可加早餐(成本30)+升级券(20) → 优先用这个 ✓ |
| 降了能涨回吗？ | 客人在平台已形成低价预期 → 难 ✗ |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| 有人提"降到 299" | 先问量能涨多少，再对照临界表（降 30% 需涨 42.9%） |
| 要做淡季促销 | 必须配栅栏（提前期/不可退/会员），否则等于永久降价 |
| 老客户也开始用折扣 | 说明buy-down发生了 → 立即加严栅栏 |
| 不知道需求敏不敏感 | 小范围测试（限量限时）测出弹性，不要猜 |
| 竞品降价了 | 走第 6 章流程：先看原因与 MPI，不急着跟 |


## 五、课堂案例（直接用正文里的）

### 案例一 · 一次失败的"全员降价"

某店淡季将 BAR 从 600 降到 399（−33.5%），出租率从 45% 升到 62%（+37.8%）。 收入变动 = 1.378 × 0.665 − 1 = −8.4%。 / 更糟的是：老客户发现后也开始按 399 订，原本 600 的收入永久性流失。 / 正确做法：降价必须配栅栏——"提前 7 天订、不可取消、仅限会员"，让只有价格敏感的人才拿得到。

### 案例二 · 加价值替代降价格

竞品降价到 350，你维持 500 但客人在流失。若跟降 30%，量需涨 43% 才回本——显然做不到。 替代方案：维持 500，加赠早餐（成本 30）+ 升级券（成本 20）+ 延迟退房（成本约 0）。 / 客人感知价值增加约 150，而你只多花 50——相当于"隐性降价 10%"而非 30%。 / 结论：加价值比降价格便宜，且不伤价格体系。

### 案例三 · 一条栅栏挽回的 ADR

某店"提前预订 8 折"活动因无任何附加条件，老客户纷纷改用，ADR 下滑 11%。 加上"提前 21 天 + 不可取消 + 仅限官网会员"三条栅栏后，折扣使用量下降 35%，ADR 回升 8%。 / 关键洞察：使用量下降不是坏事——它说明这部分人本来就会买。筛掉他们，留下的才是真正被激励出来的增量。 / 结论：栅栏的价值不在于"限制谁"，而在于"让折扣只作用于增量"。


## 六、容易讲错的地方

- 自学者提示：把这张速查表抄下来贴着：降 10% 要涨 11% 量；降 20% 要涨 25% 量；降 30% 要涨 43% 量；降 50% 要涨一倍量。 / 下次有人提"降到 299"时，你就能当场问出那句最关键的话："量能涨多少？"

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- 算例 1：价降 20%（−20%），量升 25%（+25%）。 / 收入变动 = 1.25 × 0.80 − 1 = 0% —— 白忙一场。 / 若量只升 15%：1.15 × 0.80 − 1 = −8%（亏）。 / 若量升 40%：1.40 × 0.80 − 1 = +12%（赚）。 / / 算例 2（临界速查）： / 降 10% → 量需涨 11.1% 降 20% → 量需涨 25% 降 30% → 量需涨 42.9% 降 50% → 量需涨 100%。 / 降价幅度越大，回本越难——这是最常用的速判表。
- 若加栅栏后，60 间中有一半（30 间）不再享受折扣： / 损失降为 30 × 120 = 3,600 → 净效果 = 43,200 + 30×120 − 3,600 = +43,200。 / 栅栏让同一场促销多赚 7,200 元，而它几乎不花成本。
- 用法：任何降价提议，先答这七项。第 2、3、4 项任一不满足，就不该降。填表示例 · 销售提出"降到 350"该不该答应场景：竞品降到 350，销售要求跟降到 350（你现价 500） 降幅多少？500→350 = 降 30% → 量需涨 42.9% 才回本 量能涨这么多吗？历史同类情况最多涨 20% → 不能 ✗ 有栅栏吗？销售提议是"对所有客人" → 无栅栏 ✗ 低于变动成本？变动成本 120，350 &gt; 120 → 未破底线 ✓ 竞品是长期降吗？新开业爬坡，预计 3–6 个月 → 不是长期 ✗ 能否加价值替代？可加早餐(成本30)+升级券(20) → 优先用这个 ✓ 降了能涨回吗？
- 练习 降价 15%，量需涨多少才能保住收入？ 价从 500 降到 400，量从 100 间升到 130 间，收入是升是降？ 为什么"提前订不可退"能防止高价客下移？ 竞品降价 25%，你若跟降，量需涨多少才回本？ 举三个"加价值替代降价格"的具体做法。 本章小结（5 条，可复述） 弹性＝需求量变动% ÷ 价格变动%；&gt;1 敏感（降价有效），&lt;1 迟钝（降价无效）。 临界速查：降 10%→量需涨 11.1%；降 20%→25%；降 30%→42.9%；降 50%→100%。 降价幅度越大，回本越难——这是最常用的一条速判。 buy-down 是隐性成本：原本全价购买的客人也享受了折扣
