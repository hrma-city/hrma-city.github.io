# 第 8 章 · 套餐与锚定：让客人觉得划算 教案

> 教材定位：第二篇 · 决策篇 ｜ 模块 A · 定价决策 ｜ 第 8 章 ｜ 建议课时：2 课时（每课时 90 分钟）｜ 配套正文：教材第 8 章
> 配套资源：教师用书同章（`textbook-teacher.html#tch08`）｜ 学员自学页：`learn.html#ch08`

## 一、学完这一章，学生能做到什么

- 读完能设计：不降房价，却让客人觉得更值的产品。
- 锚定效应：客人判断"贵不贵"靠对比。
- 先展示高价选项，中价就显得合理——这是预订页面排序的基本原理。
- 套餐的价值：把低感知成本、高感知价值的项（早餐、延迟退房、升级）打包进去，用感知价值换支付意愿。
- 套餐不等于降价：套餐价必须高于纯房价，否则会侵蚀 BAR，变成变相降价。

## 三、讲这一章要用的公式与定义

- **核心公式**：套餐价 = 房价 + 附加项成本 × (1 + 溢价率) 客人感知价值 = 附加项的「市场价」之和（不是你的成本） 利润空间 = 套餐价 − 房价 − 附加项成本
- **算例 3 · 一个套餐的完整核算**：纯房价 600 附加：双早(成本60/市价176) + 下午茶(成本50/市价128) + 16点退房(成本0/感知100) 客人感知价值 = 600 + 176 + 128 + 100 = 1,004 套餐定价 850 → 客人觉得省 154 你多收 250、多花成本 110 → 净赚 140

## 四、讲这一章要用的判定表

### 本章判定表 · 套餐设计是否合格

| 判据 | 结论 |
|---|---|
| 与 BAR 的关系 | 套餐价 必须高于纯房 BAR，否则是变相降价（硬门槛） |
| 附加项选择 | 选低成本高感知的：早餐、延迟退房、升级、积分 |
| 是否有锚定项 | 页面应展示更高价选项（套房/含更多权益）作为锚 |
| 是否可拆分 | 客人若能拆出裸房价并发现更便宜 → 设计失败 |
| 是否限量/限时 | 套餐应有期限或限量，避免变成常态价 |
| 成本是否真实核算 | 早餐、下午茶的实际成本要问餐饮部，不能拍脑袋 |
| 与竞品对比 | 套餐内容应与竞品有差异，避免陷入同质比价 |

### 场景：设计"暑期亲子套餐"1,080（含房+双早+儿童乐园+延迟退房）

| 判据 | 结论 |
|---|---|
| 与 BAR 的关系 | 纯房 BAR 780，套餐 1,080 &gt; 780 → ✓ |
| 附加项是否低成本高感知？ | 乐园(成本40/市价160)、早餐(60/176)、退房(0/100) → ✓ |
| 有锚定项吗？ | 页面同时展示"亲子套房 1,580"作为高价锚 → ✓ |
| 可拆分吗？ | 拆开：房780+早176+园160+退房100=1,216 &gt; 1,080 → 客人拆开更贵 → ✓ |
| 限量/限时？ | 限暑期、每日 15 份 → ✓ |
| 成本真实核算？ | 已与餐饮/乐园部门确认成本 → ✓ |
| 与竞品差异？ | 竞品无儿童乐园，差异化明显 → ✓ |

### 遇到下面这些情况，直接按"动作"做

| 判据 | 结论 |
|---|---|
| 客人说"你们太贵了" | 不要降价——加价值（含早/下午茶/延迟退房）并推套餐 |
| 设计完一个套餐 | 第一件事：拆开算一遍，确认拆开比套餐贵 |
| 套餐卖得很好但 ADR 掉了 | 检查是否套餐价低于纯房 BAR → 提价或拆算校验 |
| 不知道加什么进套餐 | 选低成本高感知项：延迟退房(0)、升级(20)、早餐(60) |
| 要在页面放几个房型 | 把最贵的放前面作锚（锚定效应） |


## 五、课堂案例（直接用正文里的）

### 案例一 · 一个套餐救活淡季周末

某店周末纯房卖 450 鲜有问津。推出"周末微度假套餐"680（含双早 + 双人下午茶 + 16 点退房）。 附加成本约 70，净收 610（比原来 450 多 160）。 / 客人感知价值 700+，觉得划算；酒店多赚；且纯房价 450 的体系完好无损。 / 结论：套餐是"加价值"，不是"降价格"——这是它比打折高明的地方。

### 案例二 · 页面排序的威力

某店预订页原本按价格从低到高排序，客人多数选最便宜的房型。 改为把"行政房 + 套餐"放在首位（作为锚），纯房放第二位。 / 结果：选择中高价选项的客人比例从 22% 升到 41%，ADR 提升 9%，而总订单量几乎没变。 / 结论：客人不是只买便宜的，是在可见范围里选"看起来最值"的。你展示什么，决定了他们选什么。

### 案例三 · 拆开算就露馅的套餐

某店推"住宿+双早"套餐 680，而纯房 BAR 600、早餐市价 176。 客人一算：600 + 176 = 776 &gt; 680 → 套餐确实便宜，于是大量客人通过套餐"变相"拿到了低于 BAR 的房价。 / 结果：ADR 从 600 掉到约 570，价格体系被自己设计的套餐侵蚀。 / 修正：套餐价调整为 720（高于拆算价的 93 折以内仍算合理），或改为"加价值但价格不低于拆算值"。 / 结论：设计完套餐，第一件事就是"拆开算一遍"。这是最容易出错、也最容易自查的一步。


## 六、容易讲错的地方

- 自学者提示：设计套餐时，把每一项按"客人眼中的市价"列出来，而不是按你的成本。感知价值与成本之间的差额，就是你要的利润空间。 / 晚餐自助标价 198、成本 60——这就是典型的"高感知、低成本"项，优先打包。

## 七、作业与测评

本章教材练习（答案在教材附录 B）：
- 算例：房价 600。早餐成本 30、市价 88；下午茶成本 25、市价 128；延迟退房成本约 0、感知价值 100。 / 客人感知总价值 ≈ 600 + 88 + 128 + 100 = 916。 / 套餐定价 780 → 客人觉得"省了 136"，你多收 180、多花成本 55，净赚 125。 / 关键：定价锚定的是"客人眼中的市价"，不是你的成本。
- 若改为直接降价：房价降到 550 才能产生类似的吸引力 → 收入直接少 50/间，且 BAR 被下移。 / 结论：套餐比降价多赚约 190/间，且不伤价格体系。这就是它值得优先使用的原因。
- 用法：设计完套餐，先问"拆开算是否比纯房便宜"。若是，重做。套餐的第一原则是保护价格体系。填表示例 · 这个套餐设计合格吗场景：设计"暑期亲子套餐"1,080（含房+双早+儿童乐园+延迟退房） 与 BAR 的关系纯房 BAR 780，套餐 1,080 &gt; 780 → ✓ 附加项是否低成本高感知？乐园(成本40/市价160)、早餐(60/176)、退房(0/100) → ✓ 有锚定项吗？页面同时展示"亲子套房 1,580"作为高价锚 → ✓ 可拆分吗？拆开：房780+早176+园160+退房100=1,216 &gt; 1,080 → 客人拆开更贵 → ✓ 限量/限时？限暑期、每日 15 
- 练习 房价 500，加早餐（成本 30/市价 88）与延迟退房（成本 0/感知 100），设计一个套餐价。 为什么套餐价必须高于纯房 BAR？ 什么是锚定效应？在预订页面如何应用？ 某套餐售价 720、房价 600、附加成本 60，利润空间多少？ 为什么套餐不能做成常态？ 本章小结（5 条，可复述） 锚定效应：客人靠对比判断贵贱——页面顺序影响选择。 低成本高感知项优先：延迟退房（成本 0）、升级（20）、早餐（60）。 定价锚是"客人眼中的市价"，不是你的成本——差额就是利润空间。 硬门槛：套餐价必须高于纯房 BAR；拆开算必须比套餐贵。 验算口诀：设计完套餐，第一件事就是"拆开算一遍"。
