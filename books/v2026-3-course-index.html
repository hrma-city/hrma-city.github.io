这一版是什么

直接回答「为什么之前看不到正式课程内容」

之前的 v2026-2-curriculum-l123.html 是课程规格说明：能力卡、通过线、章节映射、版本状态。它回答「这门课怎么设计」，不回答「这节课讲什么」。

v2026.3 是正式授课内容本体：41 讲逐讲保留现行教材完整正文（思维导图、案例导入、讲解、算例、折叠答案块），外面套统一授课外壳（目标 / 导入 / 校正版算例 / 练习 / 答案 / 教师提示 / 作业），另配 L1 / L2 / L3 三册逐周开课手册。教师拿这一套就能排课、试讲、批改。

没有再出对照表；旧版教材、旧版课程规格、两份体检报告、v2026.2 实体资产全部保留在线。

引用规则与边界

怎么引用
  1. 讲次引用：「v2026.3 第 N 讲（textbook-merged.html 第 N 章正文，已应用 v2026.2 校正）」。
  2. 引用旧教材写「v1.0 textbook-merged.html」，引用旧题库解析写「v1.0 workbook-index.json」。
  3. 公式一律写「RGI = MPI × ARI ÷ 100（v2026.2）」；答案一律写「判断题分母 288 / OOO 分母 297（v2026.2）」。
  4. 改内容：先备份 → 改真源 → 重跑生成器 → 回归门禁 → 另起版本文件。
仍然需要你拍板的三件事
  1. 市场主体注册（授权收款主体资格）。
  2. 授权合同 / 贡献者协议 / AI 政策交律师与税务师审阅。
  3. 三档授权一口价金额。

另：整本旧教材与旧题库的原文件未回写，错误值只在本版更正；若要把旧站也改过来，需你明确点头并另起版本。
