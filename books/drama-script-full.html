RMCITY · 收益管理教学漫剧

《小棠与阿表》完整剧本

共 36 集，每集按教学标准撰写：分镜 + 对白 + 旁白（未来配音）+ 判定表结论。阿表在本版会翻到具体判定表并给出结论，不再是只卖萌不点破。时长每集约 30–60 秒。

角色　小棠：20 多岁女性收益经理，利落短发、深色西装，凭直觉但肯学。　阿表：金色封面判定表精灵，圆眼睛，会说话；本版负责把方法讲明白。　格式说明　「分镜」给未来视频工具拍；「对白」是角色台词；「旁白」是画外音/配音稿；「判定表结论」是每集交付的一个可记住的方法。
EP01

《今天该涨价吗》

指向 表 A · 每日价格调整 · 约 45 秒
分镜
  1. 清晨，小棠盯着屏幕上的「目标日预测 OCC 82%」出神。
  2. 阿表从屏幕边缘飘出，翻开金色封面，停在第 A 页。
  3. 表 A 上两个输入框亮起：① 目标日预测 OCC；② Pickup 偏差。
  4. 小棠手指在「涨价 / 持平 / 降价」三个按钮上悬停，最终点「涨价」。
  5. 屏幕弹出提示：「已写入调价台账 · 依据表 A」。
对白

小棠：今天房量看着不错，能涨价不？

阿表：先别拍脑袋。翻到表 A，给我两个数——目标日预测 OCC，还有 Pickup 偏差。

小棠：OCC 82%，Pickup 比去年同期多 15%。

阿表：两个输入都往上，表 A 说涨。点「涨价」——记住，写进调价台账，注明依据表 A。

小棠：懂了，涨价不是胆子大，是表让我涨。

旁白（未来配音）

每天开盘第一件事，用表 A 读两个输入，决定涨、平、降。调价不是凭感觉，是查表。

判定表结论

表 A 每日价格调整：输入「预测 OCC + Pickup 偏差」，输出涨 / 平 / 降；每次调价写入调价台账，注明依据表 A。

EP02

《限制条件大乱斗》

指向 表 B · 库存与限制条件 · 约 50 秒
分镜
  1. 小棠面前摊着三张互相打架的限制条件：最短住期、连住、关某房型。
  2. 她翻来翻去下不了决定，眉头越皱越紧。
  3. 阿表飘过来，把表 A 合上，翻开表 B。
  4. 屏幕上「库存动作」一行亮起，三个条件被自动排好优先级。
  5. 小棠松口气，按表 B 顺序点下配置。
对白

小棠：价格用表 A 定了，可这些限制条件谁先谁后？我头都大了。

阿表：价格定了，立刻配库存。表 B 说——库存动作优先级高于价格动作。

小棠：所以最短住期、连住、关房型，不是我想怎么设就怎么设？

阿表：对。输入还是预测 OCC，表 B 给你该开哪些限制。房量安全，永远比多卖 20 块钱重要。

小棠：原来价格管赚多少，库存管别翻车。

旁白（未来配音）

价格定完立刻配库存。库存动作优先级高于价格动作——房量安全永远第一。

判定表结论

表 B 库存与限制条件：输入预测 OCC，输出最短住期 / 连住 / 关房型等限制配置；库存动作优先级高于价格动作。

EP03

《我比别人贵还是便宜》

指向 表 C · 价格指数 ARI · 约 45 秒
分镜
  1. 屏幕并排立着本店与竞品的价格柱，小棠来回比。
  2. 一条金色指数线在柱顶之间滑动，小棠眼神跟着晃。
  3. 阿表翻开表 C，公式浮现：ARI = 本店 ADR ÷ 竞争加权 ADR × 100。
  4. 本店柱旁跳出「ARI ≈ 105」。
  5. 小棠点点头，不再盲目跟价。
对白

小棠：隔壁卖 650，我卖 680，我是不是太贵了？

阿表：别只看一家。翻表 C，算 ARI——本店 ADR 除以竞争组合加权 ADR，再乘 100。

小棠：竞争组合均价 680，我 680……那我 ARI 才 100？

阿表：对，ARI≈100 就是不贵不便宜。你刚才那是拿最低价的一家比，吓自己。

小棠：所以贵不贵，得看一篮子竞品，不是看最便宜那家。

旁白（未来配音）

ARI 回答一个问题：我卖得比隔壁贵还是便宜。大于 100 偏贵，小于 100 偏便宜。

判定表结论

表 C 价格指数 ARI：ARI = 本店 ADR ÷ 竞争组合加权 ADR × 100；结合 MPI 一起看，别被单一低价竞品带偏。

  2. 小棠伸手想比划，被一道新切线打断。
  3. 阿表翻开表 D：MPI = 本店 OCC ÷ 竞争 OCC × 100。
  4. 本店扇区旁跳出「MPI 92」。
  5. 小棠盯着缩小的扇区，若有所思。
对白

阿表：那是份额问题，不是价格问题。翻表 D，算 MPI——本店 OCC 除以竞争组合 OCC，乘 100。

小棠：我 OCC 70，竞品平均 76……MPI 92，我落后了。

阿表：MPI 小于 100，说明该抢的份额被抢走了。这时候该先抢量，不是守价。

判定表结论

表 D 市场渗透指数 MPI：MPI = 本店 OCC ÷ 竞争组合 OCC × 100；MPI 偏低要先抢量，别死守价格。

EP05

《升房加多少钱》

指向 表 F · 房型价差阶梯 · 约 45 秒
分镜
  1. 屏幕浮着房型阶梯价目条：标准 / 高级 / 豪华 / 套房，逐级抬升。
  2. 客人问升房，小棠手指在两级价差间来回比划。
  3. 阿表翻开表 F，以高级房 BAR 为基准 100，其余房型价自动生成。
  4. 升房加价数从阶梯里跳出来。
  5. 小棠照阶梯报价，客人接受。
对白

小棠：客人想从标准间升到豪华，我加 200 还是 300？没谱。

阿表：别拍脑袋。翻表 F——以高级房 BAR 为基准 100，全房型价差一次设好，自动生成。

小棠：高级房 BAR 680 是 100，那豪华间该是 130，升一级就加 30%。

阿表：对。升房加价看价差阶梯，不是看心情。设一次，以后系统自己算。

小棠：早该这样，每次临时想数太累了。

旁白（未来配音）

表 F 以高级房 BAR 为基准 100，设定一次，全房型价格自动生成。升房加价按阶梯来。

判定表结论

表 F 房型价差阶梯：以高级房 BAR 为基准 100，各房型平峰价按阶梯自动生成；升房加价看阶梯而非拍脑袋。

EP06

《折扣带条件才有效》

指向 表 A · 折扣分支 · 约 50 秒
分镜
  1. 小棠想直接打折冲量，屏幕弹出一张带小锁的折扣券。
  2. 折扣分支上挂着几把锁：连住、提前订、不可取消。
  3. 阿表翻开表 A 的折扣分支，逐把锁亮起说明。
  4. 小棠把「裸打折」改成「连住两晚 9 折」。
  5. 均价曲线没有塌，量上来了。
对白

小棠：房卖不动，我直接打 8 折冲一波？

阿表：停。表 A 的折扣分支说——裸打折冲量，会拉低整日均价，白忙。

小棠：那怎么办？

阿表：折扣要带条件：连住、提前订、不可取消。锁上这几把锁，利润才保得住。

小棠：所以不是不打折，是打折得换点东西回来。

旁白（未来配音）

折扣带条件才有效。裸打折冲量拉低均价，条件折扣才保利润。

判定表结论

表 A 折扣分支：折扣须绑定连住 / 提前订 / 不可取消等条件；裸打折会拉低均价，条件折扣保利润。

EP07

《弹性算反的那次》

指向 表 A · 价格弹性 · 约 50 秒
分镜
  1. 小棠一降价，屏幕上的需求曲线没涨，反而往下弯。
  2. 她手指在曲线上来回划，一脸懵。
  3. 阿表翻开表 A 的弹性分支，一条反向弯曲的曲线亮起。
  4. 「弹性算反」四个字弹出。
  5. 小棠把价格调回原位，先去查弹性。
对白

小棠：我降了 50 块，怎么订量反而少了？

阿表：因为你这档需求是反向弹性的——越便宜人家越觉得不对劲。表 A 弹性分支说，先算弹性再调价。

小棠：还有反向的？

阿表：当然。商务客、会议客经常「贵才信」。不先算弹性就动手，越降越糟。

小棠：那次我白降了。下次先问表 A：这档弹性是正的还是反的。

旁白（未来配音）

不是所有需求都随降价上涨。先算弹性，再调价，别凭感觉。

判定表结论

表 A 价格弹性分支：调价前先判断需求弹性方向；反向弹性时降价反而减收入，须先算后动。

指向 表 E · 超额预订标准 · 约 50 秒
分镜

对白

小棠：原来超售有标准动作，不是看胆子。

旁白（未来配音）

超售间数 = 可售房量 × 超售率（向下取整）。三步走：查基准、乘修正、卡上限。

判定表结论

表 E 超额预订标准：超售间数 = 可售 × 超售率（下取整）；查基准率 → 乘修正系数 → 卡硬上限，不靠赌。
