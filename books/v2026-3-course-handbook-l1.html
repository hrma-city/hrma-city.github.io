级别定位与考核

L1 能力卡

收益执行专员 / Revenue Executive　独立完成每日取数、查表、执行、记录全流程

先修：无　·　周数 / 学时：4 周 / 16 学时（能力主线）　·　通过线：笔试≥80、实操≥85、出勤≥90%　·　结业：课程结业证明（L1）

本册排课口径

本册按教材全量排课：8 讲、16 学时、4 周。与 v2026-2-curriculum-l123.html 的「20 周 / 80 学时能力主线」存在差额，原因是能力主线只计必修核心学时，教材含选讲与自学。这一差额登记为口径差异，不静默改数；三级合计 94 学时与教材一致。

免责声明：自建学习成果证明，无外部背书，不等同国家职业资格或职业技能等级认定

本级别授课纪律
  1. 每讲先写口径（分母、含税、币种），再讲判定式，最后算净贡献。
  2. 案例先让学生自己判断，再对照母本「案例导入」推进讲解。
  3. 练习必须写出依据表号；只写结论不写取舍理由按半分计。
  4. 凡涉及旧值，板书标 v1.0；本版值标 v2026.3，避免两套写法混用。
  5. 异常日按表 L 暂停自动改价，课堂演练一次人工降级流程。
  6. 每讲收尾回扣本讲关联判定表的输入字段与复审日。
  7. 教具只用本手册第 04 节清单内的资料，不临时引入未校准的阈值。

三级深度与晋级

级别本级别深度晋级条件
L1 执行会取数、查表、执行、记录；不要求解释模型来源完成 8 讲 + 通过线 + 决策日志无缺项
L2 决策会预测、复算、置换、仲裁、校准；要求写出依据完成 16 讲 + L1 或 1 年经验 + 通过线
L3 治理会定目标、搭治理、控合规、做汇报与体系维护完成 17 讲 + L2 + 3 年经验 + 答辩 ≥75
三级共用同一套 41 章教材正文，差异在深度不在章目；分册每讲第 07 板块写明 L1 / L2 / L3 各自要求。

Have a Try / Tips

Have a Try（明天能做的三件事）

  1. 按逐周日历排第一周课，把两讲的第 05 / 06 板块打印成当堂练习与答案页。
  2. 用第 04 节教具清单核对教师用书、学生用书与投影资料是否齐备。
  3. 把通过线、结业证明措辞与免责声明写进课程大纲，避免对外口径越界。

Tips

开课手册回答「什么时候讲哪一讲、讲多久、交什么」，讲次正文回答「这一节课具体讲什么」。
