把一个行业的方法，搬进另一个行业

收益管理的通用内核只有一套：预测、定价、库存、渠道、超售。行业不同只是参数不同。 下面八个案例，讲透"方法迁移"——看懂一个，就能举一反三。

航空 → 住宿

舱位控制，就是房型嵌套

来源：航司用 R/Y/B… 舱位做嵌套保护水平　→　落地：酒店用 BAR 价格档做房型嵌套

航司把一架飞机的座位按价高到低分成若干舱，低价舱卖光不影响高价舱。酒店完全同理：把 300 间房按价分成全价/高级/折扣三档，折扣档售罄不挡全价售卖——这就是"嵌套控制"。

迁移要点：① 保护水平 = 为高价档保留的最低房量；② 关掉最低档用"限制"而不是"涨价"；③ 库存从低到高开放，避免贱卖。

带走：你只要会算"多留一间给高价客的期望收益 ≥ 现在低价卖出"，舱位和房型是同一道题。
餐厅 → 景区

翻台率，就是承载力利用率

来源：餐厅用翻台率 + 分时定价管午晚市　→　落地：景区用分时预约 + 承载力限流

餐厅午市空闲、晚市爆满，于是午市降价拉翻台、晚市控预订保体验。景区也一样：工作日上午闲置、节假日爆满，于是工作日低价引流、节假日分时预约限流。

迁移要点：① 把"翻台"换成"时段承载力"；② 用价格 + 预约双重手段削峰填谷；③ 超售=接受适量等位（餐厅）对应景区"弹性放号+现场候补"。

带走：任何"同一空间在不同时间价值不同"的生意，都能用分时定价 + 容量限制。
航空 → 酒店

DB 拒载，就是 walk 客人

来源：航司超售算 No-show 期望，爆舱赔 DB　→　落地：酒店超售算 No-show 期望，爆仓赔 walk

两者都是"因为有人不来，所以多卖一点"，爆了都要赔。区别只在赔付形式：航司是法定赔偿+改签，酒店是送隔壁+免单+积分。

迁移要点：① 最优超售量 = 容量 × No-show 率，再按赔付成本微调；② 赔付成本上升时，超售额度应下调（多卖一间的边际收益抵不过赔付）；③ 把超售做进每日判定表，别临场拍。

带走：超售是概率题不是胆量题，行业换了名字，算的是同一个期望。
酒店 → 剧院

动态定价，就是早鸟与尾票

来源：酒店按 OCC+Pickup 调价　→　落地：演出按售座率+临近度调价

酒店临近日期、库存剩得多就降价。演出同理：开票早鸟打折锁需求，临演未售出的票尾票甩卖回血——座位和房间一样，开场即归零。

迁移要点：① 用"已售比例 + 距开场天数"做双因子；② 早鸟是预测性降价（锁需求），尾票是清库存降价（防归零），目的不同动作不同；③ 好座位=高价档，需嵌套保护。

带走：凡是"开场/午夜归零"的库存，早鸟与尾票就是它的双因子矩阵。
餐饮 → 航空

套餐提升客单价，就是辅营收入

来源：餐厅用套餐/酒水拉高人均消费　→　落地：航司用选座/行李/升舱拉高 RASK

餐厅 ADR 难涨，就靠套餐和酒水把"人均消费"做厚。航司票面价被比价压死，就靠选座、优先登机、行李、升舱这些辅营（Ancillary）把单位收入做厚。

迁移要点：① ADR/票面是"引流价"，辅营是"利润价"；② 用产品区隔而非直接涨价避免比价；③ 关键指标从 ADR 升级到"单位产能综合收入"（RevPAR / RASK + 辅营）。

带走：当主产品被比价锁死，把利润搬去"周边产品"是跨行业通用解法。
零售 → 全行业

收益管理，就是动态定价 + 个性化

来源：电商按库存/竞争实时调价、按人出券　→　落地：酒店/景区的动态价 + 会员定向权益

零售早就把"剩货降价、旺货提价、对价格敏感的人发券"玩透了。 hospitality 行业慢半拍，但路径一致：用剩余库存驱动调价，用客户标签驱动定向权益。

迁移要点：① 把零售的"实时比价调价"接进 RMS；② 把"发券"换成"会员等级权益"，避免公开破价；③ 始终守住 Rate Parity，券/权益不公开挂价。

带走：收益管理的终局是"千人千价"，但 hospitality 要用权益而非明码差价来实现。
网约车 → 全行业

动态溢价，就是需求峰值加价

来源：网约车按实时供需缺口加价（Surge）　→　落地：酒店 / 景区 / 餐厅在高峰时段动态提价

网约车用车紧张时自动加价、缓解后自动回落——加价信号来自"实时供需缺口"而非"想多赚"。酒店、景区、餐厅的需求高峰同理：当库存稀缺叠加查询暴涨，就该提价；平峰就该降价引流。

迁移要点：① 溢价触发要基于"库存剩余 + 实时查询"双信号，不是主观拍脑袋；② 提价必须可解释（让用户懂"为什么现在贵"），否则引发抵触、损伤品牌；③ 用时间窗限制溢价时长，避免长期高价被认定宰客。

带走：任何"供给相对需求瞬时稀缺"的场景，都能用实时溢价把稀缺变现，前提是信号透明、时长可控。
停车 / 充电 → 酒店

闲置产能的分时复用

来源：停车场 / 充电站昼夜闲置，用分时计价 + 包月盘活　→　落地：酒店宴会厅、会议室、健身房闲时对外出租

写字楼停车场白天满、夜间空，运营商用夜间包月把闲置车位卖掉；充电站同理错峰计价。酒店的非客房产能——宴会厅、会议室、泳池、健身房——工作日上午大量闲置，却几乎从不做收益管理。

迁移要点：① 把"非核心时段产能"当作第二库存单独定价；② 用打包（住宿含会议、含健身）而非直接降价，避免冲击主价格体系；③ 闲置产能边际成本近零，多卖一元即纯利润，应优先用低价填满而非空置。

带走：收益管理不只管"客房 / 座位"，任何边际成本近零的闲置产能，都是被忽视的利润池。
