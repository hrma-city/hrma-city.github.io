《收益管理操作指南》分级蓝图

按我们自己的 L1 / L2 / L3 三级能力体系重新切分 · 判定表贯穿所有产品
收益管理实战书系 · 门内评审稿
诊断结论（先说事实）：现有《收益管理操作指南》正文 v1（books/guide.html，36 章）是按业务职能 topical 编排的——入门 / 定价 / 库存 / 周期 / 多业态 / 组织六篇。它以 codex 的 15 张判定表为操作核心，但没有按技能等级分档，也没有挂 L1/L2/L3、861 判定项或 1+X。所以你担心的"有人觉得太复杂、有人觉得太粗略"是真实的：一本通吃，等于没分级。

本蓝图怎么做：以我们自己的 L1/L2/L3 三级能力体系（16 项能力徽章，正好对应 15 张判定表）为蓝本，把同一本 36 章操作指南重新切出三档读者版。难度由"能级"解决，粗细由"每档附速查卡"解决。判定表做脊梁，全程贯穿。

一、为什么用 L1/L2/L3 作蓝本（而不是另起炉灶）

我们的三级能力体系（见 badges.html）是按"能不能独立做事"定义的，天生就是分级的，且与判定表一一对应：

L1 · 基础：会算、会查
跟完一天不出错。4 项：算得清 / 跟得上节拍 / 看得懂进度 / 查得对表。
L2 · 操作：会定、会留痕
独立出建议，动作有依据有记录。7 项：控库存 / 算超售 / 理价差 / 排渠道 / 升档 / 守团价 / 交周期产出。
L3 · 经营：会权衡、会汇报
处理冲突异常，讲成经营语言。5 项：定位置 / 算团队 / 处异常 / 裁冲突 / 讲经营。
16 项能力 ↔ 15 张判定表（表 A 每日调价 / B 库存配置 / C ARI / D MPI / E 超售 / F 价差 / G 询价 / H 渠道 / … / O 冲突仲裁）。判定表既是操作落点，也是分级的标尺——L1 查基础表、L2 用全套、L3 用冲突仲裁与战略表。

二、三档读者版大纲（同一本 36 章，三种厚度）

L1 执行专员版

定位：一线执行，照表做、不出错（对应 1+X 初级 / 861 基础判定项）

  • 必读章（12 章）：第 1–4 章（指标与报表入门）、第 20 章（运营全景·跟节拍）、第 31 章（每日实操流程与例会）、第 12–13 章（MinLOS、超售·基础查表）、第 30 章（系统数据·基础）、第 32 章（30 误区·基础 10 条）
  • 必会判定表：表 A（查涨价/降价分支）、表 B（库存限制配置）、表 E（超售红线）
  • 角色开场："你坐哪儿、对谁负责、每天 5 件事"
  • 红线页：walk>0.5%、价格一致性、净价口径、日报不漏填
  • 自测：20 题，取自 861 基础判定项 + 教材对应章
L2 主管版

定位：独立负责一家店日常收益，会定、会留痕（对应 1+X 中级 / 861 操作判定项）

  • 必读章（20 章）：第二篇全部（5–11 定价全套）、第三篇全部（12–19 库存/超售/渠道/团价/置换）、第 21/23/24 章（预测/淡旺/周月节奏）、第 25 章（成本利润）、第 30 章（系统·进阶）
  • 必会判定表：全套 A–O，重点表 A/B/E/F/G/H（定价+库存+询价+渠道）
  • 新增能力：异常判读（pickup 落后 / 竞对调价 / 渠道异常 → 怎么下令）、带人分工、周月季报告
  • 红线+留痕：每步决策写依据、调价分批纪律、置换留记录
  • 自测：30 题，取自 861 操作判定项 + 教材对应章
L3 经理版

定位：参与经营决策、带团队/多店，会权衡、会汇报（对应 1+X 高级 / 861 经营判定项）

  • 必读章（16 章）：第 3 章（竞争定位 RGI/ARI/MPI）、第 17 章（团队置换·权衡）、第 18 章（渠道战略）、第 22 章（年度预算）、第 26–28 章（餐饮/宴会/跨行业总贡献）、第 19 章（直销会员战略）、第 29/33/34 章（组织/渠道生态/连锁）、第 35 章（危机处置）、第 36 章（优先级冲突仲裁·表 O）
  • 必会判定表：表 O（冲突仲裁，最高优先级）、表 C/D（竞争定位）、表 H（渠道战略）、表 A/B（配套）
  • 新增能力：冲突仲裁、预算与总盘、向总经理汇报（结果/原因/要什么决定）、多业态组合
  • 战略页：渠道生态、连锁中央定价边界、极端场景预案
  • 自测：25 题，取自 861 经营判定项 + 教材高阶章 + C/D 类赛项素材

四、判定表如何贯穿（"查表→执行"闭环）

沿用现有指南的核心机制，三档统一：

  • 每章末挂"判定表落点"：指明遇到该类决策翻哪张表、按什么条件执行，不必靠个人判断。
  • 书末附录集中 15 张判定表：A 每日调价 / B 库存配置 / C ARI / D MPI / E 超售 / F 价差 / G 询价 / H 渠道 / … / O 冲突仲裁。
  • 三档差异只在"拥有哪些表"：L1 拥有 A/B/E（查基础）；L2 拥有 A–H 全套（独立操作）；L3 额外拥有 O（仲裁）及 C/D 战略用法。
  • 与认证打通：每档自测题取自 861 判定项 + 教材对应章；通过即点亮 badges.html 对应能力徽章，自然衔接 M01–M14 认证模块与"课证融通附件包"。

五、与既有资产的衔接

  • 教材（41 章 / 861 判定项）：本指南只讲"怎么做"，教材讲"为什么"；自测题双向引用。
  • 判定表 codex（15 张）：操作落点的唯一真源，三档共用。
  • 能力徽章 badges（16 项）：分级的标尺，也是认证入口。
  • 课证融通附件包：L1/L2/L3 三档即"院校可照表上课、照表办赛、照表出校本达标证明"的蓝本。
  • 赛事引擎（16 赛项）：A 类理解赛对应 L1、B 类决策赛对应 L2、C/D 类论证抗压赛对应 L3。
结论：我们完全有自己的标准（L1/L2/L3 + 861 + 41 章 + 15 判定表），分级操作指南应以它为唯一蓝本。1+X 不是我们的标准，仅作为院校出口的并行映射（见另一版蓝图）。
