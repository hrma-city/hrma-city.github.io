00一个具体场景 / 五步全景

周二上午，某高职院校教务处来电：「下学期开收益管理课，想买你的教师配套和学生认证，怎么走？」对方有意愿、有课程、有经费窗口，但没人能替你把合同、发票、开通、验收串起来。这份手册就是把这一通电话之后的每一步写清楚。

一句话结论

授权卖的是「一学年的资源使用权 + 版本更新 + 认证资格」，不是一次性的资料包。

完成这件事的五步是：确认主体资格 → 定标的与一口价 → 走对方采购流程签合同 → 开通并完成验收 → 期间服务与到期续费。

最容易被漏掉、也最容易卡死的是第一步：你自己能不能开对公发票、能不能进对方供应商库。内容早就齐了，卡点在这里。

步要拿到的东西对应本页
1可售主体资格 + 发票能力 + 供应商入库条件01
2授权标的清单（SKU）与免费层边界 + 三档一口价02 / 03
3对方的采购路径、合同、审签与付款节点04 / 05 / 06
4账号 / IP 白名单 / 教师身份验证 / 考务账号 / 验收单07 / 08
5使用统计、勘误、版本更新、续费通知与终止处置09 / 10
上位判断见《盈利模式与共创分润建议》：授权层是三层产品中的第二层，第一层是学生教材版税，第三层是 1 对 1 开课陪跑。本页只解决第二层怎么交付，不改前两层的定价与边界。

01第一卡点：收款主体资格

《著作权法》第二十六条规定，使用他人作品应当同著作权人订立许可使用合同；许可使用合同应包括许可使用的权利种类、专有或非专有、地域范围、期间、付酬标准和办法、违约责任。签合同这一环没有障碍。障碍在收钱这一环。

国内高校数字资源采购的公开合同几乎都要求：供应商为可签约主体、提供含税发票、对公结算、提供版权合规证明；单套超 5 万元的数字资源要提供性能指标测试报告原件；合同总价 10 万以上常要求 5% 履约保证金；30 万以上需审计后付款。若以自然人身份直接参与政府采购，供应商资质、发票与保证金都会成为卡点。
路径适用你要具备优点 / 代价
A · 轻量：著作权许可费单院系、金额较小、走院系经费或横向课题经费、不进入政府采购目录个人身份签「著作权许可使用合同」；到税务机关代开发票；能收对公转账起步快、零注册成本；但很多院校财务不接受个人供应商，且额度受限
B · 正式：市场主体进入院校供应商库、走政府采购/招标、金额较大或需履约保证金个体工商户或一人公司；对公账户；自行开具增值税发票；公章与合同主体一致可承接正式采购与多年期合同；代价是注册、记账、报税与年度维护

接到电话后先问三句话，答案决定走 A 还是 B：① 这笔经费从哪个科目出、由谁签？② 贵校对供应商资质和发票类型有什么要求？③ 金额落在什么区间、要不要走招标或政府采购？不要先报价，先问流程——EDUCAUSE 的采购指南强调，谁有权限批这笔钱、以及非正式采购与正式采购的阈值，决定了整个时间表。

诚实边界：目前没有查到本项目已注册的市场主体信息，此前讨论创业申报时也是「个人未注册」状态。因此路径 B 是一个待办，不是已完成的前提。主体与税务处理请由执业税务师与院校财务确认后再对外承诺交付时间。

授权层不含：逐校定制诊断、驻校培训、1 对 1 开课辅导、教材本身（教材走购书与版税）。这几项归第三层，把它们塞进授权包会让交付变成服务，续费和边际成本都失控。

CC BY-NC-SA 的含义是：他人可在非商业条件下自行取用与改编，无需再征得同意，并可部署到自己的校内平台。若把授权标的误标进免费层，院校就没有付费理由了。合同里必须写明「附件一商业资源不适用附件二 CC 许可」，两份清单各自附校验值。

03怎么定价：分档与报价

全球教育机构授权的主流是固定费的 site license 与按规模分档，而不是按实际使用量结算。固定费简化对方预算，也免去你每学期核人数的行政成本。

惯例做法公开例子是否适合 RMC
Site license（固定费不限量）一校一口价，覆盖全校授权用户Respondus：按 IPEDS 学生 FTE 分 12 档年费，机构自报档位，合规点是申报数准确适合，但按全校 FTE 对单门课不贴切
FTE 分档按全日制当量学生数分档，兼读按 0.5 计EIFL：要求院校提供官方 FTE 数字；EDUCAUSE：须写明计数口径并谈 true-down 条款不建议，单课程与全校规模弱相关
期限阶梯1 / 3 / 5 年不同价，多标题数量折扣ArcLearn：FTE <8000 / >8000 × 1/3/5 年定价；须用院校标准采购单 PO可借鉴多年期，但不做折扣
按学期访问码学生每人每学期一个 access codeMcGraw Hill Connect / Cengage MindTap 等课程平台增加核销与分发成本，暂不采用
Consortium 联盟价多校联合采购，统一合同与合规审查EDUCAUSE：省采购与法务成本，但要确认联盟价确优于单独谈判可作为独立 SKU（多校集团），不是折扣

RMC 建议：按「开课规模」三档，每档一个按校按年的一口价，全年不因人数变化调整。计价基数用「开课班数 + 授课教师数 + 参训学生上限」，比全校 FTE 更贴合，也让对方一眼看懂买了多少。

档位适用规模（写入合同）覆盖 SKU一口价
档 A · 单班1 个班 / ≤2 位授课教师 / 学生上限 ___ 人A + B + D___ 元/学年
档 B · 多班2–3 个班 / ≤5 位授课教师 / 学生上限 ___ 人A + B + C + D___ 元/学年
档 C · 院系不限量本院系内不限班数与教师数 / 学生上限 ___ 人A + B + C + D + 多次组卷___ 元/学年
金额留空由你定，此处只定结构。三条纪律：① 每档只报一口价，不打折不买送；② 续费涨幅或次年价写进首年合同（EDUCAUSE 指出突发涨价是院校与供应商最主要的摩擦来源）；③ 报价单注明含税、有效期与学年起止日，对齐对方预算周期。

与教材的绑定关系：授权层以「本校已采用或同步采用教材」为前置条件，因为教案、题库、rubric 都引用章号与表号，脱离教材无法使用。但教材购书款与授权费分别结算、分别开票，不打包打折。

04端到端 12 步

下表按一通电话之后的时间顺序写。每步都给出「要拿到什么」和「常见卡点」，照着走即可，不必先建平台。

步 / 时点动作输入 → 输出常见卡点
1 · T+0接意向电话，只问不报：谁买、买哪些 SKU、给谁用、经费科目与审批阈值来电 → 《院校意向登记表》四问答案一上来就报价，后续发现要走招标，报价作废
2 · T+0自查主体资格：能否开含税发票、能否进供应商库、是否需要履约保证金自身资质 → 路径 A / B 判断个人主体无法进政府采购；见 01
3 · T+1发《授权说明书》：SKU 清单、免费层边界、样例章、版权合规声明、三档结构资料包 → 对方内部传阅与立项把母本整包发出去当「样章」，付费理由消失
4 · T+2开 2–4 周试用：限定入口、限定 IP/邮箱域名、只开 B 包与部分 A 包试用账号 → 使用记录与师生反馈EIFL 建议避开开学、考试与假期；正式宣布前自己先验访问
5 · 试用同期拉对方 IT / 财务 / 法务 / 采购一起进沟通（EDUCAUSE 强调早期介入）四部门联系人 → 采购路径确认只对接教务处，到签合同才发现信息办要立项论证
6 · T+7~21按金额区间走对方流程：询价记录 / 论证报告 / 项目库申报 / 招标材料 → 采购受理单各校阈值不同；先要对方现行制度原文，别照抄别校
7 · 报价出书面报价单：档位、一口价、含税、学年起止、SKU 清单、有效期、续费涨幅报价单 → 对方预算锁定未写明次年涨价规则，续费时反复议价
8 · 签约授权合同 + 附件一/二清单 + 版权合规证明；走对方合同审签合同原件 → 双方盖章授权范围没写清 Authorised Users，后续跨校共享无据可依
9 · 开通交付资源包、校级账号、IP/邮箱白名单、教师身份验证、考务账号开通确认 → 《交付清单 + 使用说明》现有静态站登录门不足以商用，见 07
10 · 验收按合同标准初验 + 校级验收，签《履约验收书》验收单 → 验收合格缺资源清单、使用说明或版权合规证明，验收通不过
11 · 收款验收合格后开票 → 对方核对 → 对公付款发票 → 到账放假、财政封账顺延不算违约，合同要写明
12 · 期间与续费版本更新、勘误、答疑、学期使用统计；到期前 60 天发续费通知学期报 → 续费或终止处置没有使用数据，续费时说不出价值
郑州大学与洛阳职院的公开合同都写明「验收合格后通知开票、核对无误后一次性付款」；鲁东大学办法要求验收小组合格后才通知中标商开票。所以先开通、后验收、再开票收款是常态，现金流要按这个顺序安排。

05国内院校采购路径

院校不会「直接付钱」，它们走自己的采购制度。下面是从公开校例中归纳的金额分层，只用作提问参考，必须以对方现行制度为准。

金额区间（校例）常见路径常见材料对 RMC 的动作
10 万元以下用户部门自行采购自行采购询价记录、采购申请、合同审签表备好三家比价或单一来源说明；这是最可能走成的第一单
10–20 万元归口部门（信息办/图书馆）采购立项论证报告（≥10 万）、软件采购审批表提供技术标准与测试验收标准、版权合规证明
20 万元以上招标办 / 政府采购招标文件、投标响应、履约保证金（常见 5%）、验收报告需市场主体资质与保证金资金占用；建议路径 B 后再接
30 万元以上验收后还需审计审计材料 + 上述全部付款周期明显拉长，报价时把资金占用计入
公开校例要点：山东大学软件类无形资产流程为「立项论证（≥10 万）→ 采购审批 → 招标/采购 → 签合同 → 软件授权使用 → 验收（≥10 万）→ 开发票 → 付款」；鲁东大学数字资源采购办法为「组织试用 → 依据试用结果确定 → 纳入项目库申报 → 评审 → 政府采购招标 → 发布使用」，备案文件含采购招标受理单、授权委托书、合同审签表、正式合同原件、履约验收书、发票；广东轻工职业技术大学成交公告要求交付时提供资源清单、使用说明、产品合格证书、测试报告、版权合规证明，并在收到验收申请后 7 日内组织履约验收。

把这几份材料提前做成一个「采购应答包」，第一次被问就能给全，比临时补快得多。目录见 09。

06合同必备条款（16 条）

《著作权法》第二十六条列的六项是底线，院校数字资源合同还会加知识产权担保、SLA、验收与保密。下面 16 条可直接当合同目录用。

  • 双方主体：全称、统一社会信用代码、联系人；供方名称须与发票、公章、收款账户一致
  • 授权标的：附件一列明每个文件的名称、版本号、载体、校验值；附件二列明 CC 免费层范围
  • 授权性质：非独占、不可转让、不可转授权；明确不是著作权转让、不是合作作品、不是委托创作
  • Authorised Users：本校在册授课教师与当学期选课学生；写清是否含旁听生、校友、分校、附属院校、继续教育
  • 授权范围：校区与 IP 段 / 邮箱域名、地域、学年起止日、账号数或并发上限
  • 允许行为：课堂教学、校内 LMS 导入、打印份数上限、可否改编及改编后是否需回传、可否本地镜像备份
  • 禁止行为：对外分发、公开上网、转售、跨校共享、拆包、上传公共网盘、用作 AI 训练语料
  • 与 CC 的边界：附件一商业资源不适用附件二 CC 许可；免费层素材在校内使用不因此收费
  • 交付与验收：交付方式、技术标准、资源清单与使用说明、验收期限、初验与校级验收、验收单格式
  • 费用与票据：含税金额、发票类型、开票信息、付款节点、放假/财政封账顺延不算违约
  • 知识产权担保：供方保证不侵犯第三方权利；第三方索赔由供方承担并赔偿相关损失
  • 服务与 SLA：指定专人、响应时限、故障通知时限、IP 段变更时限、版本更新与勘误、使用统计
  • 超范围使用：发现后的通知 → 整改 → 暂停 → 终止四段处理，以及水印/指纹取证方式
  • 保密与数据：学生名单与成绩数据的处理方、用途限定、留存期限、到期删除或回传
  • 期限与终止：到期停用、证书编号有效性、数据留存、续费通知提前量、终止后资源下架
  • 违约与争议：违约责任、管辖或仲裁、合同份数与原件归档
可直接抄的成熟条款（来自公开采购合同）：IP 段变更——甲方通知后乙方 48 小时内回复、7 个工作日内完成更改；故障——24 小时内通知，1 个工作日响应，3–5 个工作日内解决；供方按要求提供资源列表与使用统计分析；合同期内每年年底或终止时，按采购方要求提供本地化镜像存储，不另收服务费。这些写进合同比口头承诺更能通过验收。
合同模板只作结构参考。正式对外前请由执业律师审一遍，尤其确认著作权许可与 CC 免费层不冲突、学生数据条款符合个人信息保护要求。

07技术交付 V0 / V1 / V2

诚实边界：现有门是纯前端本地哈希比对，不足以承载商业授权。账号可共享、没有角色权限、没有 IP 限制、没有审计日志、没有使用统计。不要拿它直接去收授权费。分三阶段走，第一单用 V0 就能交付。

阶段做法解决什么不解决什么
V0 · 现在可做（手工）每校独立入口 + 校级授权码；校园 IP 段或学校邮箱域名白名单；A 包资源逐页加校名水印与唯一指纹；教师身份验证（学校邮箱注册 + 验证码 + 后台确认，抄 Cengage TRC）；考务账号单独发放；使用台账人工登记身份可核、泄漏可追、验收有据、能开第一单SSO、自动名册同步、自动统计、防截图
V1 · 一学期内（半自动）真账号体系 + 角色权限（管理员/教师/学生/考务）；访问与下载日志；月度使用统计自动导出；资源包指纹与下载绑定；题库抽题组卷续费有数据、超范围使用可发现与校内 LMS 深度集成
V2 · 3–5 所校后（平台化）SSO（SAML / OAuth / LTI 1.3）、名册同步、成绩回传、IP 白名单与开考一次性码、审计日志进入院校正式信息系统、可承接政府采购技术审查暂不需要，别提前投入

V0 的教师身份验证有现成范本：Cengage 学科教学资源中心（TRC）把 PPT、教师手册、题库、参考答案列为教师专用资源，要求用学校邮箱注册、提交教师身份信息、后台发验证码、验证通过后邮件通知并重新登录下载；校园网则做 IP 免登。TPT 还规定二次分享需购买「额外许可证」——RMC 可把「跨校/跨班分享」写进合同的禁止行为。

全球平台常见配置（ISTE+ASCD site license、Synap、Cirrus）：SSO、名册自动同步、最小权限角色、IP/CIDR 白名单、审计日志、加密。这些是 V2 目标，不是第一单的前提。第一单要交付的是可核验的「谁在用、用了什么、有没有超范围」，不是一套平台。

08认证与题库安全

L1–L3 学生认证与 76 真题是授权层里最容易失守的一块。真题不整包交付，否则一届学生传完，题库就废了。

环节做法依据 / 参照
考点资格院校授权即成为本校认证考点；指定 1–2 名考务管理员，实名登记认证考试授权考点的通行做法
组卷从 76 真题按 L1 / L2 / L3 分级抽题，题目与选项顺序随机，每人一卷Synap / Janison：题随机化，每人一份不同卷

身份与准入考务账号 + 一次性开考码 + IP/CIDR 白名单 + 限时窗口；可选 MFASynap / Cirrus：一次性密码、IP 限制、唯一会话、超时

成绩与证书成绩回传院校；证书编号与查询页按学年有效；到期后编号不失效但不再发新证合同「期限与终止」条款落地
ISO 27001、SOC 2、全链路加密、专业监考是 V2 的事。现阶段靠「不整包交付 + 抽题组卷 + 曝光控制 + 考务实名 + 一次性开考码」就能把风险压到可接受，不需要采购考试平台。

12Have a Try / Tips

Have a Try（明天能做的三件事）

  1. 写下接电话时要问的四句话，并补上第五句「贵校对供应商资质和发票类型有什么要求」；先确认路径 A / B，再谈价。
  2. 把现有 v2026-1-* 文件按 A / B / C / D 四个 SKU 归一遍，同时列出「免费层」和「永不免费」两张清单，这是附件一与附件二的底稿。
  3. 先做采购应答包里最要紧的三份：授权说明书（一页）、SKU 与交付清单、版权合规证明。这三份不齐，院校的验收流程走不动。

Tips

授权卖的是一学年的使用权与更新，不是一次性的文件包；续费的理由来自使用统计和勘误记录，不是来自新资料堆量。

内容已经齐了，第一单卡在主体资格、发票和验收材料上。把流程做通一次，后面每一所校都是复用同一套动作。
