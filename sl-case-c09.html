案例 09 · 对面降价了

杭州滨江云璟酒店 · 第 0 篇 ｜ 共 11 屏
<b>引子</b>：B 店连着两周降 15%。上次我们没跟，赚了；这次要不要跟——还是同样的答案吗？

情境：这一夜到底发生了什么

五月，赵敏的比价日报连续第十天标红：

B 店把 BAR⑥ 从 680 降到 578，已持续两周。

林岚先算了 ARI⑫：

```

ARI⑫ = 本店 ADR ÷ 竞品均价

```

"ARI 从 1.02 升到 1.15。"林岚说，"我们比竞争组合㉙贵了 15%，超过合理区间了。"

小马在旁边接话："上个月 B 店也降过一次，我们没跟，最后 GOP 是赚的。这次也别跟吧？"

林岚没马上回答。她把上个月那次调出来对比：

"看出区别了吗？"林岚问小马。

"这次时间长。"

"不止。"林岚指着第二行和第四行，"上次是三天、只针对工作日商务客，那批客人看的是位置和会议室，不看价。这次是全周、连周末一起降——周末是本地休闲客，他们对价格非常敏感。"

她调出在手对比：

"周末掉得比工作日厉害。说明流失的正是价格敏感的休闲客，这批人本来是我们的增量，现在被 B 店 578 吸走了。"

决策会：跟，还是不跟？

郑昊主张跟："不跟，周末空 40 间。"

赵敏主张跟满："B 店降 15%，我们也降 15%，不然排名掉下去。"

情境：这一夜到底发生了什么

林岚给了第三个答案：跟，但不跟满；而且不公开降 BAR⑥。

她的三条理由：

第一，跟多少？

"不是说对手降 15% 我们就得降 15%。我们要回到 ARI 的合理区间，不是回到对手的价格。"

她算：目标 ARI = 1.08（本店的合理位置：比组合均价贵 8%，因为我们有博览中心的位置溢价）

```

目标 ADR = 540 × 1.08 = 583

当前 ADR = 621

降幅 = (621 − 583) ÷ 621 = 6.1%

```

"只需要降 6%，不是 15%。"

第二，怎么降？

"不公开降 BAR。"林岚说，"公开降 BAR 621 → 583，等于给所有协议公司、会员、OTA 一个新锚点——案例 01 的教训就在那儿。"

她给的替代方案：

"用定向价回到 ARI 1.08，但 BAR 不动。这样周末的量能回来，BAR 体系不破。"

第三，还能做什么？

"第三件事更重要。"林岚说，"B 店降 15% 是因为他们新开业的 E 店抢了他们的量，他们是被迫应战。这种降价通常持续不了两个月。"

情境：这一夜到底发生了什么

她查了 B 店过去两年的降价记录：

四次里，两次跟了都亏；两次没跟都赚。

但林岚指着持续时间的那一列："这次是 14 天，接近第 4 次（21 天），那次我们跟了，亏了 6%。但那次我们跟的是'公开降 BAR'。"

"所以这次的区别是什么？"

"这次我们用定向价，不破 BAR。"林岚说，"同样的'跟'，方式不同，结果会不一样。"

执行三周的结果：

B 店在第五周把价格涨回 650。他们的降价一共持续了 32 天。

周总在复盘会上说："这次做对的两件事：一是没跟满，二是没动 BAR。"

林岚补了第三件："还有一件：我们查了他们的历史。对手降价不是突发事件，是有规律的——记录它，下次就不用吵了。"

决策点 · 您会怎么选

决策点一：对手降价，第一件事做什么？

  • 不是决定跟不跟，是先算 ARI 变化
  • 判据：ARI 在合理区间（本店 1.02–1.10）内 → 不动；超出 → 才考虑动作。

决策点二：跟多少？

  • 不是对手降多少就降多少，是回到自己的合理 ARI
  • 本例：需要降 6%，不是 15%
  • 判据：跟价的目标是"回到自己的位置"，不是"追上对手的价格"。

决策点三：怎么跟？

  • 公开降 BAR vs 定向价（会员专享 / OTA 周末包 / 渠道限定）
  • 判据：能用定向价解决的，绝不动 BAR。BAR 是全年的锚，动一次影响一整年。

决策点四：怎么判断这次和上次不一样？

  • 对比三个维度：持续时间 / 覆盖日期 / 客群是否重叠
  • 判据：记录每一次对手降价的所有参数，下次直接查表，不用重新吵。

知识提炼

一、竞争三指数（别只看 ARI）

指数公式含义本店合理区间
MPI 市场渗透指数本店 OCC ÷ 竞争组合 OCC抢到的份额够不够0.95–1.05
ARI 平均房价指数本店 ADR ÷ 竞争组合 ADR卖得贵不贵1.02–1.10
RGI 收入产生指数本店 RevPAR ÷ 竞争组合 RevPARMPI × ARI1.00–1.15

RGI⑭ 是最终指标：份额和价格都赢，RGI 才高。

只赢一个（比如 OCC 高但 ADR 低）不算赢。

二、竞争响应三步

```

① 算 ARI 变化 → 超出合理区间才考虑动作

② 查历史同情境 → 这个对手、这个幅度、这个时长，我们跟过的结果

③ 判客群重叠 → 抢的是同一批人吗？（工作日商务 vs 周末休闲）

```

三步都指向"跟"才跟；有一条说"不"，就该考虑不跟。

三、跟价的三种方式（代价从小到大）

方式代价持续时间推荐度
加价值包（送早/送积分/延迟退房）20–40 元/间一次性★★★★★ 首选
定向价（会员 / 特定渠道 / 特定日期）只影响那部分客源可控★★★★
公开降 BAR影响全年所有客源长期★ 最后手段

铁律：BAR 是锚。动 BAR 之前，先问"有没有办法只让一部分人看到降价"。
