Skill 2 · RevPAR 口算与差距定位

RevPAR 口算与差距定位 · 收益经理晨报

免费公域钩子
上架一句话
给我本店和市场的 OCC / ADR，立刻算出 RevPAR、MPI、ARI、量差价差，并说清差距到底来自「卖得少」还是「卖得便宜」。
触发词
RevPAR 怎么算 / MPI ARI 是什么 / 我们 RevPAR 比竞对低 / 是量的问题还是价的问题 / 量差价差 / 晨报 / 收益日报 / 竞对 ADR / 市场渗透率
执行流程
  1. 索取最少四项：本店 OCC、本店 ADR、市场 OCC、市场 ADR；可选项：房量、竞对集合、日期。
  2. 计算并展示：本店 RevPAR = OCC × ADR；市场 RevPAR；MPI = 本店 OCC / 市场 OCC；ARI = 本店 ADR / 市场 ADR；RGI = 本店 RevPAR / 市场 RevPAR。
  3. 做量价拆分：量差 =（本店 OCC − 市场 OCC）× 市场 ADR；价差 = 本店 OCC ×（本店 ADR − 市场 ADR）；两者之和约等于 RevPAR 差额。
  4. 定位主因：量差绝对值更大 → 「卖得少」，提示查表 D（MPI）与表 H（渠道）；价差更大 → 「卖得便宜」，提示查表 C（ARI）与表 A（价格）。
  5. 输出三行晨报：数字 → 主因 → 今天先查哪张表。
输出模板
本店 RevPAR ¥{…}（OCC {x}% × ADR ¥{…}）｜市场 ¥{…}
MPI {…} · ARI {…} · RGI {…}
差距 ¥{…} = 量差 ¥{…} + 价差 ¥{…}
主因：{卖得少 / 卖得便宜}
今天先查：表 {D/H 或 C/A} → {一句话动作}
提示：口径按月度累计或指定日期，两种不要混用；示意数据不作战绩。
落地页 / 依据
calc-center-v2.html（免登录可用）、diagnose.html（健康自检）。
不做：不把示例数字当真实业绩；不承诺「用了就涨 X%」；不替用户编造市场数据。
