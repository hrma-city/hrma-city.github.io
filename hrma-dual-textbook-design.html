双版教材设计 与 出版发行合规方案

学生版（含社会人士）+ 教师版 · 双轨发行是否可行 · 自己印会不会被出版社干涉

一、先回答核心疑问：自己印，出版社会不会干涉？

这个问题必须先讲清楚，否则后面全是空谈
⚠ 先把概念纠正：在中国，图书要公开定价销售，必须有 ISBN（中国标准书号）+ CIP 数据。这两样只能由出版社申办，个人或非出版单位不能直接申请。
所以严格意义上的"我自己印、我自己卖"——如果没有书号——属于非法出版物，有被查处风险。这条路不能走。

"自己印"实际可行的三种情形

情形做法能否公开销售判断
A 无书号自印直接找印刷厂印，自己卖✗ 不可（非法出版物）不做
B 自费出版 / 合作出版通过出版社拿 ISBN + CIP，自己承担印制费、自行发行✓ 可推荐，这就是"自己印"的正确形态
C 内部资料准印向地方新闻出版部门申请准印证✗ 只能内部使用，不得定价销售不适合（你要卖）
所以答案是：走 B（自费出版/合作出版），出版社不干涉你。
在这种模式下，出版社做的是审稿 + 申请书号 + 办理 CIP，收取管理费/书号费（市场常见约 ¥1–3 万，视出版社级别与流程）。之后：
· 内容：你的稿子，只要通过审稿（不涉及违禁内容），出版社不改你的专业内容
· 定价：你定（需备案）
· 印制：你找印刷厂、你出钱
· 发行：你卖，收入归你
出版社真正的约束不在日常，而在合同。

合同四条必须守住（比什么都重要）

条款要争取的写法不守住会怎样
专有出版权限定期限（建议 3–5 年）+ 范围（简体中文纸质），到期可续、可收回签了永久独家，你再也不能自印或换社
发行权明确保留作者自销权（自销、官网、训练营配套、院校直供）只能走社的渠道，你被迫让出 40% 折扣
数字版权 / 网络传播权保留（或明确授权范围）你的 PDF、网站、题库、AI 分身都不能发
配套资源归属课件 / 游戏 / 题库 / 网站归作者所有，不随书转让整个"教材为根"的生态被一并拿走
另外两条边界：
① "买卖书号"是违规的——出版社只卖号、不审稿、不做 CIP，属违规。你要走的是正规自费出版（有审稿、有 CIP），别图便宜买裸号。
② 单独销售 PDF 需电子书号。实务中，把 PDF 作为纸质书的配套资料/赠品随书提供，可规避独立电子出版物的要求；但不建议单独出售 PDF。
（以上为一般性行业规则，具体口径以出版社与当地新闻出版管理部门答复为准；签约前请出版社书面确认书号与 CIP 的办理责任与时限。）

二、双版设计：学生版 + 教师版

你说得对，主销是学生；两版分工明确
📘 学生版（主销量）
书名：《酒店收益管理：从原理到决策》
副标题：一本书读懂酒店怎么赚钱
读者：学生 + 社会人士（从业者入门 / 转行 / 自学者）
规格：16 开，约 300 页，¥49
核心要求：没有老师也能读懂——自学友好
📗 教师版（高毛利）
书名：《酒店收益管理：教学版》
副标题：高校教师开课手册（配套学生版使用）
读者：要开这门课的教师
规格：16 开，约 240 页，¥89
核心要求：严格对应学生版章节编号

学生版结构（32 章，每章 8–9 页）

每章固定模板：一句话承诺 → 你一定踩过的坑（场景） → 一张图 + 三要点 → 一个公式 + 算例 → 本章判定表 → 真实案例（脱敏） → 练习 3 题

自学友好设计（这是"社会人士也能看"的关键）：
· 导言写三条阅读路径：学生怎么读 / 自学者怎么读 / 从业者怎么读
· 每章加「自学者提示」：没有老师时，这一章怎么自己练
· 练习答案放书末（自学者需要对答案）
· 附录：判定表全集 15 张 / 自测题库索引 / 术语表 / 练习答案

教师版结构

第 0 章 · 这门课怎么开：4 种失败 / 16 周排法 / 32 公式教学排序 / 必讲与可不讲清单
32 章教学装（每章 4–5 页）：① 这章怎么讲（20 分钟讲法） ② 一个课堂活动（可投屏） ③ 学生最容易错的点 ④ 作业怎么出、怎么判（判定表用法）
附录：「1+3」评价量规 / 251 题题库索引（按章节）/ 12 游戏对照表 / 申报材料清单 6 项 / 课程思政 3 结合点
关键：每章开头标注「对应学生版第 X 章」
两 版 的 绑 定 关 系
· 学生版可独立使用（社会人士单买也成立）→ 走量
· 教师版不能独立使用（教学装处处指向学生版章节）→ 买教师版必然买学生版
· 训练营必配两本：学员拿学生版学内容、拿教师版学教法
→ 形成「教师版带动学生版」的自然搭售，而不是硬性捆绑

三、双轨发行：可行，且直销才是利润关键

"双轨"＝渠道发行（走量·曝光）+ 自销直销（利润）
轨对象结算价单册毛利作用
轨一 · 渠道发行院校集采、书店、馆配6 折 ¥29.4¥18走量、拿"被选用"的背书与曝光
轨二 · 自销直销训练营配套、官网、公众号、院校直供全价 ¥49（减物流 ¥6）¥32利润主力
轨二 · 院校直供批量 8 折¥39.2¥28批量走量且毛利仍高
关键洞察：直销毛利（¥32）是渠道发行（¥18）的 1.8 倍。
所以策略是——渠道发行只作为"被选用"的背书与曝光手段，利润尽量走直销。这正是合同里"保留自销权"那条如此重要的原因。

四、执行顺序（一次只做一件事）

步动作判据
① 立刻发《开课自检表》收邮箱邮箱数（唯一 KPI）
②先写学生版第 1–8 章（主销版本优先）约 2.5 万字
③拿 8 章稿同时谈 2–3 家出版社，比对合同四条拿到书面书号/CIP 承诺 + 保留自销权与配套资源归属
④学生版首印 2000–3000 册（自费出版）到货、可发
⑤教师版在学生版之后做（可直接由教学装汇编）240 页
⑥开内测训练营，两版作指定教材验证搭售与自然转化
护栏：① 先学生版后教师版——学生版是主销，且教师版可由教学装汇编，成本低很多。② 不要一次写完 32 章：写完 8 章就去谈社、去内测，其余边卖边写。③ 合同四条没谈妥前，不要签——尤其"自销权"和"配套资源归属"。
一句话回答你的两个问题：
双轨可行——渠道发行拿背书与曝光，自销直销拿利润（毛利高 1.8 倍），但前提是在合同里守住自销权。
自己印不会被干涉——但要走「自费出版/合作出版」（出版社出 ISBN + CIP，你出印制费、你发行）。出版社不碰你的内容和定价，真正的风险在合同四条：专有出版权期限、自销权、数字版权、配套资源归属。
现在唯一该做的：发自检表收邮箱。稿子可以边写边谈社，但邮箱现在就能攒。
