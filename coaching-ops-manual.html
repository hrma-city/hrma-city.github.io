教学陪跑工作手册（运营版）

给「你」用的实操地图：接一单 1对1 陪跑，从第一次触达到结项，每一步做什么、用什么材料、链接在哪。

一句话：你已有一整套可交付资产（教材全本、判定表、案例库、题库、在线工具、报价页），不用先出书也能开干。本手册是这些资产的使用说明书——按生命周期 5 阶段走，每步点对应的链接取材料。

一、陪跑生命周期（5 阶段总览）

从陌生人到结项复购，全程就这 5 步。阶段 0 是持续漏斗（不花钱的引流），阶段 1–4 是一单陪跑的闭环。

二、阶段 0 · 引流触达（持续做，不花钱）

漏斗

让老师先信你，再谈合作

  • 发方法文系列（占方法位，不比权威）：案例 → 考核 → 实训 → 复盘 → 自测，5 篇持续输出。
  • 每篇文末送《15 张判定表口袋本》PDF + 私域入口（微信 rm-community / 邮箱 rm-community@qq.com）——这是最证明"你真懂决策"的尖刀，老师愿意看、愿意转。
  • 有意向的老师自然走到 open-check 做自测，进入阶段 1。
用到的材料： 方法文系列索引 · 判定表口袋本 PDF

三、阶段 1 · 开课诊断（免费，建立专业感）

诊断

先看清他卡在哪一步

  • 把 open-check.html 链接发给对方，让他花 5 分钟自测（师资 / 课时 / 实训 / 组织 四维打分，三档结论）。
  • 他提交后出诊断报告；你据此做逐校定制诊断——这才是雇你的核心理由（书里故意留白的部分，这里你来填）。
  • 诊断完再谈合作，不急着报价。
用到的材料： 开课可行性自测 · 教师开课手册（看诊断维度对照）

四、阶段 2 · 转化签约

签约

只有一个真人产品：1对1 一学期

  • 主推 coaching-1on1.html：一学期 1对1 开课辅导 ¥5–10 万（轻量 5 / 标准 7–8 主推 / 专业建设级 10）。
  • 更大合作走 consulting.html：多学期堆叠 / 专业建设陪跑（按学期叠加，不做年度打包）。
  • 老师自己能推的，先给 开课即用包（自助无真人），推得动再上陪跑，费用可抵扣。
用到的材料： 1对1 学期陪跑报价页 · 咨询 / 多学期陪跑页 · 服务总台

五、阶段 3 · 交付 16 周（核心，四步）

对应 教师开课手册 的四模块。下面是你（教练）在每个窗口该做的动作 + 取材料的链接。

① 第 1–3 周 · 立起来

  • 对照诊断，定开课方案：用 whitepaper.html 定方向，按学分选 sl-teach-16/32/48.html 学时投屏课件。
  • 交付教材全本 + 投屏 + 教案：教材全本（41章） 、教师线开课教案 PDF 、M01–M14 教案（在线）。
  • 里程碑：大纲与课件通过评审（你出书面评审意见）。

② 第 4–8 周 · 讲起来

  • 案例进课堂：案例库（298 案例） + 案例解析 PDF，按方法文 02 讲法选带决策点的真案例。
  • 教师试讲：用 AI 教案校验器 逐次校验"判断点是否讲透"，给反馈。
  • 数据工坊首练：数据工坊 让教师用真实脱敏数据做第一次决策练习。
  • 里程碑：教师完成首次独立授课。

③ 第 9–14 周 · 稳下来

  • 题库与量规落地：题库 · 案例考核 · 情景题 · 补测（考判断不考背诵）。
  • 轻量实训：实训模板 xlsx（没系统也能练，见方法文 04）。
  • 游戏化巩固：课堂竞赛 / 游戏包。
  • 里程碑：考核数据可追溯、教学效果可复盘。

④ 第 15–16 周 · 拿出来

  • 课程标准、质量手册定稿；出结项报告（开了什么 / 学生学到什么 / 成果是什么）。
  • 用 试点校一页纸 模板整理对外可展示成果。
  • 里程碑：课程完整开出 + 结项报告。

六、阶段 4 · 结项与复购

复购

把一单做成长期关系

  • 结项报告里明确"下一学期还能叠什么"（多学期 / 专业建设方向），引导回到 consulting.html 做多学期堆叠。
  • 跑通 2–3 所陪跑校后，再把方法论升级成"带真实案例的书"——这时的书是实证，比纯理论书可信十倍。
  • 最后一英里（逐校定制诊断、试讲逐节评审、校内政治导航）永远只在 1对1 里教，不当成书卖。

八、一页纸 Checklist（接单 → 结项）

  • 发方法文 + 判定表口袋本，建私域（持续）
  • 意向老师 → 发 open-check 自测链接，收诊断
  • 出逐校定制诊断（书里留白的部分你填）
  • 推 coaching-1on1（标准 7–8 万主推）；更大合作走 consulting
  • 第 1–3 周：whitepaper 定方案 → 交教材全本+投屏+教案 → 大纲过审
  • 第 4–8 周：案例进课堂 + ai-verifier 校验试讲 + 数据工坊首练 → 教师首讲
  • 第 9–14 周：题库量规 + 实训模板 + 游戏巩固 → 数据可追溯
  • 第 15–16 周：结项报告 + 试点校一页纸 → 课程完整开出
  • 结项引导多学期堆叠 / 专业建设方向（回 consulting）
书 vs 1对1 边界（别搞反）：
写进书/在线资料（一对多、可自学）：完整知识体系、判定表、脱敏案例、自诊工具、考核量规、"好是什么样"。
只在 1对1 里教（定制、现场、你的判断）：逐校诊断、试讲逐节评审、校内政治导航、第 3 周卡住的实时救火、正在跑的陪跑校实况。
书是地图+工具+好样板，1对1 是陪你走具体地形的人。把定制诊断写进书＝自断雇你的理由。
