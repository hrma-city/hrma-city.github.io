滚动训练营讲义（8 份 · 8 周）

一期 8 周：基础 6 单元 + 团队与客源细分（U7）、系统与协同（U8）两个进阶单元。每周一次 90 分钟线上研讨。

每周一份现成脚本：流程、讲解要点、互看作业看什么、高频问题怎么答、本周依据、会后动作。照着走，不备课也能带完一期。

使用方式：会前把这周讲义打开 → 按流程走 → 会后动作写进群公告。批改只批两处（依据选对没有、交付物齐不齐），不批文采——这是你时间不崩的唯一办法。
第 1 周　定你的课：学时、口径、学生画像

本周目标：把"我这学期到底要上什么"说清楚，并把口径卡建起来。

研讨流程（90 分钟）

环节时长做什么
开场5 分钟本周目标一句话 + 上周作业一句话点评
讲解25 分钟按下方"讲解要点"讲，不展开、不发散
互看作业40 分钟两人一组按"互看作业看什么"互评，用三句话给反馈：做对了什么 / 缺什么 / 下一步怎么补
答疑20 分钟按下方高频问题优先答；答不了的记进清单，下周集中回

讲解要点（可直接念）

  1. 先问三个问题：多少学时？学生什么基础？学校要什么交付物（大纲/考核/作品）？
  2. 标准课是 8 个单元：基础 6 单元 + 团队与客源细分、系统与协同两个进阶单元，每单元 6 学时（讲 3 + 实训 3）；课时排不进就用 36 学时免费版——不要按比例砍，按闭环选。
  3. 口径卡四件事：房量结构、客源结构、变动成本、竞组名单。口径一致比数据真实更重要。
  4. 学生画像先做一个假设：多数是零基础 + 没进过酒店。按这个假设备课，第一课上完再修正。

互看作业看什么

看三件事：学时填了没有、口径卡四项齐不齐、缺口清单有没有写具体（不是"缺数据"而是"缺 90 天日度数据"）。

高频问题怎么答

问：课时只有 16 怎么办？
答：按"指标→预测→调价→复盘"一条闭环选：做一次决定 + 三个指标 + 算打平量 + 汇报。其余作为作业包发下去。

问：学校已有教材，能不能不用你的？
答：能。用你校教材讲概念，用标准课的"开场问题 + 课堂动作 + 作业"套上去——脚本比教材重要。

问：数据用云璟还是真实酒店？
答：第一次开课用云璟（口径与教材一致、答案可核对）；有合作酒店再换，且必须自己先算一遍答案。

本周依据：标准课逐课脚本

会后动作：把工作台的口径卡填完，下次研讨前交《开课缺口清单》。

第 2 周　把标准课装进你的学期

本周目标：完成学期课表，并把学生版答疑页发下去。

研讨流程（90 分钟）

环节时长做什么
开场5 分钟本周目标一句话 + 上周作业一句话点评
讲解25 分钟按下方"讲解要点"讲，不展开、不发散
互看作业40 分钟两人一组按"互看作业看什么"互评，用三句话给反馈：做对了什么 / 缺什么 / 下一步怎么补
答疑20 分钟按下方高频问题优先答；答不了的记进清单，下周集中回

讲解要点（可直接念）

  1. 排课原则：每周一次课，第 3 周起按脚本走，中间留一次弹性周（补课或项目）。
  2. 数据就位：把云璟 90 天数据发给学生，第一次课就让他们手上有数。
  3. 答疑页发布：用工作台生成的"学生版答疑页"，开学第一周发到班级群，减少后面八成的重复提问。
  4. 作业提前公布：把 6 个单元的作业一次发下去，让学生知道终点在哪。

互看作业看什么

看两件事：课表是否覆盖完整闭环（指标→预测→价格→库存→渠道→竞争→汇报）；答疑页是否发了、FAQ 有没有你自己课程的具体信息。

高频问题怎么答

问：学生不看答疑页怎么办？
答：在第一次课上用 5 分钟现场演示一次提问；把它写进第一次作业（"用分身查一个问题并截图"）。

问：课时被学校压缩了？
答：降档不砍闭环：完整班是 8 个单元；实在排不进就先用 36 学时免费版，课时够再升到训练营。

问：课件要不要自己做？
答：第一学期不要。用现成投屏课件，把省下的时间全部投给学生作业批改。

本周依据：开课工作台

会后动作：交学期课表（含每次课动作与作业）+ 答疑页发布截图。

第 3 周　第一次上课：开场与查表（单元 1–2）

本周目标：把第 1 单元上下来，并拿到学生的真实卡点。

研讨流程（90 分钟）

环节时长做什么
开场5 分钟本周目标一句话 + 上周作业一句话点评
讲解25 分钟按下方"讲解要点"讲，不展开、不发散
互看作业40 分钟两人一组按"互看作业看什么"互评，用三句话给反馈：做对了什么 / 缺什么 / 下一步怎么补
答疑20 分钟按下方高频问题优先答；答不了的记进清单，下周集中回

讲解要点（可直接念）

  1. 开场三句：抛场景（周三 OCC62%、Pickup 落后 12%）→ 全班投票 → 带他们查表找唯一答案。
  2. 顺序不能改：先有立场，再被数据说服。直接讲结论等于把案例用成了例子。
  3. 查表教学：横行＝预测出租率，纵列＝进度偏差，交叉处＝当天动作。让学生念出来。
  4. 被问倒时：当着全班查判定表。学生记住的是"老师怎么处理不会"，不是"老师什么都会"。

互看作业看什么

看实录（或记录）：开场有没有投票、学生有没有真的查表、教师有没有替学生说出答案。

高频问题怎么答

问：学生一开始就问"答案是几"？
答：不急着给：先让他定位行列，再让他自己读格子。

问：投票一边倒怎么办？
答：更好。让少数派讲理由，再查表——冲突是最强的记忆点。

问：一个单元没上完预设内容？
答：正常。第一次课宁可只上"查一次表"，也不要赶进度。

本周依据：每日操作流水线（表 A）

会后动作：交第 1 单元实录 + 学生卡点记录（至少 3 条具体卡在哪一行哪一列）。

第 4 周　单元 3–4：价格与库存两课怎么讲不翻车

本周目标：把"降不降"和"超不超"变成两道算术题。

研讨流程（90 分钟）

环节时长做什么
开场5 分钟本周目标一句话 + 上周作业一句话点评
讲解25 分钟按下方"讲解要点"讲，不展开、不发散
互看作业40 分钟两人一组按"互看作业看什么"互评，用三句话给反馈：做对了什么 / 缺什么 / 下一步怎么补
答疑20 分钟按下方高频问题优先答；答不了的记进清单，下周集中回

讲解要点（可直接念）

  1. 打平量 = 降价损失 ÷ 单间边际贡献（分母是边际贡献不是卖价）。把争论变成算式。
  2. 比"直降"更好的做法：打包（含早 / 延迟退房）留出比价空间，不破价格锚点。
  3. 超售三步：基准取消率 → 连乘修正系数 → 换算间数并过硬上限。硬上限是红线不是建议。
  4. 免费升级排序：会员等级 → 连住天数 → 房态余量 → 到店顺序。规则不清的善意最后都变矛盾。

互看作业看什么

看教案：打平量有没有给算式与数字；超售有没有写硬上限；升级有没有写排序规则。

高频问题怎么答

问：学生问"多卖几间怕什么"？
答：用 walk 的代价回答：省下的是一间房费，赔上的是客户终身价值与评分。

问：打平量算出来"不划算"，但总经理要降价？
答：这就是 U6 汇报单元的内容：给替代方案 + 留痕执行。可以提前讲一句。

问：库存这课太抽象？
答：用满房日"先关谁"的排序练习带，比讲定义管用十倍。

本周依据：价格体系设计

会后动作：交第 4、5 课教案定稿 + 课堂练习答案。

第 5 周　单元 5：渠道与竞争 + 进阶铺垫

本周目标：让学生学会比"净的"，并学会先判断对手配不配。

研讨流程（90 分钟）

环节时长做什么
开场5 分钟本周目标一句话 + 上周作业一句话点评
讲解25 分钟按下方"讲解要点"讲，不展开、不发散
互看作业40 分钟两人一组按"互看作业看什么"互评，用三句话给反馈：做对了什么 / 缺什么 / 下一步怎么补
答疑20 分钟按下方高频问题优先答；答不了的记进清单，下周集中回

讲解要点（可直接念）

  1. 净收入 = 卖价 × (1 − 渠道成本率)。同价不同渠道差很多——把扣点摆出来让他们自己算。
  2. 价格一致性红线：同房型同日期各渠道价格一致，每天核查。倒挂不是价格问题，是流程问题。
  3. 竞组三个"同"：同档次、同商圈、同客源。缺一个就不可比——竞组选错，后面全错。
  4. 跟价三步：先验真伪（在手与限制条件），再定幅度（小步），最后设观察期（阀门）。

互看作业看什么

看教案：有没有净收入对比表；竞组名单是否标注了"为什么可比"；跟价有没有写观察期。

高频问题怎么答

问："竞对都降了我们也降"怎么破？
答：用三个"同"把"竞对"定义清楚，再用 MPI/ARI/RGI 判断位置——是抢不到人还是卖不到价。

问：学生觉得渠道内容离自己远？
答：让他当场查三个渠道的同房型价格，找倒挂。

问：要不要关 OTA 提直销？
答：不靠硬压。靠会员价、打包、权益做产品差异，把官网修成"另一个 OTA"才是压直销的真凶。

本周依据：渠道与分销管理

会后动作：交第 6、7 课教案定稿 + 渠道排序练习的讲解要点。

第 6 周　进阶 U7：团队与客源细分（完整实训）

本周目标：把客源细分讲成"先服务谁"的分配依据。

研讨流程（90 分钟）

环节时长做什么
开场5 分钟本周目标一句话 + 上周作业一句话点评
讲解25 分钟按下方"讲解要点"讲，不展开、不发散
互看作业40 分钟两人一组按"互看作业看什么"互评，用三句话给反馈：做对了什么 / 缺什么 / 下一步怎么补
答疑20 分钟按下方高频问题优先答；答不了的记进清单，下周集中回

讲解要点（可直接念）

  1. 客源细分五类：商务散客 / 会议 / OTA / 协议 / 会员，各有价值与成本
  2. 总贡献＝房价 + 餐饮 + 会议室，与置换成本比较
  3. 团队谈判：用条件换价格（取消条款、餐饮保底），不硬接也不硬拒

互看作业看什么

看取舍方案：是否算了总贡献；条件是否具体到条款。

高频问题怎么答

问：老客户压价要不要让？
答：让可以，但要换东西（量承诺、附加消费、取消条款）——只谈价格不谈条件，永远被动。

问：团队占比多少合适？
答：看置换成本，不看固定比例；周末高价值日收紧，淡日可放宽。

本周依据：客源细分战略

会后动作：交团队取舍方案（含条件与审批留痕）。

第 7 周　进阶 U8：系统与协同（含考核落地）

本周目标：让系统与协同成为工具，并把考核一次定下来。

研讨流程（90 分钟）

环节时长做什么
开场5 分钟本周目标一句话 + 上周作业一句话点评
讲解25 分钟按下方"讲解要点"讲，不展开、不发散
互看作业40 分钟两人一组按"互看作业看什么"互评，用三句话给反馈：做对了什么 / 缺什么 / 下一步怎么补
答疑20 分钟按下方高频问题优先答；答不了的记进清单，下周集中回

讲解要点（可直接念）

  1. 观察期：偏离 ±15% 内交给系统，超出人工复核；偏差记录攒够样本再调参，别每周改
  2. 跨部门协同：冲突用规则裁，不用权力裁；裁决必须留痕，下次就有先例
  3. 权重 30/50/20（过程 / 诊断报告 / 5 分钟汇报），开学第一周就公开
  4. 组卷按判定表映射、每张表至少 2 题；量规只看依据正确性、留痕完整性、经营解释、可执行性

互看作业看什么

看三份件：复核区间是否合理；仲裁记录是否含依据与留痕；考核方案是否含权重、量规与组卷映射。

高频问题怎么答

问：系统老是不准，要不要换？
答：先分清是参数没校准还是模型不适用——换供应商解决不了没校准的参数。

问：销售不听怎么办？
答：把规则与总贡献摆出来，用规则裁而不是用权力压；裁完留痕。

问：学生说分给低了？
答：把量规拿出来对条目。量规的价值不是替代判断，是把"好不好"拆成学生看得懂的维度。

问：作业太多改不完？
答：第一次全批立规矩，之后分组抽批 1/3，期末全批；再引入同桌互评。

本周依据：收益管理系统与自动化

会后动作：交系统复核区间设定 + 一次协同仲裁记录 + 可直接用的考核方案。

第 8 周　结营：交出一套能带走的课

本周目标：把你校版标准课整理成型，并把学生问题喂回分身。

研讨流程（90 分钟）

环节时长做什么
开场5 分钟本周目标一句话 + 上周作业一句话点评
讲解25 分钟按下方"讲解要点"讲，不展开、不发散

答疑20 分钟按下方高频问题优先答；答不了的记进清单，下周集中回

讲解要点（可直接念）

  1. 把 6 个单元教案整理成你校版本：改掉的、保留的、下届要调的各写一条。
  2. 把学生真问过的问题喂回工作台 FAQ，并按提问频次重排顺序——这就是下届最好的教案。
  3. 结营汇报：我这学期改了什么——结论先行，按"结论→结果→原因→风险→动作→需要的决定"六板块，一页纸 300 字也行。
  4. 进入教师同行社群：联合备课、互相看大纲、共享样卷。

互看作业看什么

看结营包：你校版课表、考核方案、FAQ 更新记录、结营复盘一页纸。

高频问题怎么答

问：还有没讲完的内容？
答：正常。记进"下届要调"，一学期只改三处——改多了等于没改。

问：下届想做校本化？
答：那是下一期滚动训练营的事。先保证第二届能稳定上完。

问：怎么把这门课变成你的资产？
答：连续三届的迭代记录 + 学生作品，就是你的方法论与对外发声的底气。

本周依据：开课工作台

会后动作：交你校版标准课包（教案 + 考核 + FAQ）+ 结营复盘一页纸。

贯穿整期的三条纪律

  1. 作业必须交：连续两次不交，暂停辅导（不是惩罚，是保护你的批改时间）。
  2. 答疑走提问板：私信一律转过去，回答沉淀下来，下届还能用。
  3. 同期不开第二个班：一期 20 人是上限，超了就开下一期。
