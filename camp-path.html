转岗路径怎么走

多数人不是一步登天，是在现有岗位上先"兼"再"专"。

  1. 在现岗位先兼一块：向前台/预订主管申请负责"每日比价"或"日报填报"，把 L1 练扎实。
  2. 用交付物说话：连续 4 周交出可查的日报与比价表，这是您转岗的简历。
  3. 争取一次独立决策：主动请缨做一次调价建议并被采纳——从 L1 跨到 L2 的标志。
  4. 拿下 L2 认证再谈转岗：认证是把"我能做"变成"市场认"的凭证。
  5. 补 L3 三件事：价格体系、置换谈判、月度计划——这三件是经理岗的分水岭。
