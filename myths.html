误区 01指标
❌入住率越高越好，先把房间卖满再说。
✅目标是 RevPAR（每可售房收入）最大，不是入住率最高。用低价换来的高入住会把 ADR 拉下去，RevPAR 反而更低。
🔢 100 间房两种卖法：A 卖 90 间 @¥300 → RevPAR = 90×300÷100 = ¥270；B 卖 70 间 @¥420 → RevPAR = ¥294。B 少卖 20 间，收入反而多 ¥2,400/天，还省下 20 间的清洁、布草与早餐成本。
🎯 怎么做：每天同时看 ADR 与 OCC 的组合，别单看 OCC；跟竞组比用 MPI，跟自己比只看趋势。

误区 02指标
❌平均房价（ADR）涨了，就是收益管理做得好。
✅ADR 涨了要连带看入住率：涨价后入住率跌太多，RevPAR 一样会掉。判断标准是 RevPAR，不是 ADR。
🔢 ADR 从 ¥500 涨到 ¥550（+10%），入住率从 70% 跌到 63.6% 时 RevPAR 刚好打平（500×70% = 350，550×63.6% ≈ 350）。也就是说：涨价 10%，入住率的相对跌幅不能超过 9.1%（70% → 不能低于 63.6%）。
🎯 怎么做：每次调价都记录 ADR 与 OCC 的联动，算自己的价格弹性；涨完看 7 天 pickup 有没有掉速。

误区 03指标
❌降价 10%，多卖 10% 就能打平。
✅错。打平需要的量增是 1÷(1−降幅) − 1：降 10% 需要量增 11.1%，降 20% 需要量增 25%，降 30% 需要量增 42.9%。降得越多越难打平。
🔢 当前入住率 80%、ADR ¥500：降 10% 到 ¥450，RevPAR 打平需要 OCC 到 80%×1.111 = 88.9%（+8.9pp）。如果当前只有 60%，则要到 66.7%（+6.7pp）。旺季基数越高，靠降价打平越难。
🎯 怎么做：降价前先算「打平量」：打平量 = 现量 ÷ (1−降幅)。再问自己：这个增量从哪来？如果答不上来就别降。

误区 04指标
❌RevPAR 涨了，就是赚钱了。
✅RevPAR 只看客房收入，不看获得这些收入花了多少分销成本与运营成本。要同时看 NRevPAR（扣渠道成本）和 GOPPAR（扣经营成本）。
🔢 RevPAR +8%，但 OTA 占比从 25% 升到 45%，佣金 15%：多出来的 20pp 房量要多付 20%×ADR×15% 的佣金，若再叠加免费升级与双早，NRevPAR 与 GOPPAR 可能不升反降。
🎯 怎么做：月度复盘用三个口径一起看：RevPAR（规模）、NRevPAR（净收入）、GOPPAR（利润）。渠道结构变化要单列一栏。

误区 05指标
❌当天满房，就是最优结果。
✅满房太早说明价格定低了：后面来的高价需求会被拒。最优是「最后一件库存以边际收益最高的价格卖出」，而不是最早卖完。
🔢 提前 14 天就满房，之后 7 天有 30 个询价被拒（均价 ¥700），而早卖出去的均价只有 ¥480 → 少赚 30 × (700−480) = ¥6,600。
🎯 怎么做：满房日要做的是抬 BAR、加 MinLOS、关低价渠道，而不是庆祝。看 booked pace 判断「是不是卖太快」。

误区 06指标
❌RGI 大于 100，就是赢了对手。
✅RGI = MPI × ARI ÷ 100，同样的 RGI 可能来自完全不同的结构：靠量赢（价在输）还是靠价赢（份额在丢），下一步动作完全相反。
🔢 RGI 都是 105：甲店 MPI 115 / ARI 91（卖得比对手便宜换来的量，利润薄）；乙店 MPI 92 / ARI 114（卖得贵但份额在丢，长期危险）。
🎯 怎么做：三个指数一起看：ARI 低 → 做价格与产品差异；MPI 低 → 做渠道曝光与客群；两个都低才是真落后。

误区 07指标
❌对手满房了，我也该跟着涨价。
✅竞组满房只说明市场强，不代表你的客群会接受这个价。决策依据是自己手上的 OTB 与 pickup 速度，竞品价格只用来定「相对位置」。
🔢 竞组满房但你自己的 OTB 比去年同期低 15%，此时跟涨 10% → pickup 更慢，最后 3 天被迫降价，白折腾一轮。
🎯 怎么做：先查自己 OTB 与去年同期比、再看 pickup 曲线斜率，最后用 ARI 决定你相对竞组站哪个位置。

误区 08定价
❌定价就是成本加成，成本多少加多少利润。
✅价格由需求与支付意愿决定，成本只决定下限（保本价）。用成本加成定价，等于把客人愿意多付的部分白送出去。
🔢 一间房的变动成本 ¥120，按成本加成 50% 定 ¥180；但当天市场需求能接受 ¥380 → 每间白丢 ¥200，100 间就是 ¥20,000。
🎯 怎么做：成本用来算「最低可接受价」（淡季保本线）；实际挂牌价由需求预测、竞组定位与价格弹性决定。

误区 09定价
❌统一价最公平，也最好管理。
✅单一价格会把低价卖给愿意付高价的人，白白流失消费者剩余。正确做法是 BAR + 栅栏（fence）：用条件把不同支付意愿的客人分开。
🔢 100 位客人里 30 位愿付 ¥800、70 位只愿付 ¥400。统一定 ¥400 → 收入 ¥40,000；用栅栏分成 ¥400（提前 21 天/不可取消）与 ¥800 两档 → 70×400 + 30×800 = ¥52,000，多 30%。
🎯 怎么做：设计 3–5 个价格档，每档配明确栅栏条件（提前期、取消政策、会员身份、渠道封闭）；栅栏要能「防下移」。

误区 10定价
❌周末一定要涨价。
✅商务酒店周末需求反而低，应该降价；度假与景区相反。定价看的是自己的历史需求曲线，不是日历上的周末。
🔢 某商务酒店周五/周六常年 OCC 45%、ADR ¥500，强行周末涨价 10% → OCC 掉到 38%：RevPAR 从 0.45×500 = ¥225 掉到 0.38×550 = ¥209。
🎯 怎么做：按「星期模式 × 季节 × 事件」建立双维日历，并分细分市场定价（商务客周末不来，家庭客工作日不来）。

误区 11定价
❌提前订一定便宜，越早越便宜就对了。
✅早鸟价是「需求不确定时锁定基数」的工具，不是固定规则。如果 OTB 已经超预期，就该及时收窄甚至关闭早鸟。
🔢 展会日提前 30 天放 8 折，10 天后 OTB 已超去年同期 40% → 后 20 天少赚一大截。正确做法：早鸟限量 + 设触发线（OTB 超去年 X% 即关档）。
🎯 怎么做：早鸟设「限量 + 截止日」双约束，并绑定触发规则；每天看 OTB 与去年对比，超线就抬 BAR。

误区 12定价
❌涨价一定会得罪客人。
✅客人抗拒的是「没有理由的涨价」，不是价格本身。涨幅超过竞组 ARI 110 又没有任何附加价值时，才会明显伤转化与口碑。
🔢 同样涨 10%，一档裸涨、一档带「含双早 + 延迟退房 + 积分翻倍」，后者的投诉率与退订率明显更低，实际净 ADR 反而更高。
🎯 怎么做：涨价必配「价值锚 + 一句话理由」（展会/旺季/活动），给老客户 7 天缓冲期，别一次性跳档。

误区 13定价
❌收益管理就是最后一刻甩卖。
✅甩卖是前期没调好的补救措施。80% 的收益动作应该发生在到店前 30 天到 7 天之间，最后 3 天降价通常已经晚了。

🎯 怎么做：建立 T-30 / T-14 / T-7 / T-3 / T-0 五个检查点，每个点都有固定的动作清单。

误区 14库存
❌有房就卖，空着也是空着。
✅短住低价订单会占用库存，挤掉后面来的长住高价需求。库存要给「总收益最高」的订单，不是给「先来的」订单。
🔢 周五只放 1 晚，10 间被 1 晚订单占满；结果 8 个「周五 + 周六」2 晚 ¥700/晚 的询价被拒 → 损失 8×2 = 16 个高价间夜。
🎯 怎么做：高需求日设 MinLOS 2–3 晚；先保护长住与高价需求，有余量再放短住。

误区 15库存
❌超售是不道德的，甚至违规。
✅超售是对 no-show 与取消的统计对冲，本身是行业标准做法。关键在于「算清上限 + 有 walk 处理流程」。
🔢 历史 no-show 8% + 取消 7% = 15%，200 间满房日可合理多接 200×15%×0.6 ≈ 18 间；若没有 walk 预案，硬拒客人的成本是房费的 2–3 倍（房差 + 交通 + 补偿）再加差评。
🎯 怎么做：用超售测算工具定上限，同时准备 walk 预案：付费升级 → 同级酒店 + 交通 → 补偿标准，并授权前厅当场决策。

误区 16库存
❌超售越多赚得越多。
✅期望收益先升后降：多超售带来的增量房费是线性的，但 walk 成本（房差 + 交通 + 补偿 + 客户流失）增长更快，越过某点就亏。
🔢 多超售 5 间，增量收入约 5 × ¥500 = ¥2,500；但多 walk 1 人的成本常在 ¥1,500–3,000，还不算 NPS 与复购损失。
🎯 怎么做：上限取 min(统计余量 × 风险偏好, 房量 × 硬上限%)，并按月回测实际 no-show 与取消率，动态修正。

误区 17库存
❌团队单量大，就应该接。
✅接不接看净贡献：团队带来的收益，必须大于被它挤掉的散客收益。量大不等于赚钱。
🔢 团队 80 间 @¥400 净价 = ¥32,000；被挤掉的散客 60 间 @¥600 的边际收益 ¥36,000 → 净贡献 −¥4,000，不该接（除非餐饮/会议室贡献能把净额转正）。
🎯 怎么做：用置换分析：净贡献 = 团队总贡献 − 被挤掉散客贡献，>0 才接；同时加「最晚确认日」与切房条款。

误区 19渠道
❌OTA 佣金那么高，关掉算了。
✅OTA 有增量需求与广告（billboard）效应。要管的是「占比与净收益」，一刀切关掉常常是丢掉增量而不是转移需求。
🔢 OTA 100 间 @¥600、佣金 15% → 净 ¥51,000；关掉后只有 30 间回流到直订 @¥560 = ¥16,800，其余 70 间需求直接消失 → 净收入大幅下降。
🎯 怎么做：先分清「增量」与「转移」：把该渠道关 3 天做 A/B，看总 OTB 掉多少。管理手段用「占比上限 + 高需求日关低价渠道」。

误区 20渠道

误区 21渠道
❌所有渠道必须同价，不然违反价格一致性。
✅价格一致性（Rate Parity）约束的是公开渠道价格；会员价、打包价、积分兑换属于封闭式差异，通常是被允许的。
🔢 公开渠道放 ¥80 的低价会触发 parity 条款并引来竞品跟进；改为「会员专享 + 含早 + 积分」的同额优惠，价格体系不受影响。
🎯 怎么做：差异放在权益与包装上（会员、含早、取消灵活、附加服务），不要放在公开 BAR 上。

误区 22渠道
❌哪个渠道便宜就用哪个。
✅渠道要看「净 ADR × 成交质量」：取消率、No-show 率、附加消费都会改变最终结果，便宜的渠道可能更贵。
🔢 A 渠道净 ADR ¥480 但取消率 25%；B 渠道净 ADR ¥450 但取消率 5%。按期望值算：480×0.75 = 360 < 450×0.95 = 427.5，B 更好。
🎯 怎么做：渠道评估用「净 ADR × (1−取消率) + 附加消费」排序，并区分增量与转移。

误区 24预测

误区 26预测
❌用平均值做预测就够了。
✅均值会低估旺季、高估淡季。关键日期要用区间与分位数（P20 / P50 / P80），并给不同分位配不同动作。
🔢 某日需求均值 120 间，但实际分布在 80–160 之间：按 120 备，一半时间缺房、一半时间空房。高价值日按 P80（约 145）备更稳。
🎯 怎么做：关键日用区间预测：P80 用于备货与人员，P50 用于定价基准，P20 用于最保守的现金规划。

误区 29组织
❌收益管理就是涨价。
✅收益管理是「在合适的时间、通过合适的渠道、向合适的客群、以合适的价格卖出合适的库存」，很多时候是降价、关档或拒绝订单。
🔢 淡季正确动作常常是保价 + 收窄折扣 + 做套餐，而不是降价；旺季正确动作是抬价 + 加 MinLOS + 关低价渠道。
🎯 怎么做：每次动作前对照五要素自查：时间、客群、渠道、价格、库存，缺一项就说明还没想清楚。

误区 30跨行业
❌收益管理只适用于酒店和航空。
✅只要满足「固定且易逝的库存 + 需求可分段 + 可提前预订 + 成本相对刚性」，收益管理就成立，跟行业无关。
🔢 餐饮：翻台率=OCC、客单价=ADR → RevPASH；医疗号源：RevPAA；租车：RevPAT；研学营地：RevPAS；邮轮：RevPAC。公式结构完全一致。
🎯 怎么做：迁移方法：先定义「可卖单元 × 统计周期」，再套用「收入 ÷ 可用单元」与「利用率 × 单价」两个骨架公式。
