收益管理赛事标准共建试点合作备忘录（MOU）

本模板为框架性约定，供甲乙双方（试点院校与 RMC）填写并签署。正式生效以双方盖章签字件为准；灰色虚线框为待填项。

口径声明（2026-11-04 统一修订）：本页出现的 L1/L2/L3 是 RMC 自建能力等级；「证书 / 发证 / 证书线」均指校本达标证明及其能力刻度，不是 1+X 酒店收益管理职业技能等级证书（北京三快在线科技 / 美团颁证，标准代码 540002），也不等同其初 / 中 / 高级。学分认定、1+X 与学分银行换算一律为拟对接，以本校教务部门与 1+X 考核站点正式认定为准。详见 统一口径说明 与 1+X 逐条映射大表。

二、合作目标

双方共同推动"收益管理赛事标准"在院校落地：① 以乙方 46 章教材与 L1 校赛达标包为底座，在甲方开设收益管理相关课程；② 于试点期内共同办成至少 【1】 场校级赛事；③ 验证赛项规程、判分引擎与达标评价标准的可复制性，形成可推广样板。

三、合作内容

乙方（RMC）提供甲方（院校）提供
46 章收益管理教材（赛训衔接指南）排定课表、指定任课教师、组织学生
L1 校赛达标包：赛项规程 + 判分引擎 + 编排台发布报名、组织现场联网、监督纪律
L1 达标标准与电子证明出具确认拟对接教务 / 1+X 路径（以本校认定为准）
试点期产品迭代与优先支持反馈教学痛点与赛项体验

四、试点期限与名额

期限：自 【____年__月__日】 起至 【____年__月__日】 止（约一个学期），跑通至少一场校赛。
名额：本批次共建院校不超过 5 家，甲方为其中之一。

五、费用与结算

免费项：试点期内 L1 校赛达标包（教材+赛项+判分+编排台）订阅费全免；首场校赛平台与判分服务免费。
成本项：仅下列按实结算——证明制作 / 电子证明出具成本、1+X 或学分银行对接产生的第三方费用。
结算方式：【按实发生，赛后__日内对账结清 / 其他____】。

六、知识产权与数据归属

教材版权：乙方教材著作权归乙方所有，甲方在试点期内获教学使用授权，不得外传或商用。
赛项成绩：参赛学生成绩与排名归甲方与学生本人所有，乙方仅用于匿名教研改进与标准迭代。
不锁数据：甲方可随时导出全部成绩数据（CSV），乙方不得设置导出障碍或以数据绑定续约。

七、达标证明与学分拟对接

L1 准入线：A 类（A1–A4）每项正确率 ≥ 70% 且至少 1 项决策类（B1/B2/B4）综合 ≥ 60；达线出具 L1 初级达标证明。决策类综合 ≥ 80 记录 L2 潜力。
L1 达标可作为"收益管理实务"课程模块的过程性评价佐证；与 1+X 初级考核的能力范围已逐条对标，是否换算由考核站点认定。具体拟对接路径由甲方教务确认：【对接方式____】。

八、双方权利与义务

甲方乙方 按排定课表开课，保障学生参赛覆盖保障平台稳定运行与判分准确 维护赛场纪律与身份核验提供赛项答疑与组织者培训 作为"标准首批共建院校"配合必要宣传授予共建署名并在标准文档/官网标注

九、保密

双方在合作中知悉的对方非公开信息（含教材细节、内部数据、商业安排）应予保密，未经书面同意不得向第三方披露。本条款在合作终止后 【2】 年内持续有效。

十、退出与终止

甲方可于提前 【15】 日书面通知后随时退出试点，无需承担违约责。
合作终止后，已出具的达标证明长期有效，不影响学生权益；甲方已导出数据不受影响。
任一方严重违约经催告未改正的，守约方有权终止本备忘录。

十一、争议解决

因本备忘录产生的争议，双方友好协商；协商不成的，提交 【甲方所在地 / 乙方所在地】 有管辖权的人民法院诉讼解决。

十二、生效与签署

本备忘录一式 【两】 份，双方各执 【一】 份，自双方签字盖章之日起生效。未尽事宜可签补充协议，与本备忘录同等效力。
