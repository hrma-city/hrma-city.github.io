B1 动态定价决策 · 正式赛项：登录 / 编排 / 证书

在 最小可跑原型 之上，补齐赛事产品三件套：① 登录（站点门 + 参赛者身份采集）；② 赛制编排（组织者设名称/级别/评分权重/证书线）；③ 达标证明对接（完赛按阈值出具 L1/L2/L3 能力等级卡、入本地排行榜、可导出成绩表）。这是赛事引擎可端到端运行的招牌赛项。

① 门登录已通过本站登录门；下方采集参赛者身份
② 编排组织者设定赛项参数与证书线
③ 比赛14 天逐日定价，系统机评
④ 达标证明按阈值出具能力等级，入榜可导出
口径声明（2026-11-04 统一修订）：本页出现的 L1/L2/L3 是 RMC 自建能力等级；「证书 / 发证 / 证书线」均指校本达标证明及其能力刻度，不是 1+X 酒店收益管理职业技能等级证书（北京三快在线科技 / 美团颁证，标准代码 540002），也不等同其初 / 中 / 高级。学分认定、1+X 与学分银行换算一律为拟对接，以本校教务部门与 1+X 考核站点正式认定为准。详见 统一口径说明 与 1+X 逐条映射大表。

三、达标证明怎么对接（给院校）

完赛综合得分 ≥ L1 线即出具 L1 初级 达标证明；≥ L2 / L3 线对应升级。能力等级与 课赛证映射大表 的 L1/L2/L3 一致，能力范围已逐条对标 1+X（见 映射大表）；学分认定与 1+X 换算均为拟对接，以本校教务与考核站点认定为准。本原型在浏览器内生成证书卡并保存成绩；正式部署时，证书签发与成绩入库由赛事引擎后端 + 贵校教务系统完成——本页即"接口规范"演示。
