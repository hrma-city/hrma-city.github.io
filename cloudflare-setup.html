方案：Cloudflare Pages 托管 + Cloudflare Access 登录 · 全程免费 · 第一次做请预留 30–60 分钟（含注册账号与邮箱验证）· 我已把坑填好，分 3 段做完
先把话说在前面，别指望 15 分钟就搞定。
· 我不能保证一次成功。Cloudflare 的界面每年都在改，如果某一步的名字对不上，说明是我这份手册过时了，不是您的问题。

· 真正省时间的地方：我已经把文件都备好了，您只是照着点，不用配置任何代码。
为什么必须这么做。现在这个站是 GitHub Pages，纯静态、无服务器。挂在页面上的 JavaScript 访问门只能管「页面」，管不到 xxx.zip / xxx.pdf / xxx.xlsx 这类文件的直连下载——知道链接的人一样能拉走。 Cloudflare Access 是服务端拦截：请求还没到文件就被挡住，连文件都不存在。这是免费方案里唯一能真锁住文件的办法。
做之前先知道两件事。
① Cloudflare 是境外服务，pages.dev 在国内访问可能比现在慢、偶尔不稳。
② 换域名之后，您在这台电脑上保存的登录状态不会跟着过去（浏览器按域名隔离）。到了新站点还要再用一次恢复码进站——不过那只要 10 秒，见第 4 段。

8
新建一个 Access 应用

填：

默认会有一条 Default 策略，点它右边的 Edit（铅笔图标），改成：
  • Policy name：仅站长
  • Action：Allow（允许）
  • 在 Include（包含）那里点 + Add include → 选 Email addresses → 填 3984557428@qq.com → 点 Apply
